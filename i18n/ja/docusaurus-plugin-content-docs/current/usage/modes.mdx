# 手動モードと自動モード

## ゲーム内メニュー

Setupで導入したModuleとオプションに応じて、次のメニューが構成されます。

```text
汗
├─ 汗の表示
├─ 汗 %
├─ 自動モード
├─ エフェクト
│  ├─ 全エフェクト
│  ├─ 落下する滴
│  ├─ 床の濡れ跡
│  ├─ 吐息
│  ├─ 体の湯気
│  └─ 体の湯気・吐息の濃さ（任意のラジアル）
└─ 負荷を軽減
   ├─ 肌の汗を非表示
   ├─ 相手側を低負荷
   ├─ 自分にだけ表示
   └─ 水滴の立体感（テッセレーション / 高負荷）
```

- **相手側を低負荷** は、Sweat Base Moduleを導入した場合に表示されます。
- **エフェクト** は、Sweat Effects Moduleを導入した場合に表示されます。
- **体の湯気・吐息の濃さ** は、Setupで任意の保存・同期ラジアルを選択した場合だけ表示されます。
- **水滴の立体感（テッセレーション / 高負荷）** は、水滴の立体感を導入した場合だけ表示されます。

導入していないModuleやオプションの項目は自動的に省略されます。ゲーム内メニュー名は、**［インストール / 更新］** を押したときの Setup ウィンドウの言語で作られます。

:::note[v2.0.0 で変わったメニュー名]
息 → **吐息**、湯気 → **体の湯気**、表面の汗を非表示 → **肌の汗を非表示** に変わりました。パラメーターは変わらないため、保存された値は残ります。メニュー名は **［インストール / 更新］** または **FX に適用** を押したときに変わります。以前の **VRC Light Volumes** のトグルは削除されました。
:::

## 手動モード

**自動モード** をオフにして、**汗 %** を0～100%で直接設定します。撮影、比較、固定した汗量が必要な場面に向いています。

手動モードと自動モードは別々の値を持ちません。自動モードをオフにすると、今の **汗 %** が手動の値として残ります。もう一度オンにすると、ゲージを戻さずにその値から続きます。

メニューの汗量は1%刻みで更新され、リモートの Float 同期精度は約1/127 (0.8%)です。

## 自動モード

インストール後、**自動モードは既定でオン** です。体の実際の動きを検出し、動きが多いほど汗 % が速く増え、動きを止めると汗 % がゆっくり下がります。

ダンス、スクワット、バランスボールの動き、上体の揺れなどのトラッキングされた動きがセンサーを動かします。**WASDの移動とジャンプは意図的に除外** しており、移動後の短い安定化時間も含まれます。そのため、ワールド内を移動するだけでは汗をかきません。動き検出・蓄積・回復は0.1秒の固定周期で計算されるため、ゲームFPSによって速度が変わりません。

- **自動モード感度** は、動きをどれだけ強く扱うかを決めます。
- **累積速度曲線** は、汗 % の範囲ごとの蓄積速度を変えます。
- どちらの設定も自動モードに影響します。

既定の感度プリセットは **バランス** です。

自動モードには、Modular Avatarのボーン構成を持つHumanoidアバターが必要です。Non-Humanoidアバターや、必要なボーン参照が無いアバターでは手動モードを使用できます。

## 汗の表示と汗 0% の違い

- **汗の表示ON + 汗 0%:** システムは待機状態で、自動モードは0から汗を増やし始めることができます。
- **汗の表示OFF:** 汗の表現全体が無効になります。

乾いた状態から始め、動き始めてから自然に濡れていくようにしたい場合は、汗の表示をONにしたまま0%にしてください。

汗 0% と汗の表示オフは完全に無料ではありません。屈折のための画面コピー（GrabPass、約 +0.05 ms）が残ります。肌の汗の負荷がなくなるのは **肌の汗を非表示** だけです。詳しくは[パフォーマンスガイド](../performance.mdx)を確認してください。

## 動作の簡単な確認

1. **汗の表示** を有効にします。
2. 既定でオンの自動モードを一時的にオフにして、0%、25%、50%、75%、100%を確認します。
3. 自動モードを有効にして、アバターを動かします。
4. 動きを止め、値がゆっくり下がることを確認します。
5. 範囲を通しても、見た目が急に飛ばないことを確認します。

# Setup・Tuning オプション一覧

このページでは、RealSweatSystem 2.0.0 の通常の設定項目を説明します。**Base** と書いた項目は Sweat Base Module を導入した場合に、**Effects** と書いた項目は Sweat Effects Module を導入した場合に表示されます。

## Tuning コンポーネントを開く

Setup 後、Hierarchy でアバターを展開し、アバタールート直下に生成された **RealSweat** オブジェクトを選択します。Inspector に **RealSweatSystem Tuning** があります。導入済みのアバターでは、Setup ウィンドウの **状態** の行にある **Tuning を開く** ボタンからも開けます。

初回のSetupが完了せずにオブジェクトが無い場合は、Consoleの最初のエラーを解決してから **［インストール / 更新］** をもう一度押してください。導入済みの `RealSweat` オブジェクトを手動で削除した場合は、Bodyを確認せずにSetupを再実行しないでください。[手動削除後の復旧手順](../troubleshooting.mdx#manual-delete-recovery)に従ってください。

| **立体表現の精密度** | インストール済みのすべての水滴の立体感マテリアルにすぐ反映されます。 |
| **Body表面の発生マスク** / **Body表面の表示マスク** | 汗マテリアルにすぐ反映されます。 |

| 導入時に除外した湯気の位置、導入済みエフェクトの追加・削除 | **［インストール / 更新］** を押します。 |

## Setup ウィンドウのオプション

`CookiTools → RealSweatSystem → Setup／Uninstall` を開きます。タブは **インストール** / **トラブルシューティング** / **削除** です。最初の画面には必要な項目だけを置き、細かいオプションは **詳細設定** に折りたたまれています。画像はウィンドウの大きさによらず同じ大きさで表示され、ウィンドウが短いときはスクロールします。

### 最初の画面

| 項目 | モジュール | 初期値 | 内容 |
|---|---|---|---|
| **アバター** | 共通 | 未指定 | Hierarchy でアバターを選ぶか、この欄にドラッグします。 |
| **状態** | 共通 | — | アバターの導入状態を表示します。以前のバージョンで導入したアバターでは「古いバージョンでインストールされています。」という黄色い枠が表示されます。**Tuning を開く** は導入済みの `RealSweat` オブジェクトを選択します。 |
| **汗を付ける場所** | 共通 | 自動検出 | ボディメッシュの欄です。自動で見つかり、違うときは Hierarchy から正しいメッシュをこの欄にドラッグします。その下に使うマテリアルが表示されます。**［変更］** を押すと、マテリアル枠などの残りを設定する **詳細設定 > 汗を付ける場所** が開きます。Effects Module だけのときは、この欄は **落下する滴の場所** です。 |
| **インストールするエフェクト** | Effects | すべて ON | チェックボックス: **落下する滴**、**床の濡れ跡**（落下する滴が必要）、**吐息**、**体の湯気**。体の湯気が出る場所と濃さメニューは **詳細設定 > エフェクト** にあります。 |
| **肌の汗** | Base | **濡れるほど肌のツヤ** ON | チェックボックス **濡れるほど肌のツヤ**: 汗が増えるほど肌のツヤが増します。オフにすると汗マテリアルの **濡れた肌の膜** が 0 になり、ゲーム内の **濡れた肌の膜** トグルは導入されません。 |
| **汗のスタイル** | Base | **リアル（標準）** | 2枚の画像のどちらかをクリックします: **アニメ** または **リアル（標準）**。ウィンドウを開き直すと、そのアバターの今のスタイルが選ばれています。この行は Base Module を導入しているときだけ表示されます。 |
| **表現** | Base / Effects | **基本** | **基本** または **立体（高負荷）** です。**立体（高負荷）** は水滴の立体感、3Dパーティクル、水滴のはねを一緒にオンにし、その下に **最初からオン** が表示されます。**基本** を選ぶとそれらがオフになります。Base Module があるときは2枚の画像、Effects Module だけのときはボタンで選びます。**立体（高負荷）** の画像の下には、近くや横から見ると水滴が盛り上がって見えることと、**最初からオン** にチェックしないと水滴の立体感は最初はオフで、ゲーム内メニューでオンにすることが書かれています。オフのときは、そのメニュー（**汗 > 負荷を軽減**）を案内の枠で知らせます。 |

| **自動モード感度** | 共通 | **バランス: 動きの強さに比例する推奨設定** | **バランス: 動きの強さに比例する推奨設定** または **敏感: 小さな動きでも速く蓄積** です。 |
| **［インストール / 更新］** | 共通 | — | アバターにインストールまたは更新します。結果はボタンのすぐ下の枠に表示され、時間がかかる段階ではプログレスバーが出ます。 |

### 詳細設定

**詳細設定** には次のグループがこの順に並びます。値を変えると、インストール済みの状態に戻すボタン（**インストール済みの構成に戻す**）、または最初のインストール前ならおすすめの状態に戻すボタン（**おすすめに戻す**）が表示されます。

| グループ | モジュール | 項目と初期値 |
|---|---|---|
| **汗を付ける場所**（Effects Module だけのときは **落下する滴を出すマテリアル**） | 共通 | **ボディメッシュ**（最初の画面の **汗を付ける場所** と同じメッシュです。自動で見つかります。間違っているときだけ設定します）と **再検出**。ボディのマテリアルが複数ある場合は、肌のマテリアルだけにチェックします。Effects Module だけのときは、**落下する滴を出すマテリアル** で滴を出すマテリアルの Element を選びます（通常は Element 0）。 |
| **エフェクト** | Effects | 体の湯気の下の **場所**: **胸元**、**両肩**、**脇**、**太もも**（ON）と **股間**、**足**（OFF）。最初の画面で **体の湯気** にチェックしたときに表示されます。**体の湯気・吐息の濃さメニューを追加（+8bit）**（OFF）。エフェクトそのものは、最初の画面の **インストールするエフェクト** のチェックボックスで選びます。 |
| **品質・負荷** | 共通 | **汗の品質**（**軽量** / **低負荷（推奨）** / **標準**）。**水滴の立体感（テッセレーション・高負荷）**（OFF）とその下の **最初からオン**（Base）。**3Dパーティクル（高負荷）**（OFF）と **水滴のはね**（基本の表現ではOFF）（Effects）。**ミラーでも汗を高品質（高負荷）**（OFF）（Base）。 |
| **互換性（問題があるときだけ）** | 共通 | **描画順を自動（推奨）**（ON）と、それがオフのときの **汗レンダーキュー**（Base）。ボディと汗のレンダーキューを示す行（「ボディ … → 汗 …」）があり、**そのままにする** を選んだ後は **［もう一度確認］** がここに表示されます。**Write Defaults**（**自動（推奨）** / **WD ON** / **WD OFF**）と **再検出**、検出結果。 |
| **他のメッシュにも汗を付ける（実験的）** | Base | 顔などの他のメッシュです。Restデータ・マスク・描画負荷を個別に持ちます。 |

- **ミラーでも汗を高品質（高負荷）:** オフのときはミラーで汗腺の小さな水滴を省き、水滴の立体感も盛り上がりません。オンにするとミラーでも通常の画面と同じに描くため、ミラーのGPU負荷が増えます。同じ切替は汗マテリアルのインスペクターの **詳細設定 > ミラー** にもあります。
- **体の湯気・吐息の濃さメニューを追加（+8bit）:** ゲーム内に **体の湯気・吐息の濃さ** ラジアルを追加します（初期値50%）。0%は不透明度0.1倍、50%は従来の見た目を維持する1.0倍、100%は1.5倍です。不透明度だけを変え、パーティクル数と処理負荷は減りません。同期パラメーターを8bit多く使います。
- **描画順を自動（推奨）:** メインBodyの汗をレンダーキュー `2350` で描画します。追加対象には `max(ボディの汗のレンダーキュー（通常2350）, 選択マテリアルのレンダーキュー + 1)` を使用します。**汗レンダーキュー** は、他のシェーダーで特定の順序が必要な場合のみ使用してください。手動のレンダーキューでは、ボディマテリアルの確認も変更もしません。

ボディの Shadow Strength 追従、立体感の精度、ミラー内の体の湯気、自分の視点でも吐息を表示、Custom Steam Point はインストール後に `RealSweat` オブジェクトの Tuning で設定します。

Setupは、アセットを書き込む前に、導入予定のすべてのパラメーターをAvatar Expression Parametersと他のModular Avatar宣言（接頭辞・リマップを含む）に照合します。名前が衝突する場合はSetupを停止します。予測合計が256bitを超える場合は、続行前に警告します。

### Write Defaults

**Write Defaults** のドロップダウンは **詳細設定 > 互換性（問題があるときだけ）** にあります。ほとんどの場合は **自動（推奨）** のままにしてください。

- **自動（推奨）:** 外部FXがすべてWD ONの場合だけRealSweatもすべてWD ONにします。WD OFF、混在、または判定不能の場合はWD OFF互換構成を使用します。
- **WD ON:** RealSweatのすべてのStateをWD ONに固定します。アバターのFXがすべてWD ONでなければならない場合だけ選んでください。
- **WD OFF:** WD OFFまたは混在アバター向けに、Driver ON / Output OFF分離構成を維持します。

**再検出** はアバターのFXをもう一度確認し、ドロップダウンの下の行に検出結果を表示します。

### 汗の品質

**汗の品質**（1.1.x の「全体の汗量」。Tuning でも同じ名前）は、汗の品質段階と負荷を選ぶ項目です。

| 選択肢 | 描くもの |
|---|---|
| **標準** | すべて描きます。最も重い段階です。 |
| **低負荷（推奨）** — 新規導入の既定値 | 汗腺の小さな水滴だけを省きます。会話の距離や 1.5～3 m では標準とほとんど見分けがつきません。 |
| **軽量** | 低負荷より少し多く省きます。アニメ: 流れ跡の残り滴と膜の細い線（膜のツヤは残ります）。水滴の並び、長く流れる水滴の列、流れ跡のツヤは低負荷と同じです。リアル: 残り滴、白い肌の稜線ハイライト、長く流れる水滴の列、反射プローブ、ごく小さな水滴を省くため、水滴の並びが少し違います。軽量は GPU 時間が低負荷とほぼ同じです。 |

- 肌の汗の量は3つとも同じです。汗 % ラジアルが 30% のときマテリアルの汗量は 0.30、100% のとき 1.00 です。1.1.x の軽量と低負荷（当時の名前は「少なめ」）は同じ位置で 0.20 と 0.65 だったため、この2つを使っていたアバターは以前より汗が多く見えます。
- 落下する滴は、これまでどおり標準が最も多く、低負荷と軽量では少なくなります。2Dの体の湯気は3つとも同じです。3Dパーティクルの体の湯気は v1.1.3 と同じ量で、低負荷と軽量では標準の 0.65 倍です。

### 汗のスタイル

- **アニメ** は、はっきりした輪郭とハイライトのある水滴が遠くからもよく見えます。**リアル（標準）** は輪郭のない透明な水滴です。水滴を通して見える肌が、レンズのように少し歪んで見えます。小さな水滴が多く、白いハイライトの代わりに光と周りの映り込みで描き、大きめの水滴には小さな白いハイライトがあります。水滴の間にはごく小さな水滴が群れになっていて、遠くからは点ではなく濡れたツヤに見えます。流れ落ちるのは大きな水滴だけで、流れ跡は灰色の線のない、澄んだツヤのある筋です。
- リアルの水滴のまわりには、暗い縁、リング、肌に接する部分の影がありません。そのため、水滴が肌の上のこぶのように見えません。ごく小さな水滴は少し減らし、正面から見た水滴ははっきり見えます。
- スタイルはアバターごとに1つです。ボディと他のメッシュの汗マテリアル（立体感のペアを含む）はすべて同じスタイルを使います。インストール後は Tuning の **基本設定 > 汗のスタイル** で変更できます。マテリアルインスペクターは今のスタイルを表示するだけです。
- スタイルを選べるのは Base Module を導入しているときだけです。Effects Module だけのときは Setup ウィンドウにも Tuning にも汗のスタイルがなく、落下する滴・床の濡れ跡・はねはリアルの見た目になります。2.0.0 ですでに導入したアバターは、そのときの見た目のままです。
- 新規導入と 1.1.x から更新したアバターはリアルから始まります。1.x のアバターには保存されたスタイルがないため、新しい既定値になります。2.0.0 ですでに導入したアバターは、選んだスタイルのままです。アニメを使うには、アニメの画像を選んで **［インストール / 更新］** を押してください。
- 品質段階は両方のスタイルに同じように適用されます。リアルの軽量では、ごく小さな水滴も省きます。
- 負荷: リアルのシェーダー命令数はアニメより少しだけ少なくなります（標準で 3457 対 3523）。GPU 時間はアニメとほぼ同じで、近くで胴全体が画面を埋めるときに最大約 14 % 増えます。水滴の立体感をオンにすると、標準ではアニメの立体感の約 1.07 倍、低負荷では約 0.95 倍です。アバターは選んだスタイルのシェーダーだけを使うため、他の人の初回読み込みはスタイルによらずほぼ同じです。
- 知っておくこと: リアルでは、おへその上のような折れ目で小さな水滴が2つに分かれて見えることがあり、水滴どうしが実際に合わさることはありません。

### 水滴の立体感の選択肢 {/* #droplet-depth-choices */}

水滴の立体感をオンにすると、近くでは水滴と流れ落ちる水滴が実際に肌から盛り上がり、横から見ても丸く見えます。両方のスタイルで動作します。流れ跡、汗腺の小さな水滴、跡の上の残り滴は盛り上がりません。

| 立体表現の精密度 | Tess係数 | 水滴が盛り上がる距離 | 立体感なしと同じ描画になる距離 |
|---|---:|---:|---:|
| **簡素 — 通常プレイ向け**（既定） | `2.5` | 約 0.35 m 以内 | 約 0.7 m から |
| **均衡 — 接写鑑賞向け** | `4` | 約 0.6 m 以内 | 約 1.5 m から |
| **精密 — 写真撮影向け** | `7` | 約 0.9 m 以内 | 約 2.2 m から |

水滴の立体感を導入しても、1つの対象でTessとNo Tessが同時に描画されるわけではありません。メニューは、水滴の立体感のすべての汗スロットをTessとNo Tessの間でまとめて切り替えます。**水滴の立体感（テッセレーション / 高負荷）** をオフにするとNo Tessシェーダーを使うため、Hull／Domainのテッセレーション処理は行われません。**ミラーでも汗を高品質** がオフのミラーと **相手側を低負荷** では、水滴は盛り上がりません。

複数の対象を設定した場合、各対象は選択中のTessまたはNo Tessだけを描画しますが、別のBody ElementやRendererはそれぞれ汗の描画を追加します。

### 実験的な対象の安全性

`RealSweatSystem Tuning` には、導入済みの追加対象の生成マテリアル／スロットの状態が表示されます。

- **追加対象を管理...** で、現在の対象一覧を読み込んだSetupを開きます。
- 対象が **修復が必要** と表示された場合は、**Setup ウィンドウで修復...** を使用します。
- 対象を削除するには、一覧の`-`で外してから **［インストール / 更新］** を押します。
- 生成マテリアルやRendererスロットを削除、空欄化、移動、置換、統合して対象を無効にしないでください。破損は黙って省略されず、対象を修復または削除するまでアバタービルドが停止します。

## Tuning オプション

Tuning コンポーネントは **基本設定**、**エフェクトの有効/無効**、**自動モード設定**、**肌表面の設定**、**エフェクト詳細設定**、**パフォーマンス・詳細設定** のグループに分かれ、その後に **メッシュおよびRestデータ診断** と **FX に適用** ボタンがあります。導入していないモジュールのグループは表示されません。

### 基本設定

| 項目 | モジュール | 初期値 | 範囲 | 内容 |
|---|---|---:|---:|---|
| **汗の品質** | 共通 | 低負荷（推奨） | — | Setup と同じ3段階です。 |
| **汗のスタイル** | Base | リアル（標準） | — | そのアバターのすべての汗マテリアルの見た目をまとめて変更します。 |
| **感度プリセット** | 共通 | バランス | — | **バランス** は動きの強さに比例し、**敏感** は小さな動きから早く最大反応へ到達します。プリセットを選ぶと、反応しきい値・飽和ポイント・上昇 / 乾燥基準・スムージングの値が読み込まれます。 |
| **汗の蓄積速度倍率** | 共通 | `1.0` | `0.25–4` | プリセット全体の自動蓄積速度を倍率化します。 |

### 自動モード設定

**自動蓄積レスポンス** は、感知した動きが時間とともに見える汗になる方法を決めます。

| 項目 | 初期値 | 範囲 | 内容 |
|---|---:|---:|---|
| **水平感度（左右・前後）** | `1.0` | `0.95–1.10` | 左右・前後の反応です。 |
| **上下感度** | `1.2` | `0.90–1.30` | 上下運動の反応です。小さな上下動やスクワットには `1.2` を推奨します。 |
| **プレビュー方向** | 混合 | — | **混合** / **水平** / **垂直**。プレビューだけを切り替えます。ゲーム内では全方向が常に有効です。 |

| **蓄積プロファイル** | 均一 | — | 現在の汗 % に応じて蓄積速度を変えます。同期パラメーターやランタイムレイヤーは増えません。 |
| **詳細値** | 折りたたみ | `0.1–2` | `0/25/50/75/100%` の5つの倍率を編集します。 |
| **蓄積グラフ** | 折りたたみ | — | 一定運動を仮定したプロファイルと95%までの推定時間を表示します。実際のPhysBone入力はアバターとアニメーションに依存します。 |

蓄積プロファイル:

- **均一:** すべての汗 % で同じ倍率です。新規インストールの初期値です。
- **自然（推奨）:** 序盤を少し速くし、高い汗 % ほど徐々に遅くします。
- **序盤を速く:** 最初の蓄積を強くします。
- **後半加速:** 序盤を遅くし、後半を速くします。
- **カスタム:** 5点を直接編集します。

用意されたプロファイルは95%までの推定時間がほぼ同じになるよう調整されていますが、最後の5%は異なることがあります。感度・蓄積速度倍率・方向感度・蓄積プロファイルはすべて自動モードに同時に影響します。

## 汗マテリアルのインスペクター

以下は Tuning コンポーネントではなく、生成された RealSweat マテリアルの Inspector にある項目です。新しい見た目が読む値だけを表示します: **クイック設定**、**分布**、**流れ**、**ライティング**、**詳細設定**。1.1.x の値は非表示ですが、マテリアルに残っています。

| 項目 | 場所 | 用途 |
|---|---|---|
| **Rest データ** | インスペクター上部 | 有効なRestデータがないマテリアルを知らせます。 |
| **標準の見た目に戻す** | **汗の見た目** の行 | 見た目の値だけを戻し、汗量、品質、模様番号、マスク、ステンシル、Rest データ、Setup の選択は変えません。1.1.x のプリセットはこのボタンひとつになりました。 |
| **汗の量（プレビュー）** | **クイック設定** | ゲーム内メニューがこの値を動かします。ここの値はエディターで見える量です。 |
| **水滴サイズ** | **クイック設定** | 水滴の半径を拡大縮小します。`1.6` が標準の見た目です。 |
| **きらめきの大きさ** / **きらめきの強さ** | **クイック設定** | 水滴に映る光（きらめき）です。既定はどちらも `1.5` で、`1` に下げると落ち着いた見た目になります。 |

### 表面マスク {/* #surface-masks */}

どちらのマスクも、Tuning の **肌表面の設定 > 表面マスク・メッシュ別設定** と、汗マテリアルのインスペクターにあります。どちらもメッシュのUV0を使用します。テクスチャを割り当てると **マスク強度** が1になり、外すと0になります。

- **Body表面の発生マスク:** 白い領域は表面の汗を許可し、黒い領域は遮断します。付着水滴・濡れ膜・Tess変位の生成領域を制限し、落下する滴のパーティクルは変えません。**マスク詳細設定** には **しきい値**、**ぼかし**、**マスク反転**、**タイリング**、**オフセット** があります。マテリアルインスペクターでは **分布 > 発生マスク（白＝発生）** で、赤チャンネルを読みます。**マスク強度**、**マスクしきい値**、**マスク境界のソフトさ**、**マスク反転** があります。
- **Body表面の表示マスク:** 白い領域に表面の汗を表示し、黒い領域では完全に隠します。水滴、流れ跡、濡れ膜、光沢、屈折、暗化、Tess変位を含む表面の最終結果を隠しますが、落下する滴のパーティクルには影響しません。**マスク詳細設定** には **マスクチャンネル**（R/G/B/A）、**マスク反転**、**タイリング**、**オフセット** があります。マテリアルインスペクターでは **詳細設定 > 表面の汗マスク** です。グレースケール値を正確に使うには、テクスチャの **sRGB (Color Texture)をオフ** にしてインポートしてください。既定強度は`0`のため、設定するまでは更新しても従来の見た目は変わりません。

### v2.0.0 でなくなった機能

ミルクモード、ボディノーマルマップによる濡れ表現、光学 LUT、フローガイドマップ、Rest パターンの回転は 2.0.0 の汗の見た目にはありません。Pattern Space の手動 Rest 軸モード（Rest Front XY／Side ZY／Top XZ）もなくなり、このモードを使っていたマテリアルは Rest Normal Triplanar に変わります。`Body Normal Map` の値はマテリアルに残りますが、効果はありません。流れの方向はリアルタイムのワールド重力に従います。メッシュごとのパターン密度と Tuning の「パターン密度」も非表示にしました。

Light Limit Changer（LLC）でアバターの明るさを変えると、肌の汗も同じ割合で追従します。詳しくは[対応環境・互換性](../compatibility.mdx#light-limit-changer)を確認してください。

## 相手側を低負荷・ミラー

**相手側を低負荷** はアバターメニューの項目で、Tuning Inspector の項目ではありません。相手側ではNo Tessで、汗腺の小さな水滴なしに描き、低負荷と軽量では残り滴とアニメの膜の細い線も省き、面の向きが切り替わる所の処理を減らします（相手側の GPU 時間は低負荷で約 4~8 %、標準で 23~29 % 減ります）。相手側の体の湯気／Custom Steamは数はそのままで濃さを0.6倍にします（3Dの体の湯気は数が25%）。3Dパーティクル品質の使用時は相手側の落下する滴を50%へ減らし、強い動きによる追加水滴を停止します。自分側の品質は維持します。

ミラーのオプション:

- **ミラーでも汗を高品質** は既定でオフです。オフのときはミラーで汗腺の小さな水滴を省き、水滴の立体感も盛り上がりません。オンにすると、ミラーでも通常の画面と同じに描きます。
- **ミラー内の体の湯気** は **フル**、**低（2D不透明度を低減）**、**非表示** から選びます。2Dの低はパーティクル数を変えずに、ミラー内の湯気をフルの0.8倍の濃さで描きます。3Dの低は現在フルと同じ見た目と負荷です。最も低いミラーコストは非表示です。

:::warning[負荷が重なりやすい組み合わせ]
標準の品質、接写による大きな画面占有、ミラー、水滴の立体感を同時に使うとGPU負荷が重なります。大きな項目は1つずつ変更し、アップロード後のアバターで確認してください。
:::

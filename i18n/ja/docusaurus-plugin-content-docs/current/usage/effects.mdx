# エフェクトガイド

Effects Moduleの機能は、アバターメニューの独立した **汗 > エフェクト** からまとめて、または個別にON/OFFできます。

## 初期状態

**落下する滴**、**床の濡れ跡**、**息**、**湯気**は初期状態でONです。湯気の放出位置は胸元・両肩・脇・太ももがON、股間・足がOFFです。

Setupでは従来の軽量2D品質と、任意の高負荷3D品質を選べます。3D品質への変更は生成構成が変わるため、**FXに適用**ではなく完全なSetupが必要です。3D落下水滴では任意の衝突スプラッシュも使用できます。

:::info[リグ・Bone参照に制限がある場合]
Non-Humanoidアバター、またはModular Avatar Bone ProxyによるMotion Pendulumを作成できない構成でも、Manual Mode、落下する滴、床の濡れ跡は使用できます。この場合、自動モード、息、湯気のメニュー項目は生成されません。

Motion Pendulumを作成できても、必須のHead・Chest Anchorを解決できない場合は自動モードを使用できますが、息と湯気のメニュー項目は生成されません。
:::

## 落下する滴

身体の各部から汗の粒が自然に落下します。表面の汗と同じSweat %に連動し、Sweat %が高いほど放出量が増えます。

## 床の濡れ跡

落下した汗の粒が床へ到達すると、3×3の形状バリエーションから濡れ跡を残します。床の濡れ跡は落下水滴の**衝突サブエフェクト**なので、落下水滴が導入済みかつONでなければ生成されません。ワールドの床構造、Default／Environment Layer、Colliderの状態によって、衝突しない場合や見え方が異なる場合があります。

## 息

口元から吐息を表示します。初期設定では **Sweatが約25%を超えると**、口を開いている間に表示されます。開始値はTuningで変更できます。

- SetupはAvatar DescriptorとModular Avatarから `v2/JawOpen`、`FT/v2/JawOpen` などのVRCFT Floatを検出します。
- 自動判定ではJawOpenの実際の開閉変化を検出している間はVRCFTを優先します。
- JawOpenに開閉変化が8秒間無い場合はVisemeへフォールバックします。VRCFTが再び動くとVRCFTを再使用します。
- VRCFT Floatが見つからない場合もVisemeによる口の開閉で動作します。
- Face Tracking環境ではv1.0.1以降を使用してください。

:::note[自分の1人称で表示する場合]
既定では自分のVRChat 1人称画面に息は表示されません。Setupの **一人称視点で自分の息を表示**を選ぶと、MA Visible Head Accessoryを使用して自分にも表示できます。既定はOFFで、有効なHumanoid Headボーンと対応するModular Avatarが必要です。
:::

## 湯気

身体から立ち上る湯気を表現します。初期設定では **Sweat 30%付近** から薄く現れ、100%へ近づくほど濃くなります。不要な放出位置はSetupまたはTuningでOFFにできます。

体の湯気のミラー表示は`Full / Low / Hidden`から選択します。新規導入の既定は`Low`で、v1.0.xから更新した既存表示は外観維持のため`Full`として引き継ぎます。2Dの`Low`はTexture Blurを省略して表示を弱めますがParticle数は減らしません。3Dの`Low`は現在`Full`と同じ見た目・負荷なので、最小負荷には`Hidden`を使用してください。

任意のTransformへ **Custom Steam Point** を追加し、サイズ・発生量・拡散・方向・左右ミラーペアを設定できます。有効なCustomスロットは最大4つで、左右ペアは2スロットを使用します。内蔵／Customの合計は12個が上限で、10個を超えるとミラー負荷の警告が表示されます。発生量Weightの合計が`4.0`を超えると全Emitterを同じ比率で下げて正規化します。有効なAnimatorとMA Bone Proxyを解決できる構成が必要です。

Setupで任意の **体の湯気・吐息の濃さ**ラジアルを導入すると、湯気／Custom Steamと吐息を同時に調整できます。0%が不透明度0.1倍、50%が従来の見た目を維持する1.0倍、100%が1.5倍です。不透明度だけを変え、Particle数・速度・サイズ・寿命および処理負荷は減りません。以前に生成された2点の濃さCurveを新しい3点範囲へ移行するには、**FXに適用**ではなく完全なSetupを1回実行してください。

:::tip[パフォーマンス]
使用しないEffectsはメニューで個別にOFFにできます。すべてをまとめて切り替える場合は **全エフェクト** を使用します。詳しい負荷の順序は[パフォーマンス](../performance.mdx)を確認してください。
:::

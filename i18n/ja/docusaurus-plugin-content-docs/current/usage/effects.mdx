# エフェクトガイド

Effects Moduleは、システム全体と同じ汗 % で動くパーティクルエフェクトを追加します。Effectsだけを導入する場合も放出元としてBody Meshが必要ですが、BodyのMaterialやMeshは変更しません。

Non-Humanoidアバター、またはModular Avatarのモーション振り子を作成できない場合は、手動モード、落下する滴、床の濡れ跡を使用できます。自動モード、吐息、体の湯気は作成されません。

モーション振り子を作成できても、必要なHead／Chestのアンカーが無い場合は、自動モードは使用できます。吐息と体の湯気は作成されません。

## ゲーム内の操作

次を開きます。

**汗 → エフェクト**

ここで次の項目を操作できます。

- 全エフェクト
- 落下する滴
- 床の濡れ跡
- 吐息
- 体の湯気
- 体の湯気・吐息の濃さ（任意のラジアルを導入した場合のみ）

## 2Dと3Dのパーティクル

既定では従来の軽量な2Dパーティクルを使います。**3Dパーティクル（高負荷）** は、吐息・落下する滴・体の湯気の描画をメッシュパーティクルに変えます。動き、重力、衝突、床の濡れ跡、ゲーム内のエフェクト切替は、どちらのモードでも使用できます。

- Setup ウィンドウの最初の画面の **表現** で **立体（高負荷）** を選ぶと、3Dパーティクルが水滴の立体感・水滴のはねと一緒にオンになります。**基本** を選ぶと、3Dパーティクルと水滴の立体感がオフになります。
- **3Dパーティクル（高負荷）** は **詳細設定 > 品質・負荷** で個別にオンにすることもできます。
- 2D／3Dの切替では生成構成が変わるため、**［インストール / 更新］** をもう一度押してください。**FX に適用** だけでは足りません。

3Dの体の湯気・吐息は見た目はそのままで、VRChatのパフォーマンスランクの Mesh Particle Active Polys が大きく減りました（既定の導入の湯気・吐息で 96,000 → 92）。

## 落下する滴

汗の滴が全身から落ち、汗が100%に近づくほど多くなります。落下する滴は小さく、ゆっくりのときは丸く、速く落ちるほど長く伸びます。3Dは涙形の水のレンズとして、2Dは光を受ける水滴として描きます。

落下する滴は汗のスタイルに従います。**アニメ** ははっきりした白いハイライトと輪郭で、**リアル** は暗い縁と小さなきらめきで描きます。

滴が速く落ちるため、1つのシステムで同時に見える滴は多くても8個です。**落下水滴の最大数（システムごと）** の既定値は12で、強い動きの滴はその3分の2の8個までを使います。

Baseと実験的な追加対象を導入している場合、追加対象からも任意で落下する滴を出せます。その対象には、表面積と発生率の個別の設定があります。

**初期値:** ON

## はね

はねは、滴が落ちたときに小さな丸い粒が短く飛ぶ表現です。2D・3Dのどちらのパーティクルでも動作し、汗のスタイルに従います。

- **水滴のはね** は、新しく導入するとき **基本** の表現ではオフで、**立体（高負荷）** を選ぶとオンになります。**詳細設定 > 品質・負荷** で個別にオン／オフすることもできます。
- はねをオンにするとパーティクルシステムが2つ、マテリアルスロットが2つ増えるため、VRChat のパフォーマンスランクが一段階下がることがあります（例: マテリアルスロット 15 → 17 で Medium → Poor）。
- 1.1.x の2Dパーティクルの導入は、更新してもはねなしのままです。はねを使う場合は、**水滴のはね** をオンにして **［インストール / 更新］** を押してください。

## 床の濡れ跡

床の濡れ跡は、落下する滴から出る衝突サブエフェクトです。落下する滴を導入して有効にしている間だけ使用できます。衝突対象はワールドの **Default** と **Environment** レイヤーに限定し、アバター・Player系レイヤーは除外します。床のColliderやレイヤーが合わないワールドでは、濡れ跡が出ない場合があります。

床の濡れ跡は 1.1.3 と同じにじんだ形で、床を暗くするだけです。ツヤやきらめきはなく、縁から先に乾きます。

**初期値:** ON

## 吐息

吐息は、次の両方の条件を満たしたときに口元に出ます。

- **汗 % が既定の開始しきい値25%を超えている**
- 選択または自動検出した顔の入力で、口が開いている

Viseme入力とVRCFT入力の両方に対応しています。手動モードと自動モードのどちらでも、同期済みの汗 % が吐息の開始・大きさ・周期速度を決めます。吐息は既存の `Cooki/SweatAmount` Float を再利用するため、同期Floatパラメーターは追加されません。

吐息の口判定を **自動** にすると、Avatar Descriptor と Modular Avatar から `v2/JawOpen` および `FT/v2/JawOpen` のような接頭辞付きの名前を検索します。一致する Float が存在しても、最初は Viseme を使用し、JawOpen の実際の開閉変化を検出すると VRCFT を優先します。JawOpen が閉じた値（0.015 未満）まで下がったあと、0.03 を超えないまま8秒たつと Viseme に戻ります。VRCFT を停止したあとに吐息が出なくなった場合は、口判定を Viseme に変更してください。

吐息は既定では自分の一人称視点に表示されません。自分にも表示するには、Tuning の **自分の視点でも吐息を表示** を有効にします。有効なHeadボーンと、MA Visible Head Accessoryを含むModular Avatarが必要です。カメラと重なる場合があるため、既定ではオフです。

**初期値:** ON

## 体の湯気

体の湯気は v2.0.0 で作り直しました。1点から大きな塊がひとつ上がる代わりに、いくつもがにじんだ淡い湯気が、各部位の周りの広い範囲からゆっくり立ちのぼります。歩くと湯気が体についてきます。深度テクスチャのないワールドでも見え、暗いワールドで光らず、白い肌に灰色のしみを残しません。

体の湯気は既定では汗 **30%** 前後から徐々に濃くなり、共通の汗 % とともに増えます。胸元と両肩を中心に、脇と太ももは弱く補助します。既定の導入では次の位置が有効です。

- 胸元
- 左右の肩
- 脇
- 太もも

股と足の位置は既定でオフです。

- パーティクルシステムの数は変わらず、最大パーティクル数は減りました（既定値で、湯気12か所 288 → 131、既定の導入の7か所 168 → 95）。シェーダーは軽くなりましたが、湯気が広くなった分、近くでは描く量が増えます。
- 2Dの体の湯気は標準、低負荷、軽量で同じです。3Dパーティクルの体の湯気は、低負荷と軽量では標準の 0.65 倍です。
- **相手側を低負荷** では、他の人の画面の体の湯気が、数はそのままで濃さだけ0.6倍になります（3Dの体の湯気は数が25%）。

**初期値:** ON

### Custom Steam Point

Custom Steam Point は、Tuning でアバターのTransformに追加できます。各ポイントにはサイズ・発生量・拡散・方向と、任意の左右ミラーペアがあります。有効なAnimatorとMA Bone Proxyが必要です。有効なカスタムエミッタースロットは最大4つで、左右ミラーペアは2つを使用します。内蔵／Customを合わせて10個を超えるとミラー負荷の警告を表示し、合計12個が上限です。発生量ウェイトの合計が `4.0` を超える場合は、同じ比率で下げて上限内に収めます。検証と生成アセットの更新は、**［インストール / 更新］** または **FX に適用** の実行時に行われます。

### ミラー表示と共通の濃さ

**ミラー内の体の湯気** の選択肢:

- **Full:** すべての表現を描きます。
- **Low:** 2Dの体の湯気は、パーティクル数を変えずに、ミラー内の湯気を Full の0.8倍の濃さで描きます。3Dでは、Low は現在 Full と同じ見た目と負荷です。
- **Hidden:** ミラーのコストが最も低くなります。

新規導入の既定値は Low です。以前の導入を更新した場合は、従来の見た目を Full として引き継ぎます。

Setup では、保存・同期される **体の湯気・吐息の濃さ** ラジアルを任意で導入できます。Setup のチェックは既定でオフで、導入するとラジアルは50%から始まります。0%は不透明度0.1倍、50%は従来の見た目を維持する1.0倍、100%は1.5倍で、**0%でもエフェクトはオフになりません**。体の湯気、Custom Steam、吐息にまとめて適用し、数・速度・サイズ・寿命・処理負荷は変えません。

:::tip[パーティクルの負荷を減らす]
使わないエフェクトは、エフェクトのサブメニューでオフにしてください。多くのアバターが見えている場面では、まず体の湯気から減らすのが一般的です。
:::

## 導入するエフェクトを変更する

- Setup で除外した吐息・体の湯気・落下する滴は、それぞれのパーティクルオブジェクトと専用FXレイヤーを導入しません。
- 既存の導入から除外する場合は、該当オプションをオフにして **［インストール / 更新］** を押してください。該当する生成オブジェクトだけを削除し、共通の自動汗量計算は維持します。
- これは、ゲーム内メニューで一時的にエフェクトをオフにする操作とは異なります。パッケージのインポートだけでは、既存の導入に残っている未使用のパーティクルは削除されません。

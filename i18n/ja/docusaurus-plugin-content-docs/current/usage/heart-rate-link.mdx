# 心拍連動（実験的）

**心拍連動**（v2.1.0 から）は、心拍アプリ（スマートウォッチや心拍ベルトとつながったアプリ）が OSC で VRChat に送る心拍数（BPM）を読み取り、心拍ゾーンに合わせて自動モードの汗の量を決めます。自動モードがオンのときに動作し、自動モードを使えないアバター（ヒューマノイドではないアバターなど）にはインストールしません。

任意の機能で、初期設定はオフです。オフのときはアバターに何も追加しません。オンにしても同期ビットは増えません。心拍は自分の PC でだけ読み取り、ほかの人にはこれまでどおり **汗 %** として見えます。

:::caution[実験的な機能: Unity 上でだけテストしています]
心拍連動は実験的な機能です。Unity 上でテストしましたが、ゲーム内で心拍アプリと一緒に使うテストは、まだしていません。
:::

## はじめて使う方へ {/* #before-you-start */}

Real Sweat System のほかに、次の2つが必要です。

- **心拍を測る機器**: スマートウォッチや心拍ベルト。
- **心拍アプリ**: その心拍数を OSC で VRChat に送るアプリ（ふつうは PC で動かします）。Real Sweat System は、このアプリが送る心拍数（BPM）のパラメーターだけを読み取ります。

よく使われているアプリと、そのアプリが送るパラメーター名です。

| アプリ | パラメーター名 |
|---|---|
| Pulsoid、PulsoidToOSC、MagicChatBox | `HR` |
| VRCOSC | `VRCOSC/Heartrate/Value` |

どちらの名前も、Setup ウィンドウの **心拍パラメーター** の一覧にあります。アプリのインストールと設定の方法は、そのアプリの案内をご覧ください。

手順は次のとおりです。

1. 心拍アプリを設定し、アプリに心拍数が表示されることを確認します。
2. Unity で心拍連動をオンにして **［インストール / 更新］** を押します（[オンにする](#turn-it-on)を参照）。
3. アバターをアップロードします。
4. VRChat のアクションメニューで **Options > OSC > Enabled** をオンにします。
5. ゲーム内メニュー **汗** で、**自動モード** と **心拍連動** がオンになっていることを確認します。
6. 心拍が上がると、汗も増えます。反応が **自然** なら約3分、**速く** なら約45秒かかります。最大心拍数の 50 % 未満では汗をかきません。

## オンにする {/* #turn-it-on */}

1. `CookiTools → RealSweatSystem → Setup／Uninstall` を開き、アバターを選びます。
2. 最初の画面の **自動モード感度** の下にある **心拍連動** の行で、**心拍数に合わせて汗をかく（実験的）** にチェックします。その下に項目が表示されます。
3. **最大心拍数**、**心拍パラメーター**、**反応** を設定します（下の表）。ゾーンの表は **詳細設定** のいちばん上にあります（[心拍ゾーン別の汗の量](#zones)を参照）。
4. **［インストール / 更新］** を押します。
5. アバターをアップロードします。
6. VRChat のアクションメニューで **Options > OSC > Enabled** をオンにしてください。心拍アプリの設定は、そのアプリの案内に従ってください。

[![Setup ウィンドウ最初の画面の心拍連動の行にチェックし、その下に最大心拍数・心拍パラメーター・反応が表示された様子](/img/guide/heart-rate-japanese.png)](/img/guide/heart-rate-japanese.png)

*<small>Setup ウィンドウ最初の画面の、自動モード感度の下にある心拍連動です。</small>*

| 項目 | 説明 |
|---|---|
| **心拍連動** | **心拍数に合わせて汗をかく（実験的）** にチェックすると、下の項目が表示されます。 |
| **最大心拍数** | 時計に表示される最大心拍数（BPM、100～250、初期値 190）。わからない場合は、220 から年齢を引いた値を入力します。 |
| **心拍パラメーター** | 心拍アプリが送るパラメーター名です。ほとんどの場合 `HR` です。一覧には `HR` と `VRCOSC/Heartrate/Value` があります。一覧にない場合は **直接入力** を選び、**パラメーター名** に入力します。`/avatar/parameters/` で始まるアドレスを入れても名前だけを使います。 |
| **反応** | **自然（推奨）**: 約3分で心拍に追いつきます。**速く**: 約45秒で追いつきます。増えるときも乾くときも同じ速さです。 |

**［インストール / 更新］** がパラメーターをどうするかは、Setup ウィンドウの確認一覧に前もって表示されます（[パラメーターと同期](#parameters)を参照）。

## 心拍ゾーン別の汗の量 {/* #zones */}

**心拍ゾーン別の汗の量** は、**心拍連動** にチェックしているときに **詳細設定** のいちばん上に表示されます。各ゾーンは、そのゾーンの終わりに達したときの汗の量を決めます。

| ゾーン | 心拍（最大心拍数に対して） | ゾーンの終わりの汗 %（初期値） |
|---|---|---|
| 1 | 50～60 % | 10 % |
| 2 | 60～70 % | 30 % |
| 3 | 70～80 % | 60 % |
| 4 | 80～90 % | 85 % |
| 5 | 90～100 % | 100 % |

- 最大心拍数の 50 % 未満では汗をかきません。ゾーンの間では汗 % がなだらかにつながり、最大心拍数を超えるとゾーン5の値を使います。
- 各ゾーンは、下のゾーンより少なく、上のゾーンより多くは設定できません（心拍が上がっているのに汗が減らないように）。
- 心拍の信号がある間は、動きに関係なくこの表に従います。
- 表には、設定した **最大心拍数** に合わせたゾーンごとの BPM の範囲が表示されます。初期値の 190 BPM なら、95 BPM 未満では汗をかきません。

## 心拍の信号がないとき {/* #no-signal */}

- 心拍数が 30 BPM 未満のとき、60秒間まったく変わらないとき（例: アプリを閉じて最後の値が残っているとき）、ゲーム内メニュー **汗 > 心拍連動** をオフにしたときは、信号がないものとして扱います。その間は、いつもどおり動きで汗をかきます。
- 信号が途切れても戻っても、そのときの汗の量から続くので、汗が急に変わることはありません。
- 手動モード（自動モードがオフ）では、心拍に関係なく **汗 %** のラジアルに従います。

## ゲーム内メニュー {/* #menu */}

**汗 > 心拍連動** は、心拍連動を導入した場合だけ表示されます。心拍の信号で汗を決めるかをオン・オフします。既定はオンで、値は保存されます（同期なし、0bit）。オフにすると、いつもどおり動きで汗をかきます。メニュー全体は[手動モードと自動モード](./modes.mdx)にあります。

## パラメーターと同期 {/* #parameters */}

- アバターに同じ名前のパラメーターがすでにある場合（Expression Parameters や、ほかのギミックの MA Parameters）、読み取るだけで、その設定は変更しません。ない場合は、同期しない Int パラメーターとして追加します（0bit）。**［インストール / 更新］** がどうするかは、Setup ウィンドウの確認一覧に前もって表示されます。
- その名前が Bool の場合は心拍数を受け取れないため、インストールを止めてお知らせします。Float の場合はその値を BPM として読み取るため、0～1 の値を送るパラメーターは選ばないでください。Real Sweat System または VRChat がすでに使っている名前は使えません。
- 同期ビットは増えません。心拍は自分の PC でだけ読み取り、ほかの人にはこれまでどおり **汗 %** として見えます。

## 導入後に変える {/* #after-install */}

- 最大心拍数、ゾーン別の汗の量、反応、パラメーター名は、Setup ウィンドウで変えてから **［インストール / 更新］** を押すと反映されます。Tuning の **FX に適用** では反映されません。
- 心拍連動をオフにして **［インストール / 更新］** を押すと、心拍連動のレイヤー・クリップ・メニュー・パラメーターを消します。設定値は Tuning に残り、次にオンにするときに使います。
- 2.0.x から上書きインポートするだけでは、心拍連動は追加されません。Setup ウィンドウでオンにして **［インストール / 更新］** を押してください。

## 汗が心拍に合わないとき {/* #troubleshooting */}

上の内容のうち、次の点を確認してください。

- 自動モードをオンにしておく必要があります。手動モードでは、心拍に関係なく **汗 %** のラジアルに従います。
- ゲーム内メニューの **汗 > 心拍連動** をオンにしておく必要があります。
- VRChat のアクションメニューで **Options > OSC > Enabled** をオンにし、心拍アプリをそのアプリの案内どおりに設定して、アプリに心拍数が表示されている必要があります。
- **［インストール / 更新］** を押したあとで、アバターをアップロードする必要があります。それでも汗が心拍に合わない場合は、アクションメニューの **Options > OSC > Reset Config** を押し、別のアバターに切り替えてから戻してください。
- **心拍パラメーター** は、アプリが送る名前（ほとんどの場合 `HR`）にする必要があります。一覧にない名前の場合は **直接入力** を選びます。
- 心拍数が 30 BPM 未満のときや、60秒間まったく変わらないときは信号がないものとして扱い、その間は動きで汗をかきます。
- 最大心拍数の 50 % 未満では汗をかきません。汗が少ないままの場合は、**最大心拍数** を確認してください。
- 設定を変えた後は **［インストール / 更新］** を押してください。**FX に適用** では反映されません。

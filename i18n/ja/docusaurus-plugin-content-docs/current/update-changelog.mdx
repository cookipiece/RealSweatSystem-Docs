# 更新・変更履歴

## 最近のパッチノート

最近のユーザー向けの変更をまとめています。バージョンを選ぶと詳しい内容へ移動します。

- **[v2.0.0 — 最新](#v200)**
  - **新しい汗の見た目:** 肌の汗を一から作り直し、画像で選ぶ2つのスタイル **アニメ（標準）** と **リアル** を用意しました。**水滴の立体感** も作り直し、両方のスタイルでカメラの近くの水滴が実際に肌から盛り上がります。
  - **新しい Setup ウィンドウ・体の湯気・落下する滴・はね:** 最初の画面には必要な項目だけを置き、表現と負荷もそこで選びます。体の湯気は広い範囲から淡く立ちのぼり、落下する滴とはねを描き直し、床の濡れ跡は床を暗くするだけになりました。
  - **軽くなりました:** 他の人の初回読み込みの停止が v1.1.3 より約3分の2短くなり、既定の導入の汗 100 % の負荷は v1.1.3 の約半分になりました。
- **[v1.1.3](#v113):** Steamをオフにするとセットアップが失敗する問題を修正し、選択を外したエフェクトのパーティクルや専用FXが残らないようにしました。
- **[v1.1.2](#v112):** 表面の汗を非表示にする際、空のマテリアルスロットではなく専用の非表示マテリアルを使用します。
- **[v1.1.1](#v111):** 重複した参照確認を減らし、No Tessの一部の削除処理を改善し、段階別の診断ログを追加しました。
- **[v1.1.0](#v110):** 任意の3Dパーティクル、Custom Steam Point、表示マスク、実験的な追加メッシュに対応しました。
- **[v1.0.2 — 2026-07-27](#v102--2026-07-27):** Write Defaultsの自動判定と最終ビルドでの補正を追加し、MMD再生中に表情やリップシンクが止まる場合を減らしました。
- **[v1.0.1 — 2026-07-27](#v101--2026-07-27):** VRCFT、フェイストラッキング、Write Defaults OFFのアバターとの互換性を改善し、顔のアニメーション、汗の操作、自動モードを一緒に使えるようにしました。

## 安全な更新手順

1. アバターとプロジェクトを、プロジェクトの外にバックアップします。
2. 現在導入している Real Sweat System のバージョンを確認します。
3. 所有しているBaseとEffectsのモジュールを、すべて同じ新しいバージョンで既存ファイルへ上書きインポートします。インポートの順番は問いません。
4. 旧バージョンを先に削除したり、`RealSweat` オブジェクトや `Assets/CookiTools/Generated` を削除したり **しないでください**。
5. `CookiTools → RealSweatSystem → Setup／Uninstall` を開き、アバターごとに **［インストール / 更新］** を一度押します。**FX に適用だけではこの更新は行われません。**
6. シーンを保存し、Consoleを確認して、アップロード前にPlay Modeとアバタービルドで確認します。

バージョンが混ざっていると、Setup ウィンドウが同じバージョンで再インポートするよう知らせ、インストールを止めます。

1.x から v2.0.0 への更新では、先に[1.x からの更新方法](./quick-start.mdx#updating-from-1x)を読んでください。以前の汗マテリアルの見た目の値が新しい既定値になり、最初に **［インストール / 更新］** を押したときにアバターごとの新しいデータが保存されます。

削除、クリーンな再導入、Base・Effects・Full Packの構成変更は、[削除・再導入・Module構成を変更する](./troubleshooting.mdx#uninstall-reinstall-or-change-modules)に従ってください。

## v2.0.0 {/* #v200 */}

このアップデートは、Base Module、Effects Module、Full Packに共通で含まれるCoreに適用されます。肌の汗の見た目、Setup ウィンドウ、体の湯気を新しくしました。更新するには[1.x からの更新方法](./quick-start.mdx#updating-from-1x)に従ってください。

### 主な変更点

- **画像で選ぶ2つの汗のスタイル:** Setup ウィンドウの最初の画面で、2枚の画像のどちらかをクリックします。**アニメ（標準）** は明るいハイライトのある、はっきりしたアニメ調の水滴で、遠くからもよく見えます。**リアル** は光と周りを映す小さな水滴が多く、より控えめで、遠くからは濡れたツヤに見えます。スタイルはアバターごとに1つで、後から Tuning の **基本設定 > 汗のスタイル** で変更できます。
- **両方のスタイルで立体的な水滴:** 水滴の立体感（テッセレーション・高負荷）を作り直しました。近くでは、付着した水滴と流れ落ちる水滴が実際に肌から盛り上がり、横から見ても丸く見えます。アニメでもリアルでも動作します。既定の精度では約 0.7 m より離れると立体感なしと同じ描画になります。
- **新しい肌の汗の見た目:** 付着した水滴と流れ落ちる水滴、汗腺の水滴、流れ跡と流れたばかりの跡のツヤ、薄い濡れ膜、遠くからの見え方を一から作り直しました。流れ跡は v1.1.x のようにほぼまっすぐ下へ流れます。アニメでは流れ落ちる水滴の頭が丸くなり、流れ跡がなめらかにつながるため、流れ跡と水滴が切れて見えません。リアルでは、流れ落ちる水滴が通り道から取り込んだ小さな水滴がすぐ後ろで戻ることはなく、流れ跡が乾くにつれて戻ります。
- **近くでもはっきり見える水滴:** 水滴が少し大きくなり（水滴サイズ 1.6）、きらめきが大きく明るくなりました。きらめきはマテリアルインスペクターのクイック設定の **きらめきの大きさ** と **きらめきの強さ**（どちらも 1.5）で変えられ、1 に下げると落ち着いた見た目になります。
- **汗の流れ:** マテリアルインスペクターのクイック設定に、急な肌を流れ落ちる水滴の数と距離を決めるスライダーが加わりました。既定の 1 が各スタイルの標準の見た目で、0 では水滴がその場にとどまり、2 ではほとんどが流れ落ちます。
- **暗い肌:** 水滴が灰色の円盤ではなく明るくきらめくようになり、膜と流れ跡のぎらつきが減りました。白い肌、普通の肌、日焼けした肌の見た目は変わりません。
- **体に合わせた水滴サイズ:** 胴と脚のヒューマノイドのボーンの長さで測ります。バウンディングボックスは使わないため、髪、帽子、アクセサリー、姿勢に左右されません。どのアバターのどのメッシュでも（cm でも m でも）水滴は体に対して同じ大きさで、アバターの倍率に合わせて変わります。ヒューマノイドではないアバターは視点の位置を使います。
- **新しい Setup ウィンドウ:** 最初の画面には状態、汗を付ける場所、インストール内容、スタイルの画像、**表現** の画像（**基本** / **立体（高負荷）**）、**負荷** のボタン（**低負荷（推奨）** / **標準**）、自動モード感度、**［インストール / 更新］** があり、ほかのオプションは **詳細設定** にあります。**立体（高負荷）** は水滴の立体感、3Dパーティクル、水滴のはねを一緒にオンにし、その下に **最初からオン** が表示されます。新しく導入するときは **基本** で始まり、はねはオフです。**軽量** は **詳細設定 > 品質・負荷** で選びます。タブはインストール / トラブルシューティング / 削除で、結果は押したボタンのすぐ下に表示され、時間がかかる段階ではプログレスバーが出ます。
- **新しい体の湯気:** 1点から大きな塊が上がる代わりに、にじんだ淡い湯気がその周りの広い範囲（胸の上側、肩のライン、太ももと足首の前側）からゆっくり立ちのぼります。歩くと体についてきて、深度テクスチャのないワールドでも見え、暗いワールドで光らず、パーティクルも少なくなりました（既定の導入で最大 168 → 95）。
- **新しい落下する滴・はね:** 落ちながら伸びる小さな滴と、丸い小さな粒が短く飛ぶはねです。両方のスタイルと、2D・3Dパーティクルのどちらにも適用されます。2Dにもはねが付き、3Dの王冠形のリングはなくなりました。床の濡れ跡は 1.1.3 と同じにじんだ形で、床を暗くするだけです。
- **3Dの体の湯気・吐息のパフォーマンスランク:** 見た目はそのままで、VRChatのパフォーマンスランクの Mesh Particle Active Polys が大きく減りました（既定の導入の湯気・吐息で 96,000 → 92）。
- **大幅に軽くなりました:** 他の人がこのアバターを初めて読み込むときのシェーダーコンパイルによる停止が、v1.1.3 より約3分の2短くなりました。既定の導入の汗 100 % の負荷は v1.1.3 の約半分になり、汗 0 % の負荷も大きく減りました。[測定値](./performance.mdx#measured-load)を確認してください。
- **レンダーキュー 2350:** 肌の汗のレンダーキューが 2350 になりました（v1.1.x は 2455）。そのため、ボディに重ねて描く影・デカールのマテリアルと同じキューにならず、Cutout の衣装や髪が汗を覆います。ボディのレンダラーに 2350 以上の不透明・Cutout マテリアルがあると、Setup が 2349 に下げるかどうかを一度だけ確認し（推奨）、削除のときに元のキューに戻します。
- **画面コピーの分離:** 2.0.0 の汗は新しい名前の画面コピーから肌を読むため、同じ画面の v1.1.x の汗と混ざりません。2350 以外のキューで描画する汗は「(Late Queue)」シェーダーを使います。
- **Light Limit Changer に追従:** Light Limit Changer（LLC）でアバターの明るさ（明るさの下限・上限）を変えると、肌の汗も同じ割合で追従します。ボディの肌が lilToon または Poiyomi のときに動作し、設定は不要で、パラメーターも増えません。

### その他の変更

- **汗の品質**（以前の「全体の汗量」）で3つの段階から選びます: 標準、低負荷（推奨・既定）、軽量。肌の汗の量は3段階とも同じになりました（30 % で 0.30、100 % で 1.00）。そのため、低負荷や軽量を使っていたアバターは v1.1.x より汗が多く見えます。
- アバターごとに模様番号が付くため、同じアバター2体が同じ場所に汗をかくことはありません。
- 新しい見た目には Rest データが必要です（Setup がベイクします）。Rest データがないマテリアルは、マテリアルインスペクターと Tuning が知らせます。
- **ミラーでも汗を高品質** がオフ（既定）のとき、ミラーでは汗腺の小さな水滴を省き、水滴の立体感も盛り上がりません。
- **相手側を低負荷** で、他の人に見える肌の汗がどの段階でも軽くなりました。体の湯気は数を減らさず、濃さ 0.6 倍で見えます。
- マテリアルインスペクターは新しい見た目が読む値だけを表示します。プリセットは **標準の見た目に戻す** ボタンひとつになりました。
- 削除した機能: ミルクモード、ボディノーマルマップによる濡れ表現、光学 LUT、フローガイドマップ、Rest パターンの回転、手動 Rest 軸モード、VRC Light Volumes 対応。更新すると「VRCライトボリューム」のメニュートグルと 1bit のパラメーターが外れます。古い値はマテリアルに非表示で残り、使わなくなったテクスチャはアバタービルドでアップロードされません。
- ゲーム内メニュー名: 息 → 吐息、湯気 → 体の湯気、表面の汗を非表示 → 肌の汗を非表示。パラメーターと保存された値は変わりません。
- 削除の後、マテリアルの並びがプレハブと同じに戻ったプレハブインスタンスには、マテリアルのオーバーライドが残りません。
- **3Dパーティクルの体の湯気:** 段階ごとの量は v1.1.3 と同じです（低負荷と軽量では標準の 0.65 倍）。一部のテスターだけに配布した 2.0.0 の試験版で湯気の塊が間違った場所に描かれていた問題（長い筋や色のむら。v1.1.x にはありませんでした）も修正しました。3Dパーティクルを使うアバターは、**［インストール / 更新］** または **FX に適用** を一度押してから、もう一度アップロードしてください。
- **深度テクスチャがないときの3Dパーティクルの体の湯気・吐息:** カメラに深度テクスチャがないワールド（リアルタイムの影を落とすディレクショナルライトがないワールドなど）でも消えなくなりました。
- **リアルの体の輪郭:** 薄い膜に映る空が輪郭に近づくほど明るくなることはなくなり、体の輪郭に沿った明るい線は半分以下の明るさになりました。アニメは変わりません。
- **落下する滴・床の濡れ跡・はね:** 既存の導入は **［インストール / 更新］** を一度押すと新しい見た目になります。**落下水滴の最大数（システムごと）** の既定値は64から12に変わり、強い動きの滴はその3分の2の8個までを使います。64のままの導入だけが変わります。v1.1.x の2Dパーティクルの導入は、更新してもはねなしのままです。はねを使う場合は、**［インストール / 更新］** を押す前に **水滴のはね** をオンにするか、**立体（高負荷）** を選んでください。

### 既知の制限

- 有効な Rest データがないと汗は描かれません。たとえば Setup 前のマテリアルや、ベイク後に変わったメッシュです（次のビルドで再ベイクされるまで）。
- 水滴の立体感は近くで GPU 負荷が増える高負荷オプションのままです。
- 汗 0 % と汗の表示オフは完全に無料ではありません。屈折のための画面コピー（GrabPass、約 +0.05 ms）が残ります。負荷がなくなるのは肌の汗を非表示だけです。
- 相手側を低負荷: 面の向きが切り替わる所（胴の横や腕など）で、他の人の画面では水滴の下の端がまっすぐ切れて見えることがあります。まれで、小さな差です。
- リアルは会話距離、暗いワールド、反射プローブのないワールドでアニメより目立ちにくくなります。折れ目（おへその上など）では小さな水滴が2つに分かれて見えることがあり、水滴どうしが実際に合わさることはありません。リアルの軽量は、リアルの低負荷・標準と水滴の並びが少し違います。
- 服に付く RealRain 自身のリアルな雨粒は、RealRain のアップデートで提供されます。RealRain が肌に付ける雨は、すでに汗のスタイルに従います。

v2.0.0 に以前の見た目は含まれません。必要な場合は v1.1.3 を使い続けてください。更新後に戻すには、更新前に作ったバックアップを使ってください。

## v1.1.0 {/* #v110 */}

### v1.0.0～v1.0.2から更新する場合

中間バージョンを経由する必要はありません。現在、v1.0.0～v1.0.2 の導入は、[同じ手順](./quick-start.mdx#updating-from-1x)で v2.0.0 へ直接更新できます。次の v1.1.0 の移行内容は、引き続き適用されます。

- 古いRealSweat生成データを検出すると、閉じることのできるSceneビュー通知を表示します。準備ができたら Setup ウィンドウで **［インストール / 更新］** を押してください。
- 既存の感度・汗の品質・自動反応・主なトグル・湯気位置は基本的に維持されます。生成済みコントローラー・メニュー・クリップ・パーティクルを直接編集している場合、Setupで再生成される可能性があるため別途バックアップしてください。
- 床の濡れ跡の `Pooling Chance` が以前の既定値 `0.25` と完全に一致する場合、新しい既定値 `0` へ移行します。それ以外のカスタム値は維持されます。
- 従来の体の湯気のミラー設定は、見た目を維持するため `Full` のまま引き継がれます。新規導入の既定値は `Low` です。
- 3DパーティクルとBodyの汗のミラーフル品質は自動的に有効になりません。濡れた肌の光沢も、更新時は導入済みマテリアルの状態を引き継ぎます。
- BaseとEffectsの旧版・新版を混在させた場合、Setupとビルドで処理を停止します。Uninstallは不要です。

### 新機能と改善

- 既定の軽量2Dパーティクルを維持しながら、吐息・体の湯気・落下水滴に任意の高負荷3D品質を追加
- 3D落下水滴に任意の衝突スプラッシュを追加
- 3D落下水滴と体を動かした時に飛び散る滴の既定サイズを、元のサイズより8%小さく調整

- R/G/B/A、反転、強度、タイリング、オフセットに対応した、Body表面の最終表示マスクを追加
- Tess／No Tessの元Shaderと **見た目をリセット** の細い濡れ跡の初期値を`0`へ統一。見た目をリセットした際は、水滴サイズとPattern密度も管理対象および連動Particle設定へ反映。v2.0.0 では、プリセットは **標準の見た目に戻す** ボタンひとつになりました。
- 実験的: 複数のBody Material Elementと、追加 `SkinnedMeshRenderer` 対象に対応
- Tuningの状態表示、**追加対象を管理...**、修復・削除の案内、生成スロットの破損時のビルド停止を追加
- ポイントごとの設定と左右ミラーペアを持つCustom Steam Pointを追加
- 保存・同期される任意の **体の湯気・吐息の濃さ** ラジアルを追加。既定OFFで、0%が不透明度0.1倍、50%が従来の見た目を維持する1.0倍、100%が1.5倍です。不透明度だけを変え、0%でもエフェクトはオフにならず、パーティクル数と処理負荷は減りません。
- 任意の **一人称視点で自分の息を表示** を追加
- 床の濡れ跡の3×3バリエーション、衝突直後の短い広がり、重なりの穏やかな濃さ、乾き方を調整
- Body自動検出、パラメーター衝突の検査、最終Rest／Tangentの検証、d4rkAvatarOptimizerの保護、Module混在の停止、Setup失敗時のロールバックを強化
- ビルド後半のSubmesh `baseVertex` 変更に対応する互換処理を追加し、確認済みのModular Avatar Shape Changer Delete構成で表面の汗が破片状に崩れる問題を防止。すべてのメッシュ変更ツール／組み合わせとの完全互換を保証するものではありません
- Bodyメッシュの内蔵頂点カラーによってパーティクルが表示されない場合に使用する任意の落下水滴互換設定を、Setup ウィンドウの **トラブルシューティング** タブに追加。標準動作は変更されず、落下する滴と体を動かした時に飛び散る滴だけに適用
- 任意の3D水滴Particle Shaderから未使用の照明／Soft Particle Variant軸を削除。見た目とGPU Instancingは変更しません
- `汗オン` を `汗の表示` へ変更し、エフェクトの操作を独立したサブメニューへ移動

### v1.1 の重要な制限

- 実験的な追加対象は `SkinnedMeshRenderer` だけに対応し、設定した対象ごとに汗マテリアルと描画負荷が1つずつ増えます。
- 各対象には、読み取り可能なMeshデータ、有効なSubMesh・Material・Tangent、固有のAnimationパス、共有されていない生成汗マテリアル系統が必要です。
- 生成されたRealSweatのマテリアルやRendererスロットを削除、空欄化、移動、置換、統合しないでください。**追加対象を管理...** と **［インストール / 更新］** で対象を修復または削除してください。
- フェイストラッキング・表情・メッシュ統合・置換・最適化の全組み合わせは保証されません。目や唇周辺のTessは避けてください。
- 床の濡れ跡は落下する滴の衝突サブエフェクトなので、落下する滴を有効にしておく必要があります。
- 有効なCustom Steamのスロットは最大4つで、左右ミラーペアは2つを使います。内蔵／Customを合わせて12個が上限で、発生量ウェイトが `4.0` を超える場合は同じ比率で下げます。
- 3Dパーティクルとミラーフル品質はGPU負荷を増やします。3Dの体の湯気の `Low` は現在 `Full` と同じ負荷です。ミラーのコストを最も低くするには `Hidden` を使います。

現在の同期パラメーターのコストは、[技術仕様](./technical-specifications.mdx#synced-parameters)を確認してください。

## v1.0.2 — 2026-07-27 {/* #v102--2026-07-27 */}

### Compatibility

- v1.0.1で、全FXがWD ONのアバターにRealSweatのOutputレイヤーだけがWD OFFで追加され、ON/OFF混在となることで、一部のMMDダンス中に表情・リップシンクが動作しない問題を修正
- アバターFXのWrite Defaults構成を判定する **Auto Detect（推奨）** を追加
- RealSweat以外のFX StateがすべてWD ONの場合、生成するRealSweatレイヤーもすべてWD ONへ統一
- WD OFF、ON/OFF混在、または判定不能の場合はv1.0.1のDriver ON / Output OFF互換構成を維持
- NDMFで最終統合されたFXをビルド時に再確認し、検出結果に合わせてRealSweatのWD構成を調整

:::note[過去の更新案内]
当時v1.0.1からv1.0.2へ更新する際には全体Setupが必要でした。現在はv1.0.0／v1.0.1からも中間バージョンを経由せず、[1.x からの更新方法](./quick-start.mdx#updating-from-1x)でv2.0.0へ直接更新できます。
:::

:::caution[MMDワールド]
WD OFFまたはON/OFF混在のFX構成では、ワールド側のFXレイヤー制御方式によってMMD再生中の表情やReal Sweat Systemが正しく動作しない場合があります。詳しくは[対応環境・互換性](./compatibility.mdx#mmd-world-compatibility)を確認してください。
:::

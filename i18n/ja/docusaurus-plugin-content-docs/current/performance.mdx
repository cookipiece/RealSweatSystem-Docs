# パフォーマンスガイド

負荷は主に、画面に映る汗の面積、水滴密度、立体機能、ミラーによる再描画、Effectsの表示量で変化します。

## 優先して調整する順序

1. Setupで3Dパーティクル品質を選んでいる場合は、軽量な2D品質へ戻してSetupを再実行します。
2. 搭載している場合は **水滴の立体感（テッセレーション / 高負荷）** をOFFにします。
3. ミラーでもBodyの汗をフル品質で表示している場合はOFFにし、体の湯気は`Low`または`Hidden`を選びます。
4. 全体の汗量とパターン密度を下げ、使用しない落下水滴、床の濡れ跡、吐息、湯気をOFFにします。
5. Base Moduleを使用している場合は **相手側を低負荷** をONにします。
6. 必要に応じて **自分にだけ表示**、または **表面の汗を非表示** を使用します。

## Tess / No Tess

立体機能を搭載した構成では、インゲームメニューから立体表現を切り替えられます。通常プレイや多人数環境ではOFF、撮影時など立体感を優先する場面ではONを目安にしてください。

立体機能を搭載していない構成ではNo Tessのみが導入され、**水滴の立体感（テッセレーション / 高負荷）** のメニュー項目は表示されません。

## Mirror

ミラーではアバターが別のカメラでも描画されるため、負荷が増えます。**ミラーでもBodyの汗をフル品質で表示**は既定OFFの高負荷オプションです。体の湯気は`Full / Low / Hidden`を選べます。2Dの`Low`はぼかし処理を省略して弱く表示しますが、3Dの`Low`は現在`Full`と同じ見た目・負荷です。最小負荷は`Hidden`です。

## 相手側を低負荷

**相手側を低負荷** はBase Module導入時に表示されます。自分の表示を維持しながら、相手側をNo Tess + Liteへ切り替えます。3D品質では相手側の落下水滴を50%へ減らし、強い動きによる追加水滴を停止し、体の湯気／Custom Steamを25%へ低減します。

## Effects

Effects Module導入時は、独立した **エフェクト** サブメニューから全Effects、または各Effectを個別にOFFにできます。3D品質、衝突スプラッシュ、追加対象の落下水滴、Custom Steam Pointは表示コストを増やします。追加対象は対象ごとに専用マテリアルとドローコールも追加します。

:::info[FPSについて]
FPSはCPU、GPU、VRChatの同期方式、ミラー、ワールド、他アバターによって変化します。特定GPUでのFPS値を保証するものではありません。
:::

# パフォーマンスガイド

Real Sweat System の負荷は、汗の品質の段階、汗が画面を占める広さ、水滴の立体感、ミラー、パーティクルエフェクト、描画されるアバターの数によって変わります。

v2.0.0 は v1.1.3 より大幅に軽くなりました。他の人がこのアバターを初めて読み込むときのシェーダーコンパイルによる停止が約3分の2短くなり、既定の導入の汗 100 % の負荷は v1.1.3 の約半分になり、汗 0 % の負荷も大きく減りました。

## おすすめの調整順

1. **3Dパーティクル** をオフのままにし、既定の軽量な2Dパーティクルを使います。
2. 表現を **基本** のままにするか、水滴の立体感を導入している場合はゲーム内で **水滴の立体感（テッセレーション / 高負荷）** をオフにします。
3. **標準** ではなく **低負荷（推奨）** を使います。**軽量** は少し多く省きますが、GPU 時間は低負荷とほぼ同じです。
4. 任意のエフェクトを、体の湯気から順にオフにします。
5. ミラーの湯気が不要なら、**ミラー内の体の湯気** を **Hidden** にします。
6. **ミラーでも汗を高品質** はオフのままにします。
7. 他の人のために **相手側を低負荷** を有効にします。
8. 相手側に見せる必要がない場合は **自分にだけ表示** を使います。
9. 肌の汗がまったく不要な場合は **肌の汗を非表示** を使います。負荷はありません。

変更は1つずつ行い、同じカメラ距離とミラーの状態で比べてください。

## 負荷（測定） {/* #measured-load */}

RSS のない同じアバターに対するアバターの GPU 時間の倍率です（小さいほど軽い）。1台の PC（RTX 5090、D3D11、2880 × 2880、MSAA なし）で、ミルティナが画面の 28 %（全身）/ 69 %（上半身）を占める状態で、100 フレーム × 7 回を交互に測った中央値です。GPU が違えば倍率も変わるため、行どうしで比べてください。特に書いていないものはアニメです。

| 全身 / 上半身 | v1.1.3 | v2.0.0 |
|---|---|---|
| 既定の導入（低負荷）、汗 100 % | 5.04 倍 / 4.44 倍 | 2.68 倍 / 2.36 倍（リアル 2.61 倍 / 2.27 倍） |
| 標準、汗 100 % | 5.25 倍 / 4.55 倍 | 3.59 倍 / 2.98 倍（リアル 3.90 倍 / 3.23 倍） |
| 水滴の立体感、低負荷、汗 100 % | 6.58 倍 / 5.33 倍 | 3.57 倍 / 2.93 倍 |
| 相手側を低負荷で他の人に見える既定の導入 | 3.53 倍 / 3.22 倍 | 2.45 倍 / 2.18 倍 |
| 汗 0 % | 2.10 倍 / 2.09 倍 | 1.18 倍 / 1.10 倍 |
| 肌の汗を非表示 | 1.00 倍 / 1.00 倍 | 1.00 倍 / 1.00 倍 |

- アニメの標準は v1.1.3 のパブリックプリセット（3.21 倍 / 2.86 倍）とほぼ同じで、リアルの標準は少し重くなります。
- 初回読み込み（他の人のシェーダーコンパイルによる停止、同じ PC）: v1.1.3 は約 0.81 秒、v2.0.0 は約 0.27 秒です。
- アバターは選んだスタイルのシェーダーだけを使うため、他の人の初回読み込みはスタイルによらずほぼ同じです。
- 汗 0 % と汗の表示オフは完全に無料ではありません。屈折のための画面コピー（GrabPass、約 +0.05 ms）が残ります。負荷がなくなるのは肌の汗を非表示だけです。

## 水滴の立体感（Tess と No Tess）

水滴の立体感は任意の機能で、既定では導入されません。導入すると、アバターメニューで **水滴の立体感** をオン／オフできます。

近くでは GPU 負荷が増えます。既定の精度（簡素）では、約 0.7 m より離れると立体感なしと同じ描画になります（均衡は約 1.5 m、精密は約 2.2 m から）。水滴の立体感がオフのときは、見えないテッセレーション処理を続けるのではなく No Tess マテリアルを使います。通常のプレイではオフにし、近くでの形が役に立つときだけオンにしてください。

この表面の機能は、吐息・落下する滴・体の湯気をメッシュパーティクルに変える **3Dパーティクル** とは別の機能です。

## 汗のスタイル

リアルのシェーダー命令数はアニメより少しだけ少なくなります（標準で 3445 対 3506）。GPU 時間はアニメとほぼ同じで、近くで胴全体が画面を埋めるときに最大約 14 % 増えます。水滴の立体感をオンにすると、標準ではアニメの立体感の約 1.07 倍、低負荷では約 0.95 倍です。

## ミラー

ミラーは別のカメラでアバターを描くため、見えるシェーダーとパーティクルの処理が大きく増えることがあります。同じアバターで次を比べてください。

- ミラーなし
- ミラーあり
- 通常の会話距離
- Bodyが画面の大部分を占める接写

大きく下がる場合は、まず水滴の立体感をオフにし、ミラーでも汗を高品質をオフのままにし、ミラー内の体の湯気をHiddenにしてから、汗の品質を下げてください。

**ミラーでも汗を高品質** は既定でオフです。オフのときはミラーで汗腺の小さな水滴を省き、水滴の立体感も盛り上がりません。オンにするとミラーでも通常の画面と同じに描くため、ミラーのGPU負荷が増えます。

体の湯気のミラー表示は Full、Low、Hidden から選びます。2Dの`Low`はパーティクル数を変えずに、ミラー内の湯気を`Full`の0.8倍の濃さで描きます。3Dの`Low`は現在`Full`と同じ負荷です。ミラーのコストを最も低くするには`Hidden`を使います。

## 相手側を低負荷

**相手側を低負荷** は、自分の画面の表現を保ったまま、他の人に見える処理を減らします。ユーザーが別のパフォーマンス用マテリアルをアップロードする必要はありません。

相手側ではNo Tessで、汗腺の小さな水滴なしに描き、低負荷と軽量では残り滴とアニメの膜の細い線も省き、面の向きが切り替わる所の処理を減らします（相手側の GPU 時間は低負荷で約 4~8 %、標準で 23~29 % 減ります）。相手側の体の湯気／Custom Steamは数はそのままで濃さを0.6倍にします（3Dの体の湯気は数が25%）。3Dパーティクルでは、相手側の落下する滴を50%へ減らし、強い動きによる追加水滴も停止します。自分側の品質は変わりません。

## レンダーキューと画面コピー

2.0.0 の汗は画面コピー（GrabPass）から肌を読みます。2350 以外のキューで描画する汗（そのままにしたボディのキュー、Cutout の後の他のメッシュ、手動のキュー）は「(Late Queue)」シェーダーを使い、描画するときに画面を個別にコピーします。そのぶん画面コピーが 1 回増えます。詳しくは[対応環境・互換性](./compatibility.mdx#render-queue-and-shadows)を確認してください。

## 複数の汗の対象

選択した各Body Elementや実験的な追加Rendererは、それぞれ汗のマテリアルと描画を使います。追加メッシュでは、個別のRestデータ、シェルアセット、任意の落下する滴も増えることがあります。特に大きなメッシュや多くのBlendShapeを持つアバターでは、必要な対象だけを追加してください。

## パーティクルの操作

Effects Moduleを導入している場合は、次を開きます。

**汗 → エフェクト**

不要なエフェクトだけをオフにするか、**全エフェクト** でまとめて操作します。

- はねを導入するとパーティクルシステムとマテリアルスロットが2つずつ増えるため、VRChat のパフォーマンスランクが一段階下がることがあります（例: マテリアルスロット 15 → 17 で Medium → Poor）。
- 新しい体の湯気はパーティクルが少なくなりました（既定の導入で最大 168 → 95）が、湯気が広くなった分、近くでは描く量が増えます。
- 3Dの体の湯気・吐息は、VRChatのパフォーマンスランクの Mesh Particle Active Polys が大きく減りました（既定の導入の湯気・吐息で 96,000 → 92）。

:::info[FPSについて]
FPSはCPU、GPU、VRヘッドセットのモード、ワールド、ミラー、見えているすべてのアバターによって変わります。1つの設定変更で特定のFPS向上を保証することはできません。
:::

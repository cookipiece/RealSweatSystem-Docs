# 購入認証

各PCは、BOOTHの注文番号（Gumroadでご購入の場合はGumroadのライセンスキー）で一度認証します。認証ウィンドウは `CookiTools → RealSweatSystem → Purchase Activation` から開きます。

1件の注文（またはGumroadでの購入）につき、PCを同時に3台まで認証できます。BOOTHでのみ販売している Game & App Integration & Distribution License は10台です。1件の注文で新しく登録できるPCは30日に5台までです（Game & App Integration & Distribution License は12台）。

インターネットは認証時と、自動更新のため3週間に一度以上必要です。アバターのビルドやアップロードには不要です。

認証の方法、PCの解除、ギフト、エラーコードは、下のリンク先のページで案内しています。

- **詳しい案内:** [購入認証ガイド](https://cookistudio.com/license/?lang=ja)
- **個人情報:** [プライバシーポリシー（購入認証）](https://cookistudio.com/license/privacy?lang=ja)

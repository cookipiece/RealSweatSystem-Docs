# 購入認証

各PCは、注文番号で一度認証します。

1つの注文で、最大3台のPCを認証できます（ゲーム・アプリ向けライセンスは10台）。

インターネットは認証時と、自動更新のため30日に一度以上必要です。アバターのビルドやアップロードには不要です。

認証の方法、PCの解除、ギフト、エラーコードは、下のリンク先のページで案内しています。

- **詳しい案内:** [購入認証ガイド](https://cookistudio.com/license/?lang=ja)
- **個人情報:** [プライバシーポリシー（購入認証）](https://cookistudio.com/license/privacy?lang=ja)

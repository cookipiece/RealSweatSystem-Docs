# パッケージガイド

| パッケージ | 主な機能 | 向いている用途 |
|---|---|---|
| **Sweat Base Module** | 2つのスタイル（アニメ / リアル）の肌の汗、任意の水滴の立体感、マスク、Restデータ、ミラー・描画順の設定、相手側を低負荷、肌の汗を非表示 | 肌の汗が必要な場合 |
| **Sweat Effects Module** | 落下する滴とはね、床の濡れ跡、吐息、体の湯気とCustom Steam Point。2Dまたは任意の3Dパーティクル | 周囲のパーティクルエフェクトが必要な場合 |
| **Full Pack (Base + Effects)** | Base Module + Effects Module | 連動した汗表現をすべて使う完全構成 |

各Moduleには、必要な共通 **Core** ファイルが含まれています。Coreは単体で使う製品ではありません。v2.0.0 のアップデートはCoreに適用されるため、すべてのパッケージに適用されます。

## Sweat Base Module

Base Moduleは、メインのBody Rendererで選択したMaterial Elementに汗を追加します。顔メッシュなどの別 `SkinnedMeshRenderer` にも **実験的機能** として汗を導入できます。RestデータはElementごとではなくMeshごとに作成されます。同じRenderer内のElementは同じMeshの対応を共有し、別のRendererには個別のRestデータが作成されます。設定した汗のElementごとに、Materialと描画が1つずつ追加されます。

汗のスタイル（**アニメ** または **リアル**）はアバターごとに1つです。ボディと他のメッシュはすべて同じスタイルを使います。手動モードと自動モードは同じ汗 % の値を共有します。水滴の立体感を導入した場合、ゲーム内メニューで水滴の立体感のすべての汗スロットをまとめて切り替えます。

## Sweat Effects Module

Effects Moduleは、選択したBody Meshを放出元として使います。BodyのMaterial、Body Mesh、Restデータ、水滴の立体感の構成は **変更しません**。既定では従来の軽量な2Dパーティクルを使います。高負荷の **3Dパーティクル** は、Setup ウィンドウの最初の画面の **表現** で **立体（高負荷）** を選ぶか、**詳細設定 > 品質・負荷** でオンにします。

落下する滴とはねは、汗のスタイル（アニメ・リアル）に従います。スタイルを選べるのは Base Module を導入しているときだけです。Effects Module だけのときは汗のスタイルの選択がなく、滴はアニメの見た目になります。

エフェクトのメニューは、このModuleを導入した場合だけ表示されます。

## Full Pack (Base + Effects)

Full Packは完全構成です。肌の汗とエフェクトが同じ汗 % の値に反応するよう、両方のModuleを同じバージョンで導入してください。

アバターメニューは、導入したModuleから作られます。

- **自分にだけ表示** は、どのパッケージ構成でも表示されます。
- **相手側を低負荷** は、Baseを導入した場合に表示されます。
- **エフェクト** は、Effectsを導入した場合に表示されます。
- **水滴の立体感（テッセレーション / 高負荷）** は、水滴の立体感を導入した場合だけ表示されます。

## 導入・更新・パッケージ構成の変更

- 新しく導入する場合は、[5分クイックスタート](./quick-start.mdx)に従ってください。
- BaseとEffectsを両方使う場合は、同じバージョンにそろえてください。バージョンが混ざっていると、Setup ウィンドウが同じバージョンで再インポートするよう知らせ、インストールを止めます。
- BaseまたはEffectsをFull Packへ拡張するには、足りないModuleを同じバージョンでインポートしてから **［インストール / 更新］** を一度押してください。
- 1.x から更新するには、所有しているModuleをすべて同じ v2.0.0 で **既存ファイルへ上書き** インポートし、アバターごとに **［インストール / 更新］** を一度押してください。旧バージョンを先に削除しないでください。**FX に適用だけではこの更新は行われません。** 詳しい手順は[1.x からの更新方法](./quick-start.mdx#updating-from-1x)を確認してください。
- システムを削除する場合や、1つのModuleだけの構成へ戻す場合は、[削除・再導入・Module構成を変更する](./troubleshooting.mdx#uninstall-reinstall-or-change-modules)に従ってください。

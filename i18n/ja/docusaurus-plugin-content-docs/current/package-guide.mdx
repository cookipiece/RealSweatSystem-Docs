# パッケージガイド

購入した構成によって、Setupとアバターメニューに表示される機能が変わります。導入していないModuleの項目は表示されません。

各Moduleには動作に必要な共通 **Core** が含まれます。Coreは別に購入または操作する製品ではありません。

## Sweat Base Module

選択したBody Rendererの1つ以上のMaterial Elementへ肌表面の汗を追加します。実験的機能として、顔などの追加 `SkinnedMeshRenderer` も同じSetupで管理できます。Manual ModeとAuto Modeは同じSweat %を共有します。

立体機能を搭載しない場合は、各対象にNo Tess Materialを1つだけ導入します。搭載するとTessとNo Tessを同梱し、インゲームの **水滴の立体感（テッセレーション / 高負荷）** でTess対応として管理されるすべての汗Slotをまとめて切り替えます。各Slotで同時に描画されるのはTess／No Tessのどちらか1つです。

Baseを導入すると **相手側を低負荷**、**表面の汗を非表示**、**VRC Light Volumes** が表示されます。表示マスクは表面の水滴・濡れ膜・光沢・屈折・暗化・Tess変位をまとめて隠しますが、Effectsの落下水滴には影響しません。

## Sweat Effects Module

選択したBody Meshを、落下する滴と湯気などの放出元として使用します。そのためEffectsだけを導入する場合もBody Meshの指定が必要です。

Effects-only SetupはBody Material、Body Mesh、Rest Vertex Data、テッセレーション構成を変更しません。肌表面の汗も追加しません。

Effectsを導入すると独立した **エフェクト** サブメニューと、選択した個別Effectが表示されます。従来の軽量2Dまたは任意の高負荷3D品質をSetupで選択できます。Custom Steam Point、一人称の吐息、湯気・吐息の濃さラジアルも必要な場合だけ導入します。

## Full Pack (Base + Effects)

Full PackはBaseとEffectsを組み合わせた完全構成です。肌表面の汗、落下する滴、床の濡れ跡、息、湯気が同じSweat %へ連動します。

Full PackではBase PackageとEffects Packageの両方をImportし、必ず同じ製品バージョンを使用してください。

## Setup構成によるメニュー差

- 全構成: **自分にだけ表示**
- Base導入時: **表面の汗を非表示**、**相手側を低負荷**、**VRC Light Volumes**
- Effects導入時: 独立した **エフェクト** サブメニューと選択したEffects
- 立体機能を搭載した場合のみ: **水滴の立体感（テッセレーション / 高負荷）**
- Setupで選択した場合のみ: **体の湯気・吐息の濃さ**
- 立体機能を搭載しない場合: No Tess Materialのみ。立体効果Menuは表示されません。

実際のメニュー構造は[手動モードと自動モード](./usage/modes.mdx)で確認できます。

# 更新クイックガイド

導入済みの Real Sweat System を 2.0.0 以降へ更新するときの要約です。手順の全体は[1.x からの更新方法](./quick-start.mdx#updating-from-1x)にあります。

## 短い答え {/* #short-answer */}

1. 所有している Base／Effects モジュールを、**すべて同じバージョンで** 既存ファイルへ上書きインポートします。旧バージョンのファイルを消したり、先に **［削除］** を押したりする必要はありません。
2. Setup ウィンドウに「古いバージョンでインストールされています。」という黄色い枠が表示されたら、アバターごとに **［インストール / 更新］** を一度押します。
3. 2.0.0 から購入認証があります。アップロードする前に、PCごとに一度認証してください。

インポートする前に、アバターとプロジェクトを **プロジェクトの外に** バックアップしてください。Setup ウィンドウは `CookiTools → RealSweatSystem → Setup／Uninstall`、認証ウィンドウは `CookiTools → RealSweatSystem → Purchase Activation` から開きます。

## どのバージョンから更新するか {/* #by-version */}

| 現在導入しているバージョン | 必要な作業 |
|---|---|
| **1.0.x、1.1.x** | 上書きインポートしてから、アバターごとに **［インストール / 更新］** を一度押し、アップロードする前に購入認証をします。中間バージョンを経由する必要はありません。 |
| **2.0.x から 2.1.0 へ** | 上書きインポートだけで完了します。**［インストール / 更新］** を押し直す必要はありません。押すのは、[心拍連動](./usage/heart-rate-link.mdx)を追加するときと、**汗の表示** をオフにしたときに床にすでにある濡れ跡も隠したいときだけです。 |

v1.0.0～v1.0.2 から更新する場合は、[更新・変更履歴](./update-changelog.mdx#v110)にある v1.1.0 の移行内容も適用されます。

## このようにしても大丈夫です {/* #fine */}

| 方法 | 結果 |
|---|---|
| 旧バージョンを消さずに、その上へ上書きインポートする | 正しい方法です。先に削除する必要はありません。 |
| 中間バージョンを飛ばして、新しいバージョンへ直接更新する | 問題ありません。v1.0.0～v1.0.2 の導入からも直接更新できます。 |
| Base と Effects を好きな順番でインポートする | 順番は問いません。バージョンが同じであれば大丈夫です。 |
| 購入認証の前にインポートして **［インストール / 更新］** を押す | 問題ありません。導入済みのアバターの更新では認証を求められません。アバターに無かったモジュールを追加するときだけ認証を求められます。認証はアップロードする前に行ってください。 |

## 不要なこと、してはいけないこと {/* #avoid */}

| このようにすると | 起こること | このようにしてください |
|---|---|---|
| インポートだけして **［インストール / 更新］** を押さない（1.x から更新するとき） | 汗マテリアルの見た目の値はインポートの直後に新しい既定値になりますが、アバターごとの更新は行われないままです。模様番号、Rest の上方向、体の大きさに合わせた水滴サイズ、新しい体の湯気、メニュー名が反映されません。Setup ウィンドウには黄色い枠が表示され続け、Scene ビューにも「RealSweatSystem の更新を推奨」という案内が表示されます。 | アバターごとに **［インストール / 更新］** を一度押してください。 |
| **FX に適用** だけを押す | この更新は行われません。黄色い枠もそのまま残ります。 | **［インストール / 更新］** を押してください。 |
| Base と Effects のどちらか一方だけを新しいバージョンでインポートする | Setup ウィンドウが同じバージョンで再インポートするよう知らせ、インストールを止めます。そのままアップロードすると、ビルドは止まりませんが、アバターから Real Sweat System が外れ、Console に `[RealSweatSystem]` で始まる警告が出ます。 | 所有しているモジュールをすべて同じバージョンでインポートしてから、Setup ウィンドウを開き直してください。 |
| 購入認証をしていないPCからアップロードする | ビルドは失敗せず、ダイアログも表示されませんが、認証が無いモジュールの効果がアップロードしたアバターから外れます。シーンと Play Mode ではそのまま表示されます。 | 認証してから、もう一度アップロードしてください。**［インストール / 更新］** を押し直す必要はありません。 |
| 先に **［削除］** してから、新しいバージョンで導入し直す | 不要な作業です。削除すると、導入オブジェクトと導入専用の生成フォルダーがまとめて削除されるため、アバターに合わせた設定を最初からやり直すことになります。その後のインストールは新しいインストールになるため、購入認証を求められます。 | 削除せずに、上書きインポートしてください。 |
| `RealSweat` オブジェクトを直接削除する | メッシュを元に戻すための情報は、このオブジェクトに保存されています。削除すると、Body に生成メッシュと汗のマテリアルスロットが残ることがあります。 | 削除しないでください。すでに削除した場合は、[`RealSweat` オブジェクトだけを直接削除した場合](./troubleshooting.mdx#manual-delete-recovery)に従ってください。 |
| `Assets/CookiTools/Generated`、または `CookiTools` フォルダー全体を削除する | Body が使っている生成メッシュが失われ、Body が表示されなくなることがあります。 | 削除しないでください。すでに削除した場合は、[`Generated` フォルダーを削除した後、Bodyが表示されない場合](./troubleshooting.mdx#if-the-generated-folder-was-deleted-and-the-body-disappeared)に従ってください。 |
| `Assets/CookiTools/RealSweatSystem` の製品フォルダーを消してからインポートし直す | 不要な作業です。生成ファイルは通常、別のフォルダー（`Assets/CookiTools/Generated`）に残ります。 | 消してしまった場合は、所有しているモジュールをすべて同じバージョンでもう一度インポートしてください。 |
| **［インストール / 更新］** を押す前に見た目を調整する（1.x から更新するとき） | そのボタンを押したときに、見た目の値が再び新しい既定値になります。 | 見た目の調整は更新の後で行ってください。更新の後で調整した値はそのまま残ります。 |

## 1.x から更新すると変わること {/* #from-1x */}

- **見た目:** 2.0.0 で肌の汗の見た目を新しく作りました。以前のバージョンの汗マテリアルの見た目の値は、マテリアルごとに一度だけ新しい既定値になり、更新したアバターは **リアル** のスタイルから始まります。
- **水滴の位置:** 新しい模様番号により、水滴の位置が一度変わります。
- **レンダーキュー:** 自動描画順の汗のレンダーキューは2455から2350に変わります。2350以降のボディマテリアルがあると、**［インストール / 更新］** が2349に下げるか確認します。自分で設定した手動のレンダーキューはそのままです。
- **そのまま残るもの:** 汗の品質、自動モード感度、エフェクトとメニュー、Rest データ、発生マスクと表示マスク、衣装ステンシルなどはそのままです。

変わる値と残る値の全体は[1.x からの更新方法](./quick-start.mdx#updating-from-1x)にあります。

:::note[初回のアップロードは時間がかかることがあります]
その PC で初めてアップロードするときは、汗シェーダーのコンパイルに数分かかることがあります。進行状況のウィンドウが出なくても、Unity を閉じずにお待ちください。
:::

## 更新の手順を間違えたとき {/* #recovery */}

- **インポートだけして、ボタンを押していません。** 今からアバターごとに **［インストール / 更新］** を一度押してください。押す前に調整した見た目の値は、そのときに新しい既定値になります。
- **モジュールを1つだけ更新しました。** 残りのモジュールも同じバージョンでインポートしてから、Setup ウィンドウを開き直してください。削除は不要です。
- **認証する前にアップロードしました。** 認証してから、もう一度アップロードしてください。シーンのアバターは変わっていません。確認方法は[アップロードすると汗やエフェクトが外れる](./troubleshooting.mdx#missing-after-upload)にあります。
- **先に削除してしまいました。** 新しいバージョンをインポートし、**［インストール / 更新］** を押して導入し直してください。新しいインストールになるため、購入認証が必要です。
- **`RealSweat` オブジェクトや `Generated` フォルダーを消してしまいました。** [削除・再導入・Module構成を変更する](./troubleshooting.mdx#uninstall-reinstall-or-change-modules)の復旧手順に従ってください。生成 Body メッシュが割り当てられたままの状態で、すぐに **［インストール / 更新］** を押さないでください。
- **以前のバージョンに戻したいです。** 更新前に作ったバックアップで戻すのが最も安全です。バックアップが無い場合は、パッケージに含まれる README の「v1.1.3 に戻す」に従ってください。**［インストール / 更新］**、**FX に適用**、**［削除］** は Ctrl+Z で元に戻せません。

# Real Sweat System ドキュメント

**Real Sweat System** は、PC版VRChatアバターにリアルタイムの汗表現を追加するシステムです。ラジアルメニューで **汗 %** を直接操作するほか、体の動きに応じて汗が増え、動きを止めるとゆっくり乾く **自動モード** を利用できます。

:::info[対象バージョン]
このドキュメントは **Real Sweat System v2.0.0** を基準にしています。v2.0.0 は、肌の汗の見た目、Setup ウィンドウ、体の湯気を新しく作った大きなアップデートです。1.x の導入を更新する場合は、[1.x からの更新方法](./quick-start.mdx#updating-from-1x)に従ってください。
:::

## 表現できるもの

- 肌に浮かぶ汗と水滴。スタイルは **アニメ（標準）** と **リアル** の2つです
- 実際の重力に従い、ほぼまっすぐ下へ流れる水滴と流れ跡
- 任意の **水滴の立体感**: カメラの近くの水滴が実際に肌から盛り上がります
- 落下する汗の滴と、短く飛ぶはね
- 床を暗くする床の濡れ跡
- 各部位の周りからゆっくり立ちのぼる、淡い体の湯気
- Viseme・VRCFTに反応する吐息
- 落下する滴・体の湯気・吐息の任意の3Dパーティクル
- 複数のBody Material Elementや追加のSkinned Meshへの汗（実験的）

肌の汗は **Sweat Base Module**、落下する滴・床の濡れ跡・吐息・体の湯気は **Sweat Effects Module** に含まれます。**Full Pack (Base + Effects)** は両方のModuleを収録した完全構成です。

## 動作環境

Real Sweat System には次の環境が必要です。

- Unity 2022.3
- VRChat Avatars SDK3
- Modular Avatar
- Direct3D 11 を使用するPC版アバター

Quest単体版には対応していません。自動モードはHumanoidアバターで使用できます。それ以外のアバターでも手動モードは使用できます。

:::warning[バックアップを作成してください]
導入や更新の前に、アバターとプロジェクトをバックアップしてください。更新の場合は、バックアップをプロジェクトの外に置いてください。
:::

:::warning[正式な削除を使用してください]
Real Sweat Systemを削除する場合は、`RealSweat` オブジェクトや `Assets/CookiTools/Generated` を直接削除しないでください。`CookiTools → RealSweatSystem → Setup／Uninstall` を開いて **削除** タブを使用し、[削除手順](./troubleshooting.mdx#uninstall-reinstall-or-change-modules)に従ってください。
:::

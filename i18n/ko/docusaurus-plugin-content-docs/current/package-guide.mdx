# 패키지 안내

| 구성 | 포함되는 주요 기능 | 추천 대상 |
|---|---|---|
| **Sweat Base Module** | 두 가지 스타일(애니 / 실사)의 피부 땀, 선택형 물방울 입체감, 마스크, Rest 데이터, 거울·렌더 순서 설정, 상대 저부하, 피부 땀 숨기기 | 피부의 땀 표현이 필요한 경우 |
| **Sweat Effects Module** | 낙하 물방울과 튀김, 바닥 물자국, 입김, 몸 김과 Custom Steam Point. 2D 또는 선택형 3D 파티클 | 주변 파티클 효과가 필요한 경우 |
| **Full Pack (Base + Effects)** | Base Module + Effects Module | 모든 표현을 함께 연동해 사용하려는 경우 |

각 모듈에는 실행에 필요한 공용 **Core** 파일이 포함됩니다. Core는 별도로 구매하거나 직접 설정하는 제품이 아닙니다. v2.0.0 업데이트는 Core에 적용되므로 모든 패키지에 적용됩니다.

VRC Light Volumes 지원은 v2.0.0에서 없어졌습니다. 피부 땀의 주변광은 Unity 라이트 프로브(SH)만 씁니다.

자동 모드에는 호환되는 Humanoid 움직임 구성이 필요합니다. 입김과 몸 김에는 Head／Chest 앵커도 필요합니다. 정확한 대체 동작은 [호환성](./compatibility.mdx#avatar-type)을 확인해 주십시오.

## Sweat Base Module

Base Module은 메인 Body Renderer에서 고른 Material Element에 땀을 넣습니다. 얼굴 메쉬 같은 별도 `SkinnedMeshRenderer` 대상에도 **실험적** 기능으로 땀을 넣을 수 있습니다. Rest 데이터는 Element가 아니라 메쉬마다 만듭니다. 같은 Renderer의 Element들은 같은 메쉬 대응을 함께 쓰고, 별도 Renderer는 자기 Rest 데이터를 받습니다. 설정한 땀 Element마다 마테리얼과 드로우가 하나씩 추가됩니다.

땀 스타일(**애니** 또는 **실사**)은 아바타마다 하나입니다. 바디와 다른 메쉬가 모두 같은 스타일을 씁니다. 수동 모드와 자동 모드는 같은 땀 %를 공유합니다. 물방울 입체감을 설치했다면 인게임 메뉴가 물방울 입체감이 있는 모든 땀 슬롯을 함께 전환합니다.

## Sweat Effects Module

Effects Module은 선택한 Body Mesh를 방출 표면으로 사용합니다. Body 마테리얼, Body Mesh, Rest 데이터, 물방울 입체감 구성은 **수정하지 않습니다**. 기본은 기존의 가벼운 2D 파티클입니다. 고부하 **3D 파티클**은 설치 창 첫 화면의 **표현**에서 <strong>입체 (고부하)</strong>를 고르거나 **고급 설정 > 품질·부하**에서 켭니다.

낙하 물방울과 튀김은 땀 스타일(애니 / 실사)을 따릅니다. 스타일은 Base Module이 설치된 경우에만 고르며, Effects Module만 있으면 땀 스타일 선택이 없고 낙하 물방울은 애니 모양을 씁니다.

이펙트 메뉴는 이 모듈을 설치한 경우에만 나타납니다.

## Full Pack (Base + Effects)

Full Pack은 완전 구성입니다. 피부 땀과 이펙트가 같은 땀 %에 반응하도록 두 모듈을 같은 버전으로 설치해 주십시오.

아바타 메뉴는 설치한 모듈에 따라 만들어집니다.

- **나에게만 보이기**는 모든 패키지 구성에서 나타납니다.
- **상대 저부하**는 Base를 설치하면 나타납니다.
- **이펙트**는 Effects를 설치하면 나타납니다.
- <strong>물방울 입체감(테셀레이션 / 고부하)</strong>은 물방울 입체감을 설치한 경우에만 나타납니다.

## 설치·업데이트·패키지 변경

- 새로 설치할 때는 [5분 빠른 시작](./quick-start.mdx)을 따라 주십시오.
- Base와 Effects를 함께 쓸 때는 같은 버전으로 맞춰 주십시오. 버전이 섞여 있으면 설치 창이 같은 버전으로 다시 임포트하라고 알리고 설치를 막습니다.
- Base 또는 Effects를 Full Pack으로 늘리려면 빠진 모듈을 같은 버전으로 임포트한 뒤 <strong>[설치 / 업데이트]</strong>를 한 번 눌러 주십시오.
- 1.x에서 업데이트하려면 보유한 모듈을 모두 같은 v2.0.0으로 **기존 파일 위에** 덮어 임포트한 뒤, 아바타마다 <strong>[설치 / 업데이트]</strong>를 한 번 눌러 주십시오. 이전 버전을 먼저 제거하지 마십시오. **FX에 적용만으로는 이 업데이트가 되지 않습니다.** 전체 절차는 [1.x에서 업데이트하는 방법](./quick-start.mdx#updating-from-1x)을 확인해 주십시오.
- 제거하거나 한 모듈만 쓰는 설치로 되돌리려면 [제거·재설치·모듈 변경](./troubleshooting.mdx#uninstall-reinstall-or-change-modules)을 따라 주십시오.

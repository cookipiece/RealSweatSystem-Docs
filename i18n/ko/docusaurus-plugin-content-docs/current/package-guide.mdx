# 패키지 안내

| 구성 | 포함되는 주요 기능 | 추천 대상 |
|---|---|---|
| **Sweat Base Module** | 피부 표면의 땀, Rest 데이터, Tess / No Tess, 렌더 순서, Remote Low Load | 피부의 땀 표현이 필요한 경우 |
| **Sweat Effects Module** | 낙하 물방울, 바닥 자국, 입김, 몸의 스팀 | 주변 파티클 효과가 필요한 경우 |
| **Full Pack (Base + Effects)** | Base + Effects | 모든 표현을 Sweat %에 맞춰 함께 사용하려는 경우 |

각 모듈에는 실행에 필요한 공용 **Core**가 포함됩니다. Core는 별도로 구매하거나 직접 설정하는 제품이 아닙니다.

## Sweat Base Module

Body 재질과 Mesh를 대상으로 피부 표면의 땀을 구성합니다. Manual Mode와 Auto Mode, 렌더 순서, 그림자 반응, 선택형 입체기능 및 상대방용 경량 표시를 포함합니다.

## Sweat Effects Module

Effects만 설치해도 파티클 방출 위치를 계산하기 위해 **Body Mesh 지정이 필요**합니다. 다만 Effects-only 설치는 Body 재질, Body Mesh, Rest 데이터 또는 테셀레이션 구성을 수정하지 않습니다.

## Full Pack (Base + Effects)

Full Pack은 Base와 Effects를 모두 포함한 완전 구성입니다. 두 모듈이 같은 Sweat %를 공유하여 피부의 땀, 낙하 물방울, 바닥 자국, 입김과 스팀이 자연스럽게 연동됩니다. 두 패키지는 같은 버전을 사용하세요.

## 설치 구성에 따른 메뉴

- Base 설치 시 **Remote Low Load**가 표시됩니다.
- Effects 설치 시 **Particles** 하위 메뉴가 표시됩니다.
- 입체기능을 탑재한 경우에만 **3D Effect (Photos Only, High Load)**가 표시됩니다.
- 설치하지 않은 모듈의 항목은 Tuning과 아바타 메뉴에 나타나지 않습니다.

# 5분 빠른 시작

이 페이지에서는 아바타를 안전하게 백업하고 Real Sweat System을 설치한 뒤, Play Mode에서 첫 동작을 확인합니다.

## 1. 설치 환경 확인

- Unity 2022.3 기반 VRChat Avatar Project를 엽니다.
- VRChat Avatars SDK3와 Modular Avatar가 설치되어 있어야 합니다.
- 아바타 Prefab 또는 Unity Project를 백업합니다.
- Console에 기존 컴파일 오류가 없는지 확인합니다.
- v1.0.0에서 업데이트한다면 먼저 [업데이트 안내](./update-changelog.mdx)를 확인합니다.

:::note
VRCFury는 필수 의존성이 아닙니다. 사용 중이어도 괜찮지만, Real Sweat System 설치에는 Modular Avatar가 필요합니다.
:::

## 2. UnityPackage 가져오기

구매한 구성에 맞는 UnityPackage를 가져옵니다.

- **Base Module:** 피부 표면의 땀
- **Effects Module:** 낙하 물방울, 바닥 자국, 입김, 스팀
- **Full Pack (Base + Effects):** Base와 Effects를 모두 가져오기

Base와 Effects를 함께 사용할 때는 반드시 같은 제품 버전으로 맞춰 주세요.

## 3. Setup 대상 지정

아바타 루트를 선택하고 Real Sweat System Setup을 엽니다. 그다음 땀이 표시될 **Body Mesh**를 지정합니다.

- Body는 아바타 하위의 유효한 Mesh와 Submesh를 가진 `SkinnedMeshRenderer`여야 합니다.
- 현재 설치 한 번당 Body Renderer 한 개를 지원합니다.
- Face Renderer를 Body 항목에 지정하지 마세요.
- 자동 감지가 실패하면 Body Mesh를 직접 지정합니다.
- Body에 재질 슬롯이 여러 개라면 **Sweat Target Element**에서 정확한 슬롯을 선택합니다.

## 4. 기본 설정 확인

처음 설치할 때의 기본값은 다음과 같습니다.

| 항목 | 기본값 |
|---|---|
| 전체 땀양 | **적음(저부하)** |
| 감도 프리셋 | **균형** |
| 자동 렌더 순서 | **켜짐** |
| 땀 Render Queue | **2455** |
| 바디 그림자 따라가기 | **켜짐** |
| 입체기능(테셀레이션) 탑재 | **미탑재** |

입체기능을 탑재하면 기본 정밀도는 **간략화 — 일반 플레이**이며, **테셀레이션 기본값 켜기**는 체크 해제 상태입니다.

Body에 Tangent가 없다면 **Safe Copy (Recommended)**를 선택하세요. Poiyomi 재질이 수동으로 Lock되어 있다면 설치 전에 임시로 Unlock하고, 설치가 끝난 뒤 다시 Lock하는 방법을 권장합니다.

## 5. 설치 또는 업데이트 실행

설정을 확인한 뒤 **Setup — Install / Update**를 실행합니다. 완료 안내가 표시될 때까지 Unity 조작을 기다리고, 끝난 뒤 Console에 새 오류가 없는지 확인합니다.

## 6. Play Mode에서 확인

1. Gesture Manager 등으로 Play Mode에 들어갑니다.
2. 아바타 메뉴에서 **땀 켜기**를 활성화합니다.
3. **땀 %**를 0%, 25%, 50%, 75%, 100% 순서로 확인합니다.
4. **자동 모드**에서 움직임과 정지에 따라 값이 변하는지 확인합니다.
5. 설치한 경우 **부하 줄이기** 메뉴에서 파티클과 입체기능을 확인합니다.
6. 얼굴 표정과 기존 아바타 기능도 함께 확인합니다.

:::info[정상 동작]
Sweat 0%에서는 땀 표현이 거의 보이지 않고, 값을 올리면 단계가 끊기지 않고 자연스럽게 증가해야 합니다.
:::

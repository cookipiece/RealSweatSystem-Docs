# 5분 빠른 시작

이 페이지에서는 아바타를 안전하게 백업하고 Real Sweat System을 설치한 뒤, Play Mode에서 첫 동작을 확인합니다.

:::note[소요 시간]
여기서 말하는 5분은 UnityPackage Import와 최초 Shader Compile이 끝난 뒤의 설정 시간입니다. 프로젝트와 PC 환경에 따라 첫 Import·컴파일에는 몇 분 이상 걸릴 수 있습니다.
:::

## 1. 설치 환경 확인

- Unity 2022.3 기반 VRChat Avatar Project를 엽니다.
- VRChat Avatars SDK3와 Modular Avatar가 설치되어 있어야 합니다.
- 아바타 Prefab 또는 Unity Project를 백업합니다.
- Console에 기존 컴파일 오류가 없는지 확인합니다.
- v1.0.0에서 업데이트한다면 먼저 [업데이트 안내](./update-changelog.mdx)를 확인합니다.

:::note
VRCFury는 필수 의존성이 아닙니다. 사용 중이어도 괜찮지만, Real Sweat System 설치에는 Modular Avatar가 필요합니다.
:::

## 2. UnityPackage 가져오기

구매한 구성에 맞는 UnityPackage를 가져옵니다.

- **Base Module:** 피부 표면의 땀
- **Effects Module:** 낙하 물방울, 바닥 물자국, 입김, 몸 김
- **Full Pack (Base + Effects):** Base와 Effects를 모두 가져오기

Base와 Effects를 함께 사용할 때는 반드시 같은 제품 버전으로 맞춰 주세요.

## 3. Setup 대상 지정

1. Hierarchy에서 Scene에 배치된 **아바타 루트**를 선택합니다.
2. Unity 상단 메뉴에서 **CookiTools > RealSweatSystem Setup／Uninstall**을 엽니다.

[![Unity 상단 CookiTools 메뉴에서 RealSweatSystem Setup／Uninstall을 여는 위치](/img/guide/setup-menu-path.png)](/img/guide/setup-menu-path.png)

*<small>CookiTools 메뉴의 Setup 실행 위치입니다. 이미지를 누르면 크게 볼 수 있습니다.</small>*
3. **아바타**와 땀이 표시될 **바디 메쉬**가 올바르게 지정되었는지 확인합니다.
4. 바디에 재질 슬롯이 여러 개라면 **땀 적용 Element**에서 피부 재질이 있는 슬롯을 선택합니다. Element 0은 보통 메인 피부입니다.

- 바디 메쉬는 아바타 하위의 유효한 Mesh와 Submesh를 가진 `SkinnedMeshRenderer`여야 합니다.
- 현재 설치 한 번당 Body Renderer 한 개를 지원합니다.
- Face Renderer를 Body 항목에 지정하지 마세요.
- 자동 감지가 실패하면 바디 메쉬를 직접 지정합니다.

[![RealSweatSystem Setup 한국어 설치 화면](/img/guide/setup-korean.png)](/img/guide/setup-korean.png)

*<small>한국어 Setup 화면입니다. 처음 설치할 때는 아바타, 바디 메쉬, 땀 적용 Element를 우선 확인하세요.</small>*

## 4. 기본 설정 확인

처음에는 아래 기본값을 그대로 사용해도 됩니다.

| 항목 | 기본값 |
|---|---|
| 전체 땀양 | **적음(저부하)** |
| 감도 프리셋 | **균형** |
| 렌더 순서 자동 설정 (권장) | **켜짐** |
| 땀 렌더 큐 | **2455** |
| 바디 Shadow Strength 따라가기 | **켜짐** |
| 입체기능(테셀레이션) 탑재 | **미탑재** |

입체기능을 탑재하면 기본 정밀도는 **간소화 — 일반 플레이용**이며, **테셀레이션 기본값 켜기**는 체크 해제 상태입니다.

:::tip[기본값으로 진행하세요]
Render Queue와 Tangent 같은 예외 설정은 Setup이 경고할 때만 확인하면 됩니다. 자세한 내용은 [문제 해결](./troubleshooting.mdx)과 [호환성](./compatibility.mdx)을 참고하세요.
:::

바디 메쉬에 Tangent가 없다는 창이 나타나면 **안전한 사본 생성 (권장)**을 선택하세요. 원본 모델의 Import 설정을 건드리지 않고 RealSweat 전용 메쉬를 생성합니다.

## 5. 설치 또는 업데이트 실행

설정을 확인한 뒤 **Setup — 자동 설치 / 업데이트**를 누릅니다.

- 완료 안내가 표시될 때까지 Unity 조작을 기다립니다.
- Console에 새 오류가 없는지 확인합니다.
- Hierarchy의 아바타 아래에 **RealSweat** 오브젝트가 생성되었는지 확인합니다.

:::info[정상 설치 완료 기준]
완료 메시지가 표시되고 아바타 아래에 RealSweat 오브젝트가 생성되며, Console에 새 오류가 없다면 설치가 끝난 것입니다.
:::

## 6. Play Mode에서 확인

1. Gesture Manager 등으로 Play Mode에 들어갑니다.
2. 아바타 메뉴에서 **땀 켜기**를 활성화합니다.
3. **자동 모드**는 기본값이 ON입니다. 먼저 수동 테스트를 위해 **자동 모드**를 OFF로 바꿉니다.
4. <strong>땀 %</strong>를 0%, 25%, 50%, 75%, 100% 순서로 확인합니다.
5. **자동 모드**를 다시 ON으로 바꾸고 몸의 움직임과 정지에 따라 값이 변하는지 확인합니다.
6. 설치한 경우 **부하 줄이기** 메뉴에서 파티클과 입체기능을 확인합니다.
7. 얼굴 표정과 기존 아바타 기능도 함께 확인합니다.

[![Gesture Manager에 표시된 Real Sweat System 메인 메뉴](/img/guide/gesture-menu-korean.png)](/img/guide/gesture-menu-korean.png)

*<small>Real Sweat System 메인 메뉴입니다. 여기서 땀, 자동 모드, 땀 %, 이펙트와 부하 설정으로 이동합니다.</small>*

[![Gesture Manager에 표시된 땀 퍼센트 라디얼 슬라이더](/img/guide/gesture-sweat-percent-korean.png)](/img/guide/gesture-sweat-percent-korean.png)

*<small>땀 %를 0%부터 100%까지 수동으로 확인하는 라디얼 슬라이더입니다.</small>*

:::info[정상 동작]
Sweat 0%에서는 땀 표현이 거의 보이지 않고, 값을 올리면 단계가 끊기지 않고 자연스럽게 증가해야 합니다.
:::

# 5분 빠른 시작

이 페이지에서는 아바타를 안전하게 백업하고 Real Sweat System을 설치한 뒤, Play Mode에서 첫 동작을 확인합니다.

:::note[소요 시간]
여기서 말하는 5분은 UnityPackage Import와 최초 Shader Compile이 끝난 뒤의 설정 시간입니다. 프로젝트와 PC 환경에 따라 첫 Import·컴파일에는 몇 분 이상 걸릴 수 있습니다.
:::

## 1. 설치 환경 확인

- Unity 2022.3 기반 VRChat Avatar Project를 엽니다.
- VRChat Avatars SDK3와 Modular Avatar가 설치되어 있어야 합니다.
- 아바타 Prefab 또는 Unity Project를 백업합니다.
- Console에 기존 컴파일 오류가 없는지 확인합니다.
- v1.0.0～v1.0.2에서 업데이트한다면 보유한 Base／Effects를 **모두 같은 v1.1.0**으로 덮어 임포트합니다. 먼저 Uninstall하거나 기존 `RealSweat` 오브젝트 또는 `Assets/CookiTools/Generated`를 삭제하지 마세요.
- 업데이트 후에는 **FX에 적용**이 아니라 **Setup — 자동 설치 / 업데이트**를 한 번 실행합니다. 자세한 내용은 [업데이트 안내](./update-changelog.mdx#v102에서-v110으로-업데이트)를 확인하세요.

:::note
VRCFury는 필수 의존성이 아닙니다. 사용 중이어도 괜찮지만, Real Sweat System 설치에는 Modular Avatar가 필요합니다.
:::

## 2. UnityPackage 가져오기

구매한 구성에 맞는 UnityPackage를 가져옵니다.

- **Base Module:** 피부 표면의 땀
- **Effects Module:** 낙하 물방울, 바닥 물자국, 입김, 몸 김
- **Full Pack (Base + Effects):** Base와 Effects를 모두 가져오기

Base와 Effects를 함께 사용할 때는 반드시 같은 제품 버전으로 맞춰 주세요.

## 3. Setup 대상 지정

1. Hierarchy에서 Scene에 배치된 **아바타 루트**를 선택합니다.
2. Unity 상단 메뉴에서 **CookiTools > RealSweatSystem Setup／Uninstall**을 엽니다.

[![Unity 상단 CookiTools 메뉴에서 RealSweatSystem Setup／Uninstall을 여는 위치](/img/guide/setup-menu-path.png)](/img/guide/setup-menu-path.png)

*<small>CookiTools 메뉴의 Setup 실행 위치입니다. 이미지를 누르면 크게 볼 수 있습니다.</small>*
3. **아바타**와 땀이 표시될 **바디 메쉬**가 올바르게 지정되었는지 확인합니다. Project 창의 `.fbx`나 Mesh 에셋이 아니라, Hierarchy에서 피부용 `SkinnedMeshRenderer`가 붙은 오브젝트를 지정합니다.
4. 바디에 재질 슬롯이 여러 개라면 Element 번호를 추정하지 말고, 각 Element 옆에 표시되는 재질명을 확인해 피부 슬롯을 선택합니다. v1.1에서는 같은 Renderer의 여러 Element를 선택할 수 있습니다.

- 바디 메쉬는 아바타 하위의 유효한 Mesh와 Submesh를 가진 `SkinnedMeshRenderer`여야 합니다.
- Face나 의상 Renderer를 메인 Body로 지정하지 마세요. 얼굴 등 별도 `SkinnedMeshRenderer`는 메인 Body를 지정한 뒤 **실험적 추가 대상**에 등록할 수 있습니다.
- 자동 감지는 재질·Renderer·Mesh 이름과 BlendShape를 함께 평가합니다. 후보가 약하거나 모호하면 임의로 선택하지 않으므로 직접 지정합니다.

## 4. 기본 설정 확인

처음에는 아래 기본값을 그대로 사용해도 됩니다.

| 항목 | 기본값 |
|---|---|
| 렌더 순서 자동 설정 (권장) | **켜짐** |
| 땀 렌더 큐 | **2455** |
| 바디 Shadow Strength 따라가기 | **켜짐** |
| 젖은 피부 광택 사용 | **켜짐**. 업데이트 시 기존 설치 상태 유지 |
| 전체 땀양 | **적음(저부하)** |
| 자동 모드 | **켜짐** |
| 자동 모드 감도 | **균형** |
| 입체기능(테셀레이션)(고부하) 탑재 | **꺼짐(미탑재)** |
| 입체 표현 정밀도 | **간소화 — 일반 플레이용**. 입체기능 탑재 시에만 사용 |
| 테셀레이션 기본값 켜기 | **꺼짐**. 입체기능 탑재 시에만 사용 |
| 거울에서도 바디 땀 전체 품질 | **꺼짐** |
| 낙하 물방울 | Effects 설치 시 **켜짐** |
| 바닥 물자국 | Effects 설치 시 **켜짐** |
| 입김 | Effects 설치 시 **켜짐** |
| 몸 김 | Effects 설치 시 **켜짐** |
| 3D 파티클 품질 | **꺼짐(가벼운 2D 사용)** |
| 물방울 충돌 튀김 | 3D 파티클 선택 시에만 **켜짐** |
| 몸 김 거울 표시 | 새 설치는 **Low** |
| 1인칭에서 내 입김 표시 | **꺼짐** |
| 몸 김·입김 진하기 메뉴 설치 | **꺼짐(미설치)** |
| 몸 김 위치 | **가슴골·양어깨·겨드랑이·허벅지 켜짐**, **고간·발 꺼짐** |

:::tip[기본값으로 진행하세요]
Render Queue와 Tangent 같은 예외 설정은 Setup이 경고할 때만 확인하면 됩니다. 자세한 내용은 [문제 해결](./troubleshooting.mdx)과 [호환성](./compatibility.mdx)을 참고하세요.
:::

바디 메쉬에 Tangent가 없다는 창이 나타나면 **안전한 사본 생성 (권장)**을 선택하세요. 원본 모델의 Import 설정을 건드리지 않고 RealSweat 전용 메쉬를 생성합니다.

Setup에서 낙하 물방울·바닥 물자국·입김·몸 김, 몸 김 위치와 Custom Steam Point를 선택할 수 있습니다. 3D 파티클은 GPU 부하가 커질 수 있으므로 처음에는 2D로 설치한 뒤 필요할 때 전체 Setup을 다시 실행해 전환하는 것을 권장합니다.

## 5. 설치 또는 업데이트 실행

설정을 확인한 뒤 **Setup — 자동 설치 / 업데이트**를 누릅니다.

- 완료 안내가 표시될 때까지 Unity 조작을 기다립니다.
- Console에 새 오류가 없는지 확인합니다.
- Hierarchy의 아바타 아래에 **RealSweat** 오브젝트가 생성되었는지 확인합니다.

:::info[정상 설치 완료 기준]
완료 메시지가 표시되고 아바타 아래에 RealSweat 오브젝트가 생성되며, Console에 새 오류가 없다면 설치가 끝난 것입니다.
:::

## 6. Play Mode에서 확인

1. Gesture Manager 등으로 Play Mode에 들어갑니다.
2. 아바타 메뉴에서 **땀 표시**를 활성화합니다.
3. **자동 모드**는 기본값이 ON입니다. 먼저 수동 테스트를 위해 **자동 모드**를 OFF로 바꿉니다.
4. <strong>땀 %</strong>를 0%, 25%, 50%, 75%, 100% 순서로 확인합니다.
5. **자동 모드**를 다시 ON으로 바꾸고 몸의 움직임과 정지에 따라 값이 변하는지 확인합니다.
6. **부하 줄이기**에서 표면 땀 숨기기·상대 저부하·Light Volumes·나에게만 표시와 선택형 테셀레이션을 확인하고, 별도 **이펙트** 하위 메뉴에서 낙하 물방울·바닥 물자국·입김·몸 김을 확인합니다. 바디 땀／몸 김의 미러 품질은 Setup에서 정하는 구조 옵션이므로 일반 화면과 미러를 직접 비교하세요.
7. 얼굴 표정과 기존 아바타 기능도 함께 확인합니다.
8. Scene View와 Gesture Manager 확인은 예비 확인입니다. 업로드 전 VRChat SDK의 **Build & Test**에서 표면 땀·이펙트·메뉴·거울을 최종 확인합니다.

:::info[정상 동작]
Sweat 0%에서는 땀 표현이 거의 보이지 않고, 값을 올리면 단계가 끊기지 않고 자연스럽게 증가해야 합니다.
:::

:::warning[직접 삭제하지 마세요]
Real Sweat System을 제거할 때는 `RealSweat` 오브젝트나 `Assets/CookiTools/Generated`를 직접 삭제하지 말고 [공식 Uninstall 절차](./troubleshooting.mdx)를 사용하세요.
:::

바닥 물자국은 낙하 물방울의 충돌 하위 이펙트입니다. 물자국을 확인할 때는 **전체 이펙트·낙하 물방울·바닥 물자국**을 모두 켜고 Collider가 있는 월드 바닥에서 확인하세요.

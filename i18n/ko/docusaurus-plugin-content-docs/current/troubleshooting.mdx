# 문제 해결

먼저 Unity Console을 Clear한 뒤 문제를 한 번 재현하고, **가장 먼저 발생한 오류**부터 확인해 주십시오. 뒤에 이어진 오류는 첫 오류의 결과인 경우가 많습니다.

정상 동작 기록은 설치 창 **문제 해결** 탭의 **자세한 기록을 콘솔에 남기기**를 켰을 때만 콘솔에 남습니다. 문의할 때 더 자세한 정보가 필요하면 켜 주십시오.

## 땀이 전혀 보이지 않음 {/* #no-sweat-is-visible */}

먼저 무엇을 설치했는지 확인합니다.

- **Effects Module만** 설치했다면 피부 땀은 표시되지 않습니다. 낙하 물방울, 바닥 물자국, 입김, 몸 김만 표시됩니다.
- 바디 표면의 땀에는 **Base Module** 또는 **Full Pack**이 필요합니다.

Base 또는 Full Pack이라면 다음을 확인합니다.

1. Play Mode에서 **땀 표시**를 켭니다.
2. 기본값으로 켜져 있는 **자동 모드**를 잠시 끄고 <strong>땀 %</strong>를 50% 이상으로 올립니다.
3. **부하 줄이기**의 **피부 땀 숨기기**가 꺼져 있는지 확인합니다.
4. 설치 창에서 **땀을 넣을 곳** 줄에 의도한 바디 메쉬가 보이는지, **고급 설정 > 땀을 넣을 곳**에서 피부 마테리얼만 체크되어 있는지 확인합니다.
5. Rest 데이터를 확인합니다. 새 모양은 Rest 데이터가 맞는 곳에만 땀을 그리며, 1.1.x처럼 UV 무늬로 대신 그리지 않습니다. 아직 설치하지 않은 마테리얼이나 굽기 뒤에 바뀐 메쉬는 Scene 뷰에 땀이 보이지 않을 수 있습니다. 마테리얼 인스펙터 맨 위의 **Rest 데이터** 칸과 Tuning의 **메쉬 및 Rest 데이터 진단**이 이 경우를 알려 줍니다. 메쉬가 바뀌었으면 다음 빌드(업로드) 때 최종 메쉬로 다시 굽습니다.
6. 렌더 순서를 확인합니다. 렌더 순서 자동 설정에서는 피부 땀을 렌더 큐 **2350**에 그립니다. 2459 이상인 바디 마테리얼에 **그대로 두기**를 골랐다면 그 마테리얼이 덮는 곳에서 땀이 가려집니다. [설치 창이 바디 마테리얼을 2349로 낮출지 물음](#render-queue-question)을 확인해 주십시오.
7. Play Mode를 종료하고 `CookiTools → RealSweatSystem → Setup／Uninstall`을 연 뒤 <strong>[설치 / 업데이트]</strong>를 다시 누릅니다.
8. 업로드 단계의 다른 도구가 Body를 교체하거나 병합한다면 [Unity에서는 정상인데 VRChat에서만 깨짐](#it-works-in-unity-but-breaks-only-in-vrchat)으로 이어서 확인해 주십시오.

## 설치 창에 '이전 버전으로 설치되었습니다'가 나옴 {/* #installed-with-an-older-version */}

아바타가 1.x로 설치되어 있습니다. 아바타마다 <strong>[설치 / 업데이트]</strong>를 한 번 눌러 주십시오. **FX에 적용만으로는 이 업데이트가 되지 않습니다.** 백업을 포함한 전체 절차는 [1.x에서 업데이트하는 방법](./quick-start.mdx#updating-from-1x)을 따라 주십시오.

## 설치 창이 같은 버전으로 다시 임포트하라고 함 {/* #mixed-module-versions */}

Base와 Effects의 버전이 다릅니다. 보유한 Base／Effects 모듈을 모두 같은 버전으로 기존 파일 위에 임포트한 뒤 설치 창을 다시 열어 주십시오. 버전이 섞여 있는 동안에는 설치와 아바타 빌드가 의도적으로 중단됩니다. 제거할 필요는 없습니다.

## 설치 창이 바디 마테리얼을 2349로 낮출지 물음 {/* #render-queue-question */}

피부 땀은 렌더 큐 2350에 그립니다. 바디 렌더러(땀을 넣는 렌더러)에 2350 이상에 그려지는 불투명·Cutout 마테리얼이 있으면 <strong>[설치 / 업데이트]</strong>가 한 번 묻습니다.

- <strong>2349로 낮추기 (권장)</strong>를 고르면 마테리얼마다 원래 큐를 기억해 두고 2349로 낮춥니다. <strong>[제거]</strong>하면 원래 큐로 되돌립니다. 그 사이에 직접 바꾼 큐는 그대로 둡니다.
- **그대로 두기**를 고르면 땀을 그 마테리얼 중 가장 높은 큐 + 1에 그리며, 2459를 넘지 않습니다. 바디가 2459 이상이면 그대로 둔 땀은 그 마테리얼이 덮는 곳에서 가려집니다.
- 고른 답은 아바타마다 기억합니다. 그대로 두기를 고른 뒤 다시 정하려면 **고급 설정 > 호환성**의 <strong>[다시 묻기]</strong>를 누른 뒤 <strong>[설치 / 업데이트]</strong>를 눌러 주십시오.

마테리얼 에셋 자체를 바꾸므로 같은 마테리얼을 쓰는 다른 아바타, 프리팹, 씬에도 적용됩니다. 바꾸지 않는 마테리얼은 [호환성](./compatibility.mdx#render-queue-and-shadows)을 확인해 주십시오.

## 땀 메뉴가 없거나 일부만 보임 {/* #the-sweat-menu-is-missing-or-incomplete */}

메뉴 항목은 임포트한 모듈과 설치 옵션에 따라 달라집니다.

- **상대 저부하**에는 Base가 필요합니다.
- **이펙트**와 그 개별 토글에는 Effects가 필요합니다.
- **몸 김·입김 진하기**는 설치 창에서 선택형 동기화 래디얼을 고른 경우에만 나타납니다.
- <strong>물방울 입체감(테셀레이션 / 고부하)</strong>은 물방울 입체감을 설치한 경우(**입체 (고부하)** 표현, 또는 **고급 설정 > 품질·부하**의 물방울 입체감 토글)에만 나타납니다.
- v2.0.0에서 'VRC 라이트 볼륨' 토글이 없어졌고, '표면 땀 숨기기'의 이름이 '피부 땀 숨기기'로 바뀌었습니다.

기대한 항목이 없다면 다음을 확인합니다.

1. Play Mode를 종료하고 모든 컴파일 오류를 해결합니다.
2. 프로젝트에 **Modular Avatar**가 설치되어 켜져 있는지 확인합니다.
3. 필요한 Base／Effects 모듈을 임포트했는지, Full Pack이라면 버전이 같은지 확인합니다.
4. `CookiTools → RealSweatSystem → Setup／Uninstall`을 열고 <strong>[설치 / 업데이트]</strong>를 누릅니다.
5. Gesture Manager나 Play Mode 미리보기를 새로 시작해 현재 메뉴 상태를 다시 만들게 합니다.

## Tuning 값을 바꿨지만 반영되지 않음 {/* #tuning-changes-are-not-applied */}

아바타 루트 아래에 생성된 **RealSweat** 오브젝트를 선택하고 **RealSweatSystem Tuning** 컴포넌트를 사용합니다.

- 땀 품질은 마테리얼 품질을 즉시 바꾸고, 땀 스타일은 그 아바타의 모든 땀 마테리얼에 바로 적용됩니다.
- 자동 반응, 사용자 지정 곡선, 낙하 물방울, 털림 파티클, 입김, 몸 김은 **FX에 적용**이 필요합니다.
- **바디 Shadow Strength 따라가기**는 **[설치 / 업데이트]** 또는 **FX에 적용**을 누를 때 선택한 바디 마테리얼을 읽습니다. 실시간 링크가 아닙니다.
- **FX에 적용**에서 설치 구성 변경 안내가 나오면, 수치 조정보다 먼저 <strong>[설치 / 업데이트]</strong>를 눌러 주십시오. 이펙트를 추가·제거하는 변경은 FX에 적용만으로 처리되지 않습니다.
- 1.x 업데이트에서 <strong>[설치 / 업데이트]</strong>를 누르기 전에 바꾼 모양 값은 그 버튼을 누를 때 다시 새 기본값이 됩니다. 모양은 업데이트를 마친 뒤에 다듬어 주십시오.

## 임포트나 셰이더 컴파일이 오래 걸림 {/* #import-or-shader-compilation-takes-a-long-time */}

처음 패키지를 임포트하면 Unity가 에셋 임포트, 셰이더 컴파일, Asset Database 갱신을 함께 진행하므로 오래 걸릴 수 있습니다. 이 컴파일 시간은 셰이더의 인게임 실행 부하와는 다릅니다.

- 설치 창을 열거나 Play Mode에 들어가기 전에 Unity의 임포트와 셰이더 컴파일 표시가 끝날 때까지 기다려 주십시오.
- Unity가 에셋을 처리하는 동안 설치 창을 반복해서 누르지 마십시오.
- 임포트가 끝났다고 판단하기 전에 **Console의 첫 컴파일 오류**를 해결해 주십시오.
- 이후의 임포트는 Unity가 캐시를 다시 쓰므로 빨라질 수 있습니다. 캐시 동작은 PC와 프로젝트에 따라 다릅니다.
- 큰 프로젝트에서는 1.x 업데이트 뒤 첫 <strong>[설치 / 업데이트]</strong>가 조금 걸릴 수 있으며, 진행 막대가 보입니다.

## 1.x에서 업데이트하기

[1.x에서 업데이트하는 방법](./quick-start.mdx#updating-from-1x)을 따라 주십시오. 요약하면, 프로젝트 밖에 백업하고, 먼저 제거하지 말고 보유한 모듈을 모두 같은 v2.0.0으로 기존 파일 위에 임포트한 뒤, 아바타마다 <strong>[설치 / 업데이트]</strong>를 한 번 누릅니다. **FX에 적용만으로는 업데이트가 되지 않습니다.**

## Play Mode나 VRChat에서 얼굴이 깨짐 {/* #the-face-breaks-in-play-mode-or-vrchat */}

이전 Real Sweat 구성이 Write Defaults OFF Face Tracking Animator와 충돌할 때 생길 수 있습니다.

1. 보유한 모듈을 모두 같은 현재 버전으로 업데이트합니다.
2. 생성된 Animator 항목이나 Merge Animator Priority에 진단용으로 한 변경을 되돌립니다.
3. <strong>[설치 / 업데이트]</strong>를 다시 누릅니다.
4. 얼굴 표정, 땀 토글, 자동 모드가 함께 동작하는지 확인합니다.

Animator 순서를 직접 바꾸는 것을 영구적인 회피책으로 쓰지 마십시오.

## MMD 댄스 중 표정·립싱크가 멈춤 {/* #expressions-or-lip-sync-stop-during-an-mmd-dance */}

1. 보유한 모듈을 모두 같은 현재 버전으로 업데이트하고 <strong>[설치 / 업데이트]</strong>를 한 번 누릅니다.
2. **Write Defaults 호환 방식**을 <strong>자동 감지 (권장)</strong>로 설정합니다.
3. Modular Avatar를 업데이트하고, 대상 구성에 필요하다면 MMD World Support를 켭니다.
4. Play Mode뿐 아니라 실제로 사용할 MMD 월드에서 표정, 립싱크, 땀 표시, 자동 모드를 확인합니다.

외부 FX State가 모두 WD ON이면 생성되는 RealSweat State도 WD ON으로 맞춥니다. WD OFF, ON/OFF 혼합 또는 판정 불가 구성은 호환 구조를 유지하지만, 월드마다 FX 레이어 제어 방식이 다르므로 모든 MMD 월드에서의 동작을 보장할 수 없습니다.

RealSweat만 WD ON으로 강제하면 외부 State가 WD OFF일 때 ON/OFF 혼합 구성이 다시 생길 수 있습니다. 대상 아바타나 MMD 환경이 전체 WD ON FX를 요구한다는 것을 알고 있는 경우가 아니라면 강제 모드를 영구적인 회피책으로 쓰지 마십시오.

## 땀 표시 또는 자동 모드가 작동하지 않음 {/* #sweat-display-or-auto-mode-does-not-work */}

- **땀 표시**가 켜져 있는지 확인합니다.
- 수동으로 조작하려면 자동 모드를 끄고 땀 %를 조절합니다.
- 자동 모드는 아바타가 Humanoid이고 필요한 뼈 참조가 있는지 확인합니다. 자동 모드에는 Humanoid Animator와 MA Bone Proxy가 필요하며, 조건을 충족하지 않으면 수동 모드만 설치됩니다.
- 생성된 Animator나 그 순서를 직접 편집하지 마십시오.
- 새 버전을 임포트한 뒤에는 <strong>[설치 / 업데이트]</strong>를 다시 눌러 주십시오.

## 복제한 아바타와 생성 파일을 공유한다는 경고가 나옴 {/* #duplicate-avatar-shares-generated-files */}

먼저 조정할 아바타에서 <strong>[설치 / 업데이트]</strong>를 눌러 주십시오. 선택한 아바타의 생성 파일만 분리하며, 다른 복제 아바타를 삭제할 필요는 없습니다.

같은 아바타를 다른 씬이나 프리팹으로 복제해 저장해 두었다면, 닫혀 있는 복제본은 Tuning 인스펙터의 경고에 나오지 않으므로 분리하기 전에 Tuning을 바꾸면 복제본의 땀 설정도 함께 바뀝니다. **FX에 적용**은 저장된 씬과 프리팹도 확인하고, 복제본이 같은 생성 파일을 쓰면 아무것도 바꾸지 않고 이 경고를 보여 줍니다.

## 바디 메쉬가 감지되지 않음

바디 메쉬는 자동으로 찾으며, 결과는 **땀을 넣을 곳** 줄에 보입니다. 찾지 못했거나 다른 Renderer가 보인다면, 올바른 피부용 `SkinnedMeshRenderer`가 붙은 Hierarchy 오브젝트를 사용해 주십시오. Project 창의 `.fbx`나 Mesh 에셋은 사용할 수 없습니다. Renderer에는 유효한 메쉬와 하나 이상의 유효한 Submesh가 있어야 합니다.

실험적 추가 대상은 **고급 설정**에서 따로 추가하며, `SkinnedMeshRenderer` 컴포넌트여야 합니다.

## 땀이 다른 마테리얼 슬롯에 표시됨

마테리얼이 여러 개인 Body라면 **고급 설정 > 땀을 넣을 곳**에서 피부 마테리얼만 체크한 뒤 <strong>[설치 / 업데이트]</strong>를 다시 눌러 주십시오. Element 0이 피부라고 가정하지 마십시오.

## 추가 대상이 복구 필요로 표시되거나 빌드가 중단됨 {/* #an-additional-target-shows-repair-required-or-blocks-the-build */}

실험적 대상을 끄기 위해 RealSweat이 생성한 마테리얼이나 Renderer 슬롯을 삭제·비우기·이동·교체·병합하지 마십시오. 생성 마테리얼／슬롯의 누락 또는 변경은 설치 손상으로 처리되어 Tuning에 **복구 필요**로 표시되며, 아바타 빌드는 대상을 조용히 생략하지 않고 중단됩니다.

1. 생성된 **RealSweat** 오브젝트를 선택합니다.
2. **RealSweatSystem Tuning**에서 **추가 대상 관리...** 또는 <strong>설치 창에서 복구...</strong>를 누릅니다.
3. 대상을 유지하려면 Renderer와 Element를 확인한 뒤 <strong>[설치 / 업데이트]</strong>를 눌러 마테리얼／슬롯, 셸, Rest 데이터, 애니메이션, 선택형 낙하 물방울을 다시 만듭니다.
4. 제거하려면 목록의 `-`로 뺀 뒤 <strong>[설치 / 업데이트]</strong>를 누릅니다.

Real Sweat System의 Console 안내는 선택한 도구 UI 언어를 따릅니다. Unity／NDMF 예외 제목과 스택 트레이스는 영어로 남을 수 있습니다.

## Tangent가 없다는 경고

<strong>안전한 사본 생성 (권장)</strong>을 골라 주십시오. 알맞은 Tangent 데이터가 없는 원본 메쉬를 위한 지원 방법입니다.

<a id="unity-vrchat-only" />

## Unity에서는 정상인데 VRChat에서만 깨짐 {/* #it-works-in-unity-but-breaks-only-in-vrchat */}

Real Sweat System이 준비한 뒤 최적화 도구, 리타겟 도구 또는 다른 업로드 단계 도구가 Body Renderer나 메쉬를 교체하고 있을 수 있습니다.

- 그 도구가 선택한 Body를 바꾸는지 확인합니다.
- 땀 대상 Submesh와 마테리얼 대응을 유지합니다.
- 필요한 최종 메쉬 데이터를 읽을 수 있게 유지합니다.

그 도구에 제외 기능이 있다면 Real Sweat System에서 사용하는 Body Renderer를 제외 목록에 추가해 주십시오.

Body를 제외할 수 없는 도구와의 호환성은 보장할 수 없습니다. 아바타를 백업한 뒤 그 도구를 끈 상태와 결과를 비교해 주십시오.

도구 설정을 바꾼 뒤에는 Edit Mode에서 최종 Body를 선택하고 <strong>[설치 / 업데이트]</strong>를 다시 눌러 주십시오. Play Mode와 실제 VRChat 업로드 결과를 모두 확인해 주십시오. Real Sweat System은 나중에 다른 빌드 도구가 임의로 수행하는 메쉬 교체를 자동으로 복구할 수 없습니다.

## 설치 후 기존 PhysBone이 움직이지 않음 {/* #an-existing-physbone-stops-moving-after-installation */}

Real Sweat System은 자동 모드용 PhysBone과 파라미터를 `RealSweat` 아래에 추가합니다. 가슴 PhysBone 같은 아바타의 기존 PhysBone을 변경하거나 삭제하는 구조가 아닙니다.

1. Console을 Clear하고 Play Mode에 들어가 처음 발생한 Error 또는 Warning을 확인합니다.
2. 뼈, PhysBone, Animator 레이어, 파라미터를 병합하거나 최적화하는 다른 빌드 도구가 있는지 확인합니다.
3. 움직이지 않는 PhysBone과 Real Sweat의 움직임추가 같은 Root Transform, 파라미터, 처리 대상으로 합쳐지지 않았는지 확인합니다.
4. 그 도구에 Body Renderer 제외 기능이 있다면 Real Sweat System에서 사용하는 Body Renderer를 제외 목록에 추가합니다. Body를 제외할 수 없다면 그 도구와의 호환성은 보장할 수 없습니다.

Real Sweat System을 제거한 뒤에도 기존 PhysBone이 움직이지 않는다면, Real Sweat이 생성한 범위 밖의 변경이 남아 있을 수 있습니다. 백업 아바타와 비교하고, 빌드 도구를 하나씩 분리해 확인해 주십시오.

## Rest 데이터를 다시 만들 수 없음

최종 원본 메쉬를 읽을 수 있는지, 선택한 땀 Submesh가 아직 있는지 확인해 주십시오. <strong>[설치 / 업데이트]</strong>를 다시 누르기 전에 **땀을 넣을 곳** 줄과 **고급 설정 > 땀을 넣을 곳**을 확인해 주십시오.

**Rest Vertex Data Baker**는 지원·고급 유지보수 도구입니다. 평소 사용에는 보통 필요하지 않습니다. 직접 실행하기 전에 [보조 도구](./tools.mdx)를 확인해 주십시오.

## 테셀레이션 물방울이 의상을 뚫고 보임

`CookiTools → RealSweatSystem → Clothing Fix`를 열어 해당 의상에 적용하거나, <strong>물방울 입체감(테셀레이션 / 고부하)</strong>를 꺼서 No Tess를 사용해 주십시오. 전체 절차와 주의사항은 [보조 도구](./tools.mdx)를 확인해 주십시오.

## Effects만 설치했는데 파티클이 보이지 않음

Effects Module은 Body를 수정하지 않지만, 방출 표면으로 Body Mesh가 필요합니다. **땀을 넣을 곳** 줄에 올바른 Body가 보이는지, 다음 메뉴에서 파티클 토글이 켜져 있는지 확인해 주십시오.

**땀 → 이펙트**

## 낙하 물방울 또는 바닥 물자국이 보이지 않음 {/* #falling-drops-or-floor-stains-are-not-visible */}

1. **고급 설정 > 설치할 이펙트**에서 낙하 물방울을 골랐는지 확인합니다. 바닥 물자국은 낙하 물방울의 충돌 하위 이펙트이므로 낙하 물방울도 필요합니다.
2. **땀 → 이펙트**에서 **전체 이펙트**, **낙하 물방울**, **바닥 물자국**을 켭니다. 수동 테스트에서는 자동 모드를 끄고 <strong>땀 %</strong>를 100%로 올립니다.
3. 낙하 물방울은 보이지만 바닥 물자국만 없다면 **Default** 또는 **Environment** 레이어의 Collider가 있는 월드 바닥에서 확인합니다.
4. 낙하 물방울이나 바닥 물자국이 바닥 위 공중에 떠 보이면, 아바타 안이나 아래에 있는 Unity 물리 Collider(몸, 발, 의상, 액세서리, 테스트 오브젝트의 Box, Capsule, Mesh Collider 등)가 **Default** 또는 **Environment** 레이어를 사용해 월드 바닥보다 먼저 충돌을 가로챘을 수 있습니다. VRC PhysBone Collider를 말하는 것이 아닙니다. 의심되는 Unity Collider를 하나씩 임시로 꺼서 격리 테스트해 주십시오. 끈 뒤 월드 바닥에 물자국이 생기면 중간 Collider가 원인입니다.
5. 특정 Body에서만 낙하 물방울이 전혀 나오지 않고 다른 아바타에서는 정상이라면, Play Mode를 종료하고 설치 창의 **문제 해결** 탭을 엽니다.
6. <strong>[해결 설정 적용]</strong>을 누르고 씬을 저장한 뒤 Play Mode와 **Build & Test** 양쪽에서 확인합니다.
7. 이 선택형 호환 설정은 설치된 낙하 물방울과 몸을 흔들 때 튀는 물방울이 Body의 내장 버텍스 컬러를 무시하게 합니다. Body 메쉬·마테리얼·FX 컨트롤러·바닥 물자국 설정은 수정하지 않으며, 적용하기 전의 기본 동작도 바뀌지 않습니다.
8. 개선되지 않으면 문의하기 전에 <strong>[기본 상태로 되돌리기]</strong>를 누르고, Renderer, Element, 메쉬 Import 설정, 파티클 Shape 스크린샷을 첨부해 주십시오.

낙하 물방울만 진단하기 위해 Face Renderer에 피부 표면 땀 설치를 다시 실행하지 마십시오. 선택한 표면 대상이 바뀝니다.

## 첫 빌드는 실패하고 두 번째 빌드는 성공함

임포트 직후에는 셰이더 컴파일과 Asset Database 처리가 아직 진행 중일 수 있습니다. Unity의 임포트가 끝날 때까지 기다리고 **Console의 첫 오류**를 해결한 뒤 다시 빌드해 주십시오. 두 번째 빌드가 성공했다고 해서 첫 빌드의 오류를 모두 무시해도 된다는 뜻은 아닙니다.

<a id="invalid-aabb-exhale" />

## Invalid localAABB 오류가 Exhale을 가리킴 {/* #invalid-localaabb-mentions-exhale */}

Console에 invalid local AABB 오류가 반복되고 메시지가 입김 오브젝트를 가리킨다면 다음을 확인합니다.

1. 아바타 Hierarchy에 잘못된 Transform이나 극단적인 스케일 값이 없는지 확인합니다.
2. 입김을 잠시 꺼서 반복 기록이 멈추는지 확인합니다.
3. 현재 버전을 사용합니다.

입김 오브젝트의 Bounds 오류와 얼굴 Animator 충돌은 서로 다른 문제일 수 있으므로 각각 따로 확인해 주십시오.

<a id="uninstall-reinstall" />

## 제거·재설치·모듈 변경 {/* #uninstall-reinstall-or-change-modules */}

먼저 아바타 또는 프로젝트를 백업해 주십시오.

### 아바타에 설치한 구성 제거하기

1. `CookiTools → RealSweatSystem → Setup／Uninstall`을 엽니다.
2. **제거** 탭을 선택하고 아바타를 지정합니다.
3. <strong>[제거]</strong>를 누르고 Unity가 작업을 마칠 때까지 기다립니다. 오래 걸리는 단계에서는 진행 막대가 나오고, 결과는 버튼 바로 아래에 나옵니다.
4. 생성된 **RealSweat** 오브젝트가 사라졌는지 확인합니다.
5. Base 또는 Full Pack이라면 메인 Body와 추가 대상이 생성 RealSweat 메쉬를 더 이상 참조하지 않고, 설치 창이 추가한 RealSweat 마테리얼 슬롯이 없어졌는지 확인합니다. Effects만 설치한 경우에는 Body 메쉬와 마테리얼을 바꾸지 않으므로 이 확인이 필요하지 않습니다.
6. 업로드 전에 아바타를 테스트합니다.

`RealSweat` 오브젝트나 컴포넌트만 직접 삭제하지 마십시오. 제거는 바디 메쉬／마테리얼과 외부 이펙트 오브젝트를 복원해야 합니다. Modular Avatar 비파괴 방식이라 메뉴／파라미터／FX는 다음 빌드에서 자동으로 원래대로 돌아갑니다. 직접 만든 땀 마테리얼／슬롯은 건드리지 않습니다.

제거는 설치 오브젝트와 하위 내용, 해당 설치 전용 생성 폴더를 함께 정리합니다. 현재 작업 씬의 다른 아바타나 오브젝트가 공유하는 생성 파일은 보존하며, 저장된 다른 씬이나 프리팹이 같은 생성 파일을 쓰거나 그 확인을 끝내지 못하면 생성 폴더를 남깁니다. 원본 바디·의상·외부 에셋은 삭제하지 않습니다. 원본 메쉬 복원이 불가능하면 제거를 중단하므로, 먼저 원본 메쉬 연결을 확인해 주십시오. 설치할 때 2349로 낮춘 바디 마테리얼은 원래 렌더 큐로 돌아갑니다.

### `RealSweat` 오브젝트만 직접 삭제한 경우 {/* #manual-delete-recovery */}

설치 창은 Body Renderer를 땀 표현용 Submesh가 추가된 생성 메쉬로 교체하고 RealSweat 마테리얼 슬롯을 추가할 수 있습니다. 원본／생성 메쉬의 복원 정보는 생성된 `RealSweat` 오브젝트에 저장되므로, 이 오브젝트만 삭제하면 메뉴·파라미터·FX는 다음 빌드에서 빠지더라도 Body에는 생성 메쉬와 땀 마테리얼 슬롯이 남을 수 있습니다.

1. **Hierarchy에서 `RealSweat` GameObject만 삭제했고 Project 에셋은 삭제하지 않은 경우에 한해**, 삭제 직후 **Ctrl+Z**로 오브젝트를 되살린 뒤 <strong>[제거]</strong>를 누릅니다.
2. Undo가 불가능하면 현재 아바타를 백업하고 `Assets/CookiTools/Generated`를 삭제하지 마십시오.
3. Body의 **Skinned Mesh Renderer > Mesh**를 설치 직전의 정확한 원본 메쉬로 복원합니다. 설치 전 백업이나 원본 Prefab을 사용하고, 가능하면 Mesh 프로퍼티만 Revert합니다.
4. 원본 메쉬를 연결한 상태에서 <strong>[제거]</strong>를 누릅니다. 소유권 복구 안내가 계속 표시될 때만 <strong>[설치 / 업데이트]</strong>를 한 번 누른 뒤 다시 제거합니다.
5. 자동 복구가 설치 상태를 확인하지 못하면 같은 백업을 기준으로 Body의 **Materials** 배열과 추가 대상 Renderer도 설치 전의 참조·순서·슬롯 수로 복원합니다.

:::warning[Generated 폴더를 삭제한 경우에는 Ctrl+Z 복구를 전제로 하지 마십시오]
[아래의 Generated 폴더 복구 절차](#if-the-generated-folder-was-deleted-and-the-body-disappeared)에 따라 설치 전의 정확한 원본 Body Mesh를 먼저 다시 연결해 주십시오.
:::

:::warning[생성 Body 메쉬가 연결된 상태에서 설치 / 업데이트를 누르지 마십시오]
`RealSweat_BodyShellMesh` 같은 생성 Body 메쉬가 연결된 상태에서 <strong>[설치 / 업데이트]</strong>를 바로 누르지 마십시오. 원본 추적 오브젝트가 없으면 생성 메쉬를 새 원본으로 잘못 취급할 수 있습니다. 설치 직전 메쉬를 확인할 수 없다면 생성 에셋을 강제로 삭제하지 말고 백업 또는 깨끗한 원본 아바타와 비교하여 복구해 주십시오.
:::

### `Generated` 폴더를 삭제한 뒤 Body가 사라져 보이는 경우 {/* #if-the-generated-folder-was-deleted-and-the-body-disappeared */}

Base 또는 Full Pack 설치는 땀용 Submesh가 추가된 생성 Body 메쉬를 `Assets/CookiTools/Generated/<아바타 이름>`에 저장하고 Body Renderer에 연결할 수 있습니다. 이 폴더나 이를 포함한 `CookiTools` 폴더 전체를 직접 삭제하면 Body가 참조하던 메쉬 에셋도 없어져 Body가 보이지 않을 수 있습니다. `Assets/CookiTools/RealSweatSystem` 제품 폴더만 삭제했다면 생성 메쉬는 보통 별도 폴더에 남아 있으므로, 먼저 보유한 같은 버전의 패키지를 다시 임포트해 주십시오.

1. Play Mode를 종료하고 현재 아바타를 백업합니다. 제품 파일을 다시 임포트했더라도 아직 <strong>[설치 / 업데이트]</strong>는 누르지 마십시오.
2. 원본 아바타 Prefab 또는 설치 전 백업을 기준으로 Body의 **Skinned Mesh Renderer > Mesh**에 설치 직전의 정확한 원본 메쉬를 다시 연결합니다. 가능하면 Prefab의 Mesh 프로퍼티만 **Revert**합니다.
3. 추가 땀 대상 Renderer가 있었다면 각 메쉬도 원본으로 복원합니다. Body와 추가 대상의 **Materials** 배열에 Missing 또는 RealSweat 슬롯이 남았다면 같은 백업을 기준으로 참조·순서·슬롯 수도 복원합니다.
4. RealSweatSystem을 계속 사용하려면 보유한 Base／Effects를 모두 같은 버전으로 임포트한 뒤 <strong>[설치 / 업데이트]</strong>를 누릅니다. 제거하려면 원본 메쉬가 연결된 상태에서 <strong>[제거]</strong>를 사용합니다.

정확한 원본 메쉬를 확인할 수 없다면 임의의 메쉬를 연결하거나 Missing 상태에서 <strong>[설치 / 업데이트]</strong>를 누르지 말고, 설치 전 백업 또는 RealSweatSystem이 설치되지 않은 깨끗한 아바타와 비교하여 복구해 주십시오.

### 재설치 또는 업데이트

1. 원하는 현재 패키지를 기존 파일 위에 임포트합니다. 1.x에서 업데이트할 때는 먼저 제거하거나 기존 `RealSweat` 오브젝트 또는 `Assets/CookiTools/Generated`를 삭제하지 말고, [1.x에서 업데이트하는 방법](./quick-start.mdx#updating-from-1x)을 따라 주십시오.
2. Base와 Effects를 함께 설치했다면 정확히 같은 버전으로 맞춥니다.
3. `CookiTools → RealSweatSystem → Setup／Uninstall`의 **설치** 탭을 엽니다.
4. **아바타**, **땀을 넣을 곳** 줄, **고급 설정 > 땀을 넣을 곳**, 실험적 추가 대상을 확인합니다.
5. <strong>[설치 / 업데이트]</strong>를 누른 뒤 수동 모드, 자동 모드, 얼굴, 설치한 이펙트를 확인합니다.

Base 또는 Effects를 Full Pack으로 늘리려면 빠진 모듈을 같은 버전으로 임포트하고 <strong>[설치 / 업데이트]</strong>를 다시 눌러 주십시오. Full Pack에서 한 모듈로 돌아가려면 먼저 아바타 설치를 제거하고, 더 이상 쓰지 않을 모듈의 패키지 파일을 Unity 프로젝트에서 지운 뒤, 남은 모듈로 다시 설치해 주십시오.

:::warning[수동 개조는 제거되지 않습니다]
지원되는 설치 밖에서 직접 만든 마테리얼, Renderer 슬롯, Rest 에셋, 애니메이션 변경은 제거가 지우지 않습니다. 지원되지 않는 수동 변경은 백업에서 복원해 주십시오.
:::

## Microsoft Defender가 다운로드를 경고 또는 차단함 {/* #microsoft-defender-warns-about-or-blocks-the-download */}

일부 환경에서 v1.0.0 배포 파일에 표시된 Microsoft Defender 경고는 Microsoft 재분석을 통해 오탐(False Positive)으로 확인되었으며, 관련 탐지 기준도 Microsoft 측에서 갱신되었습니다.

다만 Defender 보안 인텔리전스와 클라우드 기반 보호의 갱신 시점은 PC마다 달라, 일부 환경에서는 이전 경고가 일시적으로 남을 수 있습니다.

- Windows Security에서 Microsoft Defender 보안 인텔리전스를 최신 상태로 갱신합니다.
- BOOTH 구매 라이브러리에서 현재 버전을 다시 다운로드합니다.
- 경고가 계속되면 정확한 탐지 이름, 파일 이름과 Real Sweat System 버전을 확인합니다.

## 자주 묻는 사용 팁 {/* #common-usage-tips */}

### 본인 1인칭에서도 입김 보기

입김이 본인 1인칭 시점에 보이지 않는 것은 정상적인 기본값입니다. 본인에게도 보이게 하려면 Tuning의 **내 시점에서도 입김 보기**를 켜 주십시오. 유효한 Head 본과 MA Visible Head Accessory가 포함된 Modular Avatar 버전이 필요합니다. MA Visible Head Accessory를 찾을 수 없다는 안내가 나오면 VCC에서 Modular Avatar를 업데이트해 주십시오.

Gesture Manager만 보지 말고 VR에서 빌드해 확인해 주십시오. 아바타 크기에 따라 파티클이 얼굴이나 카메라와 겹칠 수 있어 기본값은 꺼짐입니다.

### 원하지 않는 부위에 땀이 나지 않게 하기

땀이 나지 않아야 할 곳은 Tuning의 **바디 표면 스폰 마스크**로 정해 주십시오. 붙어 있는 물방울·젖은 막·Tess 변위의 생성 영역을 제한합니다. 마스크는 UV0를 사용하므로 Body의 UV0 배치에 맞춰 칠해 주십시오.

흐른 자국, 광택, Tess 변위를 포함한 표면 최종 결과 전체를 어느 영역에서 숨기려면 **바디 표면 표시 마스크**를 사용해 주십시오. 회색조 값을 정확히 쓰려면 **sRGB (Color Texture)를 꺼서** 가져와 주십시오. 두 마스크 모두 낙하 물방울, 바닥 물자국, 입김, 몸 김 파티클에는 영향을 주지 않습니다.

### 반짝임이나 흘러내리는 물방울을 차분하게 하기

생성된 땀 마테리얼의 인스펙터에서 **빠른 설정 > 반짝임 크기**와 **반짝임 세기**는 물방울에 비친 빛을 바꾸고(기본값 둘 다 `1.5`, `1`로 낮추면 더 차분한 모습), **빠른 설정 > 땀 흐름**은 흘러내리는 물방울의 수를 정합니다(`0`이면 제자리에 머물고, `2`면 대부분 흘러내림). **기본 모습으로 되돌리기**를 누르면 모양 값이 기본값으로 돌아갑니다.

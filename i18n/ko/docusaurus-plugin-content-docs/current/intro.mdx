# Real Sweat System

**Real Sweat System**은 PC용 VRChat 아바타에 실시간 땀 표현을 추가하는 시스템입니다. 래디얼 메뉴에서 <strong>땀 %</strong>를 직접 조절하거나, 몸의 움직임에 따라 땀이 쌓이고 움직임을 멈추면 천천히 마르는 **자동 모드**를 사용할 수 있습니다.

:::info[문서 기준 버전]
이 문서는 **Real Sweat System v2.0.0**을 기준으로 작성되었습니다. 피부 땀 모양, 설치 창, 몸 김을 새로 만든 큰 업데이트입니다. 1.x 설치를 업데이트하려면 [1.x에서 업데이트하는 방법](./quick-start.mdx#updating-from-1x)을 따라 주십시오.
:::

## 표현할 수 있는 효과

- 피부에 맺히는 땀과 물방울. 스타일은 **애니**와 <strong>실사 (기본)</strong> 두 가지입니다.
- 실제 중력을 따라 거의 곧게 내려가는 흘러내리는 물방울과 흐른 자국
- 선택형 **물방울 입체감**: 가까이 있는 물방울이 피부 위로 실제로 솟습니다.
- 떨어지는 땀방울과 짧은 튀김
- 바닥을 어둡게 하는 바닥 물자국
- 각 부위 주변에서 천천히 피어오르는 옅은 몸 김
- Viseme 또는 VRCFT에 반응하는 입김
- 낙하 물방울·몸 김·입김의 선택형 3D 파티클
- 여러 Body Material Element와 별도 Skinned Mesh의 땀(실험적 기능)

피부의 땀은 **Sweat Base Module**, 낙하 물방울·바닥 물자국·입김·몸 김은 **Sweat Effects Module**에 포함됩니다. <strong>Full Pack (Base + Effects)</strong>은 두 모듈을 모두 포함한 완전 구성입니다.

## 시작하기 전에

Real Sweat System에는 다음이 필요합니다.

- Unity 에디터용 Windows (구매 인증이 Windows에서만 동작합니다)
- Unity 2022.3
- VRChat Avatars SDK 3.10.3 이상 (3.10.6까지 확인)
- Modular Avatar
- Direct3D 11을 사용하는 PC 아바타
- PC마다 한 번 하는 [구매 인증](./license-activation.mdx)

Quest 단독 실행 환경은 지원하지 않습니다. 자동 모드는 Humanoid 아바타에서 사용할 수 있으며, 다른 아바타에서도 수동 모드는 사용할 수 있습니다.

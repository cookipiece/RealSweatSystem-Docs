# Real Sweat System

**Real Sweat System**은 PC용 VRChat 아바타에 실시간 땀 표현을 추가하는 시스템입니다. Radial Menu에서 Sweat %를 직접 조절하거나, 몸의 움직임에 따라 땀이 쌓이고 움직임을 멈추면 천천히 마르는 Auto Mode를 사용할 수 있습니다.

:::info[문서 기준 버전]
이 문서는 **v1.0.1**을 기준으로 작성되었습니다.
:::

## 표현할 수 있는 효과

- 피부 표면에 맺히고 흐르는 땀
- 중력 방향을 따라 자연스럽게 내려가는 물방울
- 온몸에서 떨어지는 땀방울
- 바닥에 남는 젖은 자국
- 몸에서 피어오르는 스팀
- Viseme 및 VRCFT 입력에 반응하는 입김

피부 표면의 땀은 **Sweat Base Module**, 낙하 물방울·바닥 자국·스팀·입김은 **Sweat Effects Module**에 포함됩니다. **Full Pack (Base + Effects)**은 두 모듈을 모두 포함한 완전 구성입니다.

# 구매 인증

Real Sweat System 2.0.0은 PC마다 한 번 구매 인증을 합니다. `CookiTools → RealSweatSystem → Purchase Activation`에서 인증 창을 열고, BOOTH 주문번호(Gumroad에서 구매했다면 Gumroad 라이선스 키)를 입력해 주십시오. 인증 창의 언어(English / 한국어 / 日本語)는 창 오른쪽 위에서 바꿀 수 있고, 고른 언어는 Real Sweat System 창에도 적용됩니다.

인터넷은 인증할 때와, 자동 갱신을 위해 3주에 한 번 이상 필요합니다. 아바타 빌드와 업로드에는 필요 없지만, 인증하지 않은 PC에서 업로드하면 이 툴의 효과가 빠집니다.

## 구매별 포함 기능 {/* #modules */}

인증은 모듈마다 따로 합니다.

| 구매 | 인증 창의 「포함된 기능」 | 기능 ID |
|---|---|---|
| Base Module | Base 모듈 | `rss.base` |
| Effects Module | Effects 모듈 | `rss.effects` |
| Full Pack (Base + Effects) | Base 모듈, Effects 모듈 | `rss.base`, `rss.effects` |
| Full Pack + Game & App Integration & Distribution License (BOOTH 전용) | Base 모듈, Effects 모듈, Game & App 라이선스 | `rss.base`, `rss.effects`, `rss.license.game-app` |

- 모듈을 다른 주문으로 샀다면(예: Base를 먼저, Effects를 나중에) 두 번째 주문은 인증 창의 「다른 주문 추가」에 넣어 주십시오. 이 PC에서 인증한 주문의 기능은 모두 합쳐집니다.
- 기능 ID는 [보고 내용 복사]의 내용에 나옵니다.

## 인증이 필요한 것 {/* #what-is-gated */}

- **새 설치:** Real Sweat System이 없는 아바타에서 <strong>[설치 / 업데이트]</strong>를 누를 때입니다.
- **모듈 추가:** <strong>[설치 / 업데이트]</strong>는 프로젝트에 있는 모듈을 늘 모두 설치합니다. 아바타에 아직 없는 모듈이 프로젝트에 있으면(예: Base만 설치한 아바타가 있는 프로젝트에 Effects 패키지를 임포트한 경우), 그 버튼은 그 모듈을 더하므로 그 모듈의 인증을 묻습니다. 인증이 없으면 설치를 취소하고 아무것도 바꾸지 않습니다.
- **Rest Vertex Data Baker (Advanced) > 2. 베이크 및 할당**에는 Base 모듈 인증이 필요합니다. 일반 설치에서는 설치 창이 Rest 데이터를 자동으로 굽고 넣으므로 이 창을 쓸 필요가 없습니다.

인증이 없으면 이유와 오류 코드(CT-LIC-…)를 알려 주는 안내가 뜨고, [인증 창 열기]로 바로 인증할 수 있습니다.

## 막지 않는 것 {/* #not-blocked */}

- **업데이트:** 프로젝트에 있는 모듈이 아바타에 모두 설치되어 있으면 <strong>[설치 / 업데이트]</strong>는 인증을 묻지 않습니다. 1.x로 설치한 아바타도 같습니다.
- **FX에 적용**, <strong>[제거]</strong>, 이미 설치한 아바타의 작동
- **아바타 빌드와 업로드:** 구매 인증 때문에 빌드가 멈추지는 않습니다. 업로드에서 무엇이 빠지는지는 다음 절에 있습니다.
- 30일 동안 갱신하지 못한 인증은 새 설치와 모듈 추가 때만 갱신을 요구합니다. 업로드에서는 효과가 빠지지 않습니다.

## 인증하지 않은 PC에서 업로드할 때 {/* #uploads */}

VRChat SDK로 빌드할 때(Build & Test, 업로드) 아바타에 설치된 모듈마다 이 PC의 인증을 확인합니다. 인증이 없는 모듈은 업로드한 아바타에서 빠지고, 인증된 모듈은 그대로 들어갑니다. 예를 들어 Base 모듈만 인증했다면 피부 땀은 들어가고 Effects 모듈의 효과는 빠집니다.

- 빌드는 실패하지 않고 창도 뜨지 않습니다. 빠진 모듈마다 Console에 `Real Sweat System:`으로 시작하는 경고가 한 줄 남습니다.
- 씬의 아바타, Play Mode, 생성 파일은 바뀌지 않습니다. 인증한 뒤 다시 업로드하면 효과가 들어갑니다.
- 업로드에서 빠질 상황이면 설치 창의 설치 버튼 위에도 같은 안내와 [인증 창 열기] 버튼이 나옵니다.
- 1.x에서 업데이트했다면 업로드하기 전에 인증해 주십시오. 인증하기 전에 업로드하면 효과가 빠집니다.

확인하는 방법은 [업로드하면 땀이나 이펙트가 빠짐](./troubleshooting.mdx#missing-after-upload)에 있습니다.

## Windows 전용 {/* #windows-only */}

구매 인증은 기기 키로 PC에 묶입니다. 이 기기 키는 Windows 데이터 보호 기능(DPAPI)이 Windows 사용자 계정마다 암호화합니다. Mac이나 Linux의 Unity 에디터는 이 키를 만들거나 읽을 수 없으므로 인증할 수 없고, Mac이나 Linux에서 업로드하면 Real Sweat System의 효과가 늘 빠집니다.

## PC 수와 해제 {/* #pcs */}

- 주문(또는 Gumroad 구매) 1건으로 PC를 **동시에 3대까지** 인증할 수 있습니다. Game & App Integration & Distribution License는 10대입니다.
- 한 주문으로 새로 등록할 수 있는 PC는 **30일에 5대까지**입니다. 동시에 쓸 수 있는 PC 수에 2대를 더한 수입니다(Game & App Integration & Distribution License는 12대).
- 여기서 「PC」는 컴퓨터와 Windows 사용자 계정의 조합입니다. Windows를 다시 설치하거나, 다른 Windows 계정으로 쓰거나, 인증 폴더(`%LOCALAPPDATA%\CookiTools\license\`)를 지우면 새 PC로 셉니다.
- 인증 창의 [이 PC 해제]를 누르면 이 PC의 자리가 비워집니다. PC를 바꾸거나 넘기기 전, 또는 Windows를 다시 설치하기 전에 눌러 두면 PC 수를 아낄 수 있습니다. PC 목록에서 예전 PC를 해제하는 것은 7일에 한 번 할 수 있습니다.

## 선물로 받은 경우 {/* #gifts */}

선물로 받은 주문도 다른 주문과 같이 주문번호로 인증합니다. 선물한 분께 주문번호를 받아 입력해 주십시오. 받기 어렵다면 선물을 받은 BOOTH 계정에서 BOOTH 메시지로 상점에 문의해 주십시오. 작가가 선물 주문을 확인하고 주문번호를 알려 드립니다.

## 구매 인증이 없는 이전 버전 {/* #legacy */}

구매 인증이 없는 v1.1.3은 이전 버전 파일로 BOOTH와 Gumroad에 계속 남겨 둡니다. 지원은 2.0.0 이상만 합니다. 2.0.0으로 업데이트한 뒤 되돌리려면 업데이트 전에 만든 백업을 사용하거나, 패키지에 들어 있는 README의 「v1.1.3으로 되돌리기」를 따라 주십시오.

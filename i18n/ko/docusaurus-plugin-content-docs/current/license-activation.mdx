# 구매 인증

PC마다 BOOTH 주문번호(Gumroad에서 구매했다면 Gumroad 라이선스 키)로 한 번 인증합니다. 인증 창은 `CookiTools → RealSweatSystem → Purchase Activation`에서 엽니다.

주문(또는 Gumroad 구매) 1건으로 PC를 동시에 3대까지 인증할 수 있습니다. BOOTH에서만 파는 Game & App Integration & Distribution License는 10대입니다.

인터넷은 인증할 때와, 자동 갱신을 위해 3주에 한 번 이상 필요합니다. 아바타 빌드와 업로드에는 필요 없습니다.

인증 방법, PC 해제, 선물, 오류 코드는 아래 링크의 페이지에서 안내합니다.

- **자세한 안내:** [구매 인증 안내](https://cookistudio.com/license/?lang=ko)
- **개인정보:** [개인정보 처리방침 (구매 인증)](https://cookistudio.com/license/privacy?lang=ko)

# 설치 창·Tuning 옵션 전체 안내

이 페이지는 RealSweatSystem 2.0.0에서 사용자가 정상적으로 조절하는 옵션을 정리합니다. **Base** 표시는 Sweat Base Module, **Effects** 표시는 Sweat Effects Module이 설치된 경우에 나타나는 항목입니다.

## Tuning 컴포넌트 열기

설치를 마친 뒤 Hierarchy에서 아바타를 펼치고, 아바타 루트 바로 아래에 생성된 **RealSweat** 오브젝트를 선택합니다. Inspector에 **RealSweatSystem Tuning**이 있습니다. 설치된 아바타라면 설치 창의 **상태** 줄에 있는 **Tuning 열기** 버튼으로도 열 수 있습니다.

첫 설치가 끝나지 않아 오브젝트가 없다면 Console의 첫 오류를 해결한 뒤 <strong>[설치 / 업데이트]</strong>를 다시 눌러 주십시오. 설치된 `RealSweat` 오브젝트를 직접 삭제했다면 Body를 확인하기 전에 설치를 다시 실행하지 말고, [수동 삭제 복구](../troubleshooting.mdx#manual-delete-recovery)를 따라 주십시오.

## 변경값이 반영되는 시점

| 변경 항목 | 반영 시점 |
|---|---|
| **땀 품질** | 땀 마테리얼의 품질은 즉시 바뀝니다. 낙하 물방울과 몸 김까지 다시 맞추려면 **FX에 적용**을 누릅니다. |
| **땀 스타일** | 그 아바타의 모든 땀 마테리얼과 낙하 물방울·바닥 물자국·튀김에 바로 적용됩니다. |
| **물방울 크기** | 땀 마테리얼에 즉시 반영됩니다. 낙하 물방울과 털림 파티클 크기까지 갱신하려면 **FX에 적용**을 누릅니다. |
| **입체 표현 정밀도** | 설치된 모든 물방울 입체감 마테리얼에 즉시 반영됩니다. |
| **바디 표면 스폰 마스크** / **바디 표면 표시 마스크** | 땀 마테리얼에 즉시 반영됩니다. |
| **처음부터 켜기**, 이펙트 켜기/끄기, 몸 김 위치, **거울 속 몸 김**, **내 시점에서도 입김 보기**, Custom Steam Point, 자동 모드 설정, 이펙트 세부 설정, 성능 및 고급 설정 | **FX에 적용**을 누릅니다. |
| **바디 Shadow Strength 따라가기** | **FX에 적용**이나 <strong>[설치 / 업데이트]</strong>를 누를 때 복사됩니다. |
| 설치 때 제외한 몸 김 위치, 설치한 이펙트의 추가·제거 | <strong>[설치 / 업데이트]</strong>를 누릅니다. |
| 설치 창 옵션: 땀을 넣을 곳, 다른 메쉬, 설치할 이펙트, 몸 김·입김 진하기 메뉴, 3D 파티클, 물방울 튀김, 물방울 입체감 설치, 거울에서도 땀 고품질, 젖을수록 피부 광택, 렌더 순서, Write Defaults | <strong>[설치 / 업데이트]</strong>를 누릅니다. |

누적 그래프는 편집 중인 값을 즉시 미리 보여 주지만, **FX에 적용**을 누르기 전에는 생성된 FX가 바뀌지 않습니다. **FX에 적용**에서 설치 구성 변경 안내가 나오면 먼저 <strong>[설치 / 업데이트]</strong>를 눌러 주십시오. 이펙트를 추가·제거하는 변경은 FX에 적용만으로 처리되지 않습니다.

## 설치 창 옵션

`CookiTools → RealSweatSystem → Setup／Uninstall`을 엽니다. 탭은 **설치** / **문제 해결** / **제거**입니다. 첫 화면에는 꼭 필요한 항목만 두고, 세부 옵션은 **고급 설정**에 접혀 있습니다. 그림은 창 크기와 상관없이 같은 크기로 보이고, 창이 짧으면 스크롤됩니다.

### 첫 화면

| 항목 | 모듈 | 기본값 | 의미 |
|---|---|---|---|
| **아바타** | 공통 | 미지정 | Hierarchy에서 아바타를 고르거나 이 칸에 끌어다 놓습니다. |
| **상태** | 공통 | — | 아바타의 설치 상태를 보여 줍니다. 이전 버전으로 설치한 아바타는 '이전 버전으로 설치되었습니다'라는 노란 상자가 보입니다. **Tuning 열기**는 설치된 `RealSweat` 오브젝트를 선택합니다. |
| **땀을 넣을 곳** | 공통 | 자동 감지 | 바디 메쉬 칸입니다. 자동으로 찾으며, 틀리면 Hierarchy에서 맞는 메쉬를 이 칸에 끌어다 놓습니다. 그 아래에 쓰는 마테리얼이 보입니다. <strong>[바꾸기]</strong>를 누르면 마테리얼 칸 같은 나머지를 정하는 **고급 설정 > 땀을 넣을 곳**이 열립니다. Effects Module만 있으면 이 칸은 **낙하 물방울 위치**입니다. |
| **설치할 이펙트** | Effects | 모두 켜짐 | 체크 상자: **낙하 물방울**, **바닥 물자국**(낙하 물방울 필요), **입김**, **몸 김**. 몸 김이 나오는 곳과 진하기 메뉴는 **고급 설정 > 이펙트**에 있습니다. |
| **피부 땀** | Base | **젖을수록 피부 광택** 켜짐 | 체크 상자 **젖을수록 피부 광택**: 땀이 늘수록 피부가 더 번들거립니다. 끄면 땀 마테리얼의 **젖은 피부 막**이 0이 되고, 인게임 **젖은 피부 막** 토글은 설치되지 않습니다. |
| **땀 스타일** | Base | **실사 (기본)** | 두 그림 가운데 하나를 누릅니다: **애니** 또는 **실사 (기본)**. 창을 다시 열면 그 아바타의 지금 스타일이 선택되어 있습니다. 이 줄은 Base Module이 설치된 경우에만 나옵니다. |
| **표현** | Base / Effects | **기본** | **기본** 또는 <strong>입체 (고부하)</strong>. <strong>입체 (고부하)</strong>는 물방울 입체감, 3D 파티클, 물방울 튀김을 함께 켜고, 그 아래에 **처음부터 켜기**가 나옵니다. **기본**은 이들을 끕니다. Base Module이 있으면 두 선택지가 그림으로, Effects Module만 있으면 버튼으로 나옵니다. <strong>입체 (고부하)</strong> 그림 아래에는 물방울이 가까이나 옆에서 볼 때 솟아 보인다는 설명과, **처음부터 켜기**를 체크하지 않으면 물방울 입체감은 처음에 꺼져 있고 인게임 메뉴에서 켠다는 설명이 있습니다. 꺼 두면 그 메뉴 위치(**땀 > 부하 줄이기**)를 안내 상자로 알려 줍니다. |

| **자동 모드 감도** | 공통 | **균형: 움직임 강도에 비례하는 권장 설정** | **균형: 움직임 강도에 비례하는 권장 설정** 또는 **민감: 작은 움직임에도 더 빠르게 축적**. |
| **[설치 / 업데이트]** | 공통 | — | 아바타에 설치하거나 업데이트합니다. 결과는 누른 버튼 바로 아래 상자에 나오고, 오래 걸리는 단계에서는 진행 막대가 나옵니다. |

### 고급 설정

**고급 설정**에는 아래 묶음이 이 순서로 있습니다. 값을 바꾸면 설치된 상태로 되돌리는 버튼(**설치된 구성으로 되돌리기**)이, 첫 설치 전에는 권장 상태로 되돌리는 버튼(**권장 구성으로 되돌리기**)이 나옵니다.

| 묶음 | 모듈 | 항목과 기본값 |
|---|---|---|
| **땀을 넣을 곳** (Effects Module만 있으면 **낙하 물방울이 나올 마테리얼**) | 공통 | **바디 메쉬**(첫 화면의 **땀을 넣을 곳**과 같은 메쉬. 자동으로 찾으므로 틀렸을 때만 지정합니다)와 **다시 찾기**. 바디 마테리얼이 여러 개라면 피부 마테리얼에만 체크합니다. Effects Module만 있으면 **낙하 물방울이 나올 마테리얼**에서 물방울이 나올 마테리얼 Element를 고릅니다(보통 Element 0). |
| **이펙트** | Effects | 몸 김 아래의 **나오는 곳**: **가슴골**, **양어깨**, **겨드랑이**, **허벅지**(켜짐)와 **고간**, **발**(꺼짐). 첫 화면에서 **몸 김**을 체크했을 때 나옵니다. **몸 김·입김 진하기 메뉴 추가 (+8bit)**(꺼짐). 이펙트 자체는 첫 화면의 **설치할 이펙트** 체크 상자로 고릅니다. |
| **품질·부하** | 공통 | **땀 품질**(**경량** / <strong>저부하(권장)</strong> / **표준**). **물방울 입체감 (테셀레이션, 고부하)**(꺼짐)과 그 아래의 **처음부터 켜기**(Base). **3D 파티클 (고부하)**(꺼짐)과 **물방울 튀김**(표현이 기본이면 꺼짐)(Effects). **거울에서도 땀 고품질 (고부하)**(꺼짐)(Base). |
| **호환성 (문제가 있을 때만)** | 공통 | **렌더 순서 자동 (권장)**(켜짐)과, 이를 끄면 나오는 **땀 렌더 큐**(Base). 바디와 땀의 렌더 큐를 보여 주는 줄('바디 … → 땀 …')이 있고, **그대로 두기**를 고른 뒤에는 여기에 <strong>[다시 묻기]</strong>가 나옵니다. **Write Defaults**(**자동 (권장)** / **WD ON** / **WD OFF**)와 **다시 감지**, 감지 결과. |
| **다른 메쉬에도 땀 넣기 (실험)** | Base | 얼굴 같은 다른 메쉬입니다. 대상마다 Rest 데이터·마스크·드로우 부하가 따로 생깁니다. |

- **거울에서도 땀 고품질 (고부하):** 꺼져 있으면 거울에서는 땀구멍의 작은 물방울을 빼고 그리고, 물방울 입체감도 솟지 않습니다. 켜면 거울에서도 원래 화면과 같게 그리므로 거울 GPU 부하가 증가합니다. 같은 스위치가 땀 마테리얼 인스펙터의 **고급 > 거울**에도 있습니다.
- **몸 김·입김 진하기 메뉴 추가 (+8bit):** 인게임 **몸 김·입김 진하기** 래디얼을 추가합니다(처음 50%). 0%는 불투명도 0.1배, 50%는 기존 표현을 유지하는 1.0배, 100%는 1.5배입니다. 불투명도만 바꾸며 파티클 수와 성능 부하는 줄지 않습니다. 동기화 파라미터를 8bit 더 씁니다.
- **렌더 순서 자동 (권장):** 기본 Body의 땀을 렌더 큐 `2350`에 그립니다. 추가 대상은 `max(바디 땀 렌더 큐(보통 2350), 선택 마테리얼 렌더 큐 + 1)`을 사용합니다. **땀 렌더 큐**는 다른 셰이더가 특정 순서를 요구할 때만 사용해 주십시오. 수동 렌더 큐를 쓰면 바디 마테리얼을 묻거나 바꾸지 않습니다.

바디 Shadow Strength 따라가기, 입체 표현 정밀도, 거울 속 몸 김, 내 시점에서도 입김 보기, 몸 김 위치 직접 추가(Custom Steam Point)는 설치 뒤 `RealSweat` 오브젝트의 Tuning에서 정합니다.

에셋을 쓰기 전에 설치 창은 예정된 모든 파라미터를 Avatar Expression Parameters와 다른 Modular Avatar 선언(접두사·리맵 포함)과 비교합니다. 이름이 겹치면 설치를 멈춥니다. 예상 합계가 256bit를 넘으면 경고한 뒤 계속합니다.

### Write Defaults

**Write Defaults** 드롭다운은 <strong>고급 설정 > 호환성 (문제가 있을 때만)</strong>에 있습니다. 대부분은 **자동 (권장)** 그대로 두면 됩니다.

- **자동 (권장):** 외부 FX State가 모두 WD ON일 때만 RealSweat의 모든 State도 WD ON으로 구성합니다. WD OFF, 혼합 또는 판정 불가 구성은 WD OFF 호환 구조를 사용합니다.
- **WD ON:** RealSweat의 모든 State를 WD ON으로 고정합니다. 아바타의 FX가 모두 WD ON이어야 할 때만 골라 주십시오.
- **WD OFF:** WD OFF 또는 혼합 아바타를 위해 Driver ON / Output OFF 분리 구조를 유지합니다.

**다시 감지**는 아바타의 FX를 다시 확인하고, 드롭다운 아래 줄에 감지 결과가 나옵니다.

### 땀 품질

**땀 품질**(1.1.x의 '전체 땀양', Tuning에서도 같은 이름)은 이제 땀의 품질 단계와 부하를 고릅니다.

| 선택지 | 그리는 내용 |
|---|---|
| **표준** | 전부 그립니다. 가장 무겁습니다. |
| <strong>저부하(권장)</strong> — 새 설치 기본값 | 땀구멍의 작은 물방울만 뺍니다. 대화 거리와 1.5~3 m에서는 표준과 거의 구별되지 않습니다. |
| **경량** | 저부하보다 조금 더 뺍니다. 애니: 흐른 자국의 잔류 방울과 얇은 막 선(막의 광택은 남음). 물방울 배치, 길게 흐르는 물방울 줄, 흐른 자국의 광택은 저부하와 같습니다. 실사: 잔류 방울, 흰 피부의 능선 하이라이트, 길게 흐르는 물방울 줄, 반사 프로브, 아주 작은 물방울을 빼서 물방울 배치가 조금 다릅니다. 경량은 GPU 시간이 저부하와 거의 같습니다. |

- 피부 땀의 양은 세 선택지 모두 같습니다. 땀 % 래디얼이 30%일 때 마테리얼 땀양이 0.30이고, 100%일 때 1.00입니다. 1.1.x에서 경량과 저부하(그때 이름은 '적음')는 같은 자리에서 0.20과 0.65였으므로, 이 둘을 쓰던 아바타는 땀이 전보다 많아 보입니다.
- 낙하 물방울은 지금처럼 표준에서 가장 많고, 저부하와 경량에서는 줄어듭니다. 2D 몸 김은 세 단계 모두 같습니다. 3D 파티클 몸 김은 1.1.3과 같이 저부하와 경량에서 표준의 0.65배입니다.

### 땀 스타일

- **애니**는 또렷한 윤곽과 하이라이트가 있는 물방울이라 멀리서도 잘 보입니다. <strong>실사 (기본)</strong>는 윤곽 없는 투명한 물방울입니다. 물방울을 통해 보이는 피부가 렌즈처럼 살짝 휘어 보입니다. 작은 물방울이 많고, 흰 하이라이트 대신 빛과 주변이 비친 작은 상으로 그리며, 큰 물방울에는 작은 흰 하이라이트가 있습니다. 물방울 사이에는 아주 작은 물방울이 무리 지어 있고, 멀리서는 점 대신 젖은 광택으로 보입니다. 큰 물방울만 흘러내리고, 흐른 자국은 회색 줄 없이 맑고 윤기 있는 줄입니다.
- 실사 물방울의 둘레에는 어두운 테두리, 고리, 접촉 그림자가 없습니다. 그래서 물방울이 피부 위에 돋은 혹처럼 보이지 않습니다. 아주 작은 물방울은 조금 줄였고, 정면에서 본 물방울은 또렷합니다.
- 스타일은 아바타마다 하나입니다. 바디와 다른 메쉬의 땀 마테리얼(입체감 짝 포함)이 모두 같은 스타일을 씁니다. 설치한 뒤에는 Tuning의 **기본 설정 > 땀 스타일**에서 바꿀 수 있고, 마테리얼 인스펙터는 지금 스타일을 보여 주기만 합니다.
- 스타일은 Base Module이 설치된 경우에만 고릅니다. Effects Module만 있으면 설치 창과 Tuning에 땀 스타일이 없고, 낙하 물방울·바닥 물자국·튀김은 실사 모양을 씁니다. 2.0.0으로 이미 설치한 아바타는 그때의 모양을 그대로 씁니다.
- 새 설치와 1.1.x에서 업데이트한 아바타는 실사로 시작합니다. 1.x 아바타에는 저장된 스타일이 없어서 새 기본값을 받습니다. 2.0.0으로 이미 설치한 아바타는 고른 스타일을 그대로 씁니다. 애니를 쓰려면 애니 그림을 고른 뒤 <strong>[설치 / 업데이트]</strong>를 눌러 주십시오.
- 품질 단계는 두 스타일에 똑같이 적용됩니다. 실사의 경량은 아주 작은 물방울도 뺍니다.
- 부하: 실사의 셰이더 명령 수는 애니보다 조금 적습니다(표준 단계 3457 대 3523). GPU 시간은 애니와 비슷하고, 가까이에서 몸통 전체가 화면을 채우면 최대 약 14% 늘어납니다. 물방울 입체감을 켜면 표준에서 애니 입체감의 약 1.07배, 저부하에서 약 0.95배입니다. 아바타는 고른 스타일의 셰이더만 쓰므로, 다른 사람의 첫 로딩은 스타일과 상관없이 비슷합니다.
- 알아 둘 점: 실사에서는 배꼽 위처럼 접힌 곳에서 작은 물방울이 두 쪽으로 갈라져 보일 수 있고, 물방울끼리 실제로 합쳐지지는 않습니다.

### 물방울 입체감 선택지 {/* #droplet-depth-choices */}

물방울 입체감을 켜 두면 가까이에서 물방울과 흘러내리는 물방울이 피부 위로 실제로 솟아, 두 스타일 모두에서 옆에서 봐도 둥글게 보입니다. 흐른 자국, 땀구멍의 작은 물방울, 자국 위 잔류 방울은 솟지 않습니다.

| 입체 표현 정밀도 | 테셀레이션 계수 | 물방울이 솟는 거리 | 입체감이 없을 때와 똑같이 그리는 거리 |
|---|---:|---:|---:|
| **간소화 — 일반 플레이용** (기본) | `2.5` | 약 0.35 m 안 | 약 0.7 m부터 |
| **균형 — 근접 감상용** | `4` | 약 0.6 m 안 | 약 1.5 m부터 |
| **정밀 — 사진 촬영용** | `7` | 약 0.9 m 안 | 약 2.2 m부터 |

물방울 입체감을 설치해도 한 대상에서 두 마테리얼이 함께 그려지지는 않습니다. 메뉴는 물방울 입체감이 있는 모든 땀 슬롯을 Tess와 No Tess 사이에서 함께 전환합니다. <strong>물방울 입체감(테셀레이션 / 고부하)</strong>를 끄면 No Tess 셰이더를 사용하므로 Hull／Domain 테셀레이션 연산도 실행되지 않습니다. **거울에서도 땀 고품질**이 꺼져 있는 거울과 **상대 저부하**에서는 물방울이 솟지 않습니다.

여러 대상을 설정했다면 각 대상은 고른 Tess 또는 No Tess 하나만 그리지만, 별도 Body Element와 Renderer는 각각 땀 드로우를 추가합니다.

### 실험적 대상의 안전 장치

`RealSweatSystem Tuning`은 설치된 추가 대상의 생성 마테리얼／슬롯 상태를 보여 줍니다.

- <strong>추가 대상 관리...</strong>를 누르면 현재 대상 목록이 채워진 설치 창이 열립니다.
- 대상이 **복구 필요**로 표시되면 <strong>설치 창에서 복구...</strong>를 사용합니다.
- 대상을 제거하려면 목록의 `-`로 뺀 뒤 <strong>[설치 / 업데이트]</strong>를 누릅니다.
- 생성된 마테리얼이나 Renderer 슬롯을 삭제·비우기·이동·교체·병합해서 대상을 끄지 마십시오. 손상은 조용히 건너뛰지 않으며, 대상을 복구하거나 제거할 때까지 아바타 빌드가 중단됩니다.

## Tuning 옵션

Tuning 컴포넌트는 **기본 설정**, **이펙트 켜기/끄기**, **자동 모드 설정**, **피부 표면 설정**, **이펙트 세부 설정**, **성능 및 고급 설정** 묶음으로 나뉘고, 그 아래에 **메쉬 및 Rest 데이터 진단**과 **FX에 적용** 버튼이 있습니다. 설치하지 않은 모듈의 묶음은 나오지 않습니다.

### 기본 설정

| 항목 | 모듈 | 기본값 | 범위 | 의미 |
|---|---|---:|---:|---|
| **땀 품질** | 공통 | 저부하(권장) | — | 설치 창과 같은 세 단계입니다. |
| **땀 스타일** | Base | 실사 (기본) | — | 그 아바타의 모든 땀 마테리얼의 모양을 한꺼번에 바꿉니다. |
| **감도 프리셋** | 공통 | 균형 | — | **균형**은 움직임 강도에 비례하고, **민감**은 작은 움직임에서 더 빨리 최대 반응에 도달합니다. 프리셋을 고르면 반응 임계값·포화 지점·상승 / 건조 기준·스무딩 강도가 그 프리셋 값으로 바뀝니다. |
| **땀 축적 배속** | 공통 | `1.0` | `0.25–4` | 프리셋 전체의 자동 누적 속도 배율입니다. |
| **땀 유지시간 배율** | 공통 | `1.0` | `0.5–2` | 건조 시간 배율입니다. 높일수록 땀이 오래 남습니다. |
| **표면 물방울 외형 > 물방울 크기** | Base | `1.6` | `0.5–2.0` | 몸에 붙은 물방울 크기입니다. 기본 크기는 아바타의 몸 크기에 맞춰 자동으로 정해지며, 이 값으로 크기를 더 바꿉니다. |

패턴 밀도 항목은 2.0.0에서 숨겼습니다.

### 자동 모드 설정

**자동 누적 반응**은 감지한 움직임이 시간에 따라 보이는 땀으로 바뀌는 방식을 정합니다.

| 항목 | 기본값 | 범위 | 의미 |
|---|---:|---:|---|
| **수평 민감도 (좌우·앞뒤)** | `1.0` | `0.95–1.10` | 좌우 및 앞뒤 움직임 반응입니다. |
| **상하 민감도** | `1.2` | `0.90–1.30` | 위아래 움직임 반응입니다. 작은 상하 운동이나 스쿼트에는 `1.2`를 권장합니다. |
| **미리보기 방향** | 혼합 | — | **혼합** / **수평** / **수직**. 미리보기만 바꿉니다. 인게임에서는 모든 방향이 계속 활성화됩니다. |
| **움직임 반응** | 접힘 | — | 현재 임계값·포화 지점·스무딩·방향 반응을 보여 주는 미리보기입니다. |
| **누적 프로파일** | 균일 | — | 현재 땀 % 구간에 따라 누적 속도를 바꿉니다. 동기화 파라미터나 런타임 레이어를 추가하지 않습니다. |
| **세부 수치** | 접힘 | `0.1–2` | `0/25/50/75/100%`의 다섯 배율을 편집합니다. |
| **누적 그래프** | 접힘 | — | 일정한 움직임을 가정한 곡선과 95% 도달 예상 시간을 보여 줍니다. 실제 PhysBone 입력은 아바타와 애니메이션에 따라 달라집니다. |

누적 프로파일:

- **균일:** 모든 땀 %에서 같은 배율을 사용합니다. 새 설치의 기본값입니다.
- **자연스럽게 (권장):** 초반은 조금 빠르고 땀 %가 높아질수록 점차 느려집니다.
- **초반 빠르게:** 시작 구간의 누적을 강하게 강조합니다.
- **후반 가속:** 초반은 느리고 후반으로 갈수록 빨라집니다.
- **사용자 지정:** 다섯 지점을 직접 편집합니다.

제공되는 프로파일은 95%까지의 예상 시간이 거의 같게 조정되어 있지만, 마지막 5%는 다를 수 있습니다. 감도·축적 배속·방향 민감도·누적 프로파일은 모두 자동 모드에 함께 영향을 줍니다.

| **몸 김** | **몸 김 위치**: **가슴골**, **양어깨**, **겨드랑이**, **허벅지**(켜짐), **고간**, **발**(꺼짐). **거울 속 몸 김**(**전체 품질** / **낮음 (2D 불투명도 감소)** / **숨김**, 새 설치는 낮음). **추가 기능 — 사용자 지정 스팀 지점**. **몸 김 시작 땀양**(`0.3`, `0.05–0.85`, 몸 김이 짙어지기 시작하는 땀양), **몸 김 밀도 배율**(`1.0`, `0.5–1.5`), **몸 김 상승 속도 배율**(`1.0`, `0.6–1.5`), **몸 김 수명 배율**(`1.0`, `0.7–1.5`), **몸 김 크기 배율**(`1.0`, `0.75–1.5`), **몸 김 퍼짐 배율**(`1.0`, `0.5–1.5`), **몸 김 불투명도 배율**(`1.0`, `0.5–1.5`). |

**입김 입 연동** 선택지:

- **항상:** 입 움직임으로 제한하지 않습니다.
- **비지므 (립싱크):** VRChat Viseme 립싱크를 사용합니다.
- **커스텀 파라미터 (VRCFT):** 지정한 Float와 입 열림 임계값을 사용합니다.
- **자동 (활성 VRCFT, 비지므 폴백):** 처음에는 Viseme을 사용하고, `JawOpen`의 실제 열림·닫힘 변화가 감지되면 VRCFT를 우선합니다. JawOpen이 닫힌 값(0.015 미만)으로 내려간 뒤 0.03을 넘지 않고 8초가 지나면 다시 Viseme으로 돌아갑니다.

**내 시점에서도 입김 보기**는 생성된 Exhale 오브젝트에 MA Visible Head Accessory를 추가합니다. 유효한 Head 본이 있는 Humanoid 아바타와 MA Visible Head Accessory가 포함된 Modular Avatar 버전이 필요합니다.

Custom Steam Point: 활성 커스텀 이미터 슬롯은 최대 4개이며 좌우 미러 페어는 2개를 사용하고, 내장／Custom을 합쳐 총 12개가 상한입니다. 발생량 가중치 합계가 `4.0`을 넘으면 같은 비율로 줄입니다.

### 성능 및 고급 설정

이 값들은 **FX에 적용**을 누를 때 생성 FX 에셋에 반영됩니다. **고급 FX 값을 기본값으로 초기화**는 모든 고급 묶음을 되돌립니다.

**자동 반응**(**이 항목 기본값 복원** 포함):

| 항목 | 기본값 | 범위 | 의미 |
|---|---:|---:|---|
| **반응 임계값** | 균형 `0.04`, 민감 `0.015` | `0–0.6` | 자동 누적이 시작되는 움직임 크기입니다. |
| **포화 지점** | 균형 `0.35`, 민감 `0.18` | `0.05–1` | 상승 속도가 최대 반응에 도달하는 움직임 크기입니다. |
| **스무딩 강도** | 균형 `0.12`, 민감 `0.16` | `0.01–0.5` | 높을수록 빠르게, 낮을수록 묵직하게 반응합니다. |
| **땀 축적 저항 (%)** | `100%` | `0–100%` | 땀 40%까지 설정 강도의 20%에 이르고, 그 뒤 95%를 향해 본곡선을 적용합니다. 강한 움직임은 최대 효율을 유지하며, `0%`는 이전 방식의 반응입니다. |

| **낙하 땀 회복 시간** | `3초` | `1–8` | 움직임이 멈춘 뒤 낙하 물방울 활동이 안정되는 시간입니다. |
| **운동량 회복 시간** | `9초` | `5–15` | 체열에 사용되는 중간 운동량 단계의 회복 시간입니다. 입김 표시 자체를 뜻하지 않습니다. |

| **추 위치** | 힙 | — | **힙** / **가슴** / **머리** / **왼손** / **오른손**. 손과 머리는 힙보다 훨씬 많이 흔들리므로 균형을 권장하며, 민감은 과하게 반응할 수 있습니다. |

|---|---:|---:|---|
| **낙하 방울 최대 개수 (시스템별)** | `12` | `8–128` | 낙하 물방울 시스템마다의 파티클 상한입니다. 일반 방울은 이 상한을, 강한 움직임 방울은 그 2/3(기본값에서 8개)를 씁니다. |

## 땀 마테리얼 인스펙터

아래 항목은 Tuning 컴포넌트가 아니라 생성된 RealSweat 마테리얼 Inspector에서 조절합니다. 인스펙터는 새 모양이 읽는 값만 보여 줍니다(**빠른 설정**, **분포**, **흐름**, **조명**, **고급**). 1.1.x 값은 숨겨지지만 마테리얼에 남아 있습니다.

| 항목 | 위치 | 용도 |
|---|---|---|
| **Rest 데이터** | 인스펙터 맨 위 | 마테리얼에 맞는 Rest 데이터가 없을 때 알려 줍니다. |
| **기본 모습으로 되돌리기** | **땀 모양** 줄 | 모양 값만 되돌리고 땀양, 품질, 무늬 번호, 마스크, 스텐실, Rest 데이터, 설치 창 선택은 그대로 둡니다. 1.1.x의 프리셋 버튼이 이 버튼 하나로 바뀌었습니다. |
| **땀양 (미리보기)** | **빠른 설정** | 인게임 메뉴가 이 값을 움직입니다. 여기 값은 에디터에서 보이는 양입니다. |
| **물방울 크기** | **빠른 설정** | 물방울 반지름의 배율입니다. `1.6`이 기본 모습입니다. |
| **반짝임 크기** / **반짝임 세기** | **빠른 설정** | 물방울에 비친 빛(반짝임)입니다. 기본값은 둘 다 `1.5`이고, `1`로 낮추면 더 차분한 모습입니다. |
| **땀 흐름** | **빠른 설정** | 가파른 피부에서 흘러내리는 물방울의 수와 거리입니다. 기본값 `1`이 스타일마다의 기본 모습이고, `0`이면 물방울이 제자리에 머물고, `2`면 대부분 흘러내립니다. |
| **젖은 피부 막** | **빠른 설정** | 물방울 사이의 얇은 젖은 막과 그 광택입니다. `0`이면 꺼집니다(설치 창의 **젖을수록 피부 광택**을 끈 상태). |
| **스폰 마스크 (흰색 = 스폰)** | **분포** | Tuning의 바디 표면 스폰 마스크와 같은 마스크입니다. |
| **무늬 번호** / **새 무늬** | **분포** | 아바타의 무늬 번호입니다. **새 무늬**를 누르면 번호를 바꿉니다. |
| **전체 땀 마스크** | **고급** | Tuning의 바디 표면 표시 마스크와 같은 마스크입니다. |
| **거울에서도 땀 고품질 (고부하)** | **고급 > 거울** | 설치 창 옵션과 같은 스위치입니다. |

### 표면 마스크 {/* #surface-masks */}

두 마스크는 Tuning의 **피부 표면 설정 > 표면 마스크 및 메쉬별 설정**과 땀 마테리얼 인스펙터에 있습니다. 둘 다 메쉬의 UV0를 사용합니다. 텍스처를 넣으면 **마스크 강도**가 1이 되고, 텍스처를 빼면 0이 됩니다.

- **바디 표면 스폰 마스크:** 흰색 영역은 표면 땀을 허용하고 검은색 영역은 차단합니다. 붙어 있는 물방울·젖은 막·Tess 변위의 생성 영역을 제한하며, 낙하 물방울 파티클은 바꾸지 않습니다. **마스크 고급 설정**에는 **임계값**, **부드러움**, **마스크 반전**, **타일링**, **오프셋**이 있습니다. 마테리얼 인스펙터에서는 <strong>분포 > 스폰 마스크 (흰색 = 스폰)</strong>이며, 빨강 채널을 읽고 **마스크 강도**, **마스크 임계값**, **마스크 경계 부드러움**, **마스크 반전**이 있습니다.
- **바디 표면 표시 마스크:** 흰색 영역은 표면 땀을 보이고 검은색 영역은 완전히 숨깁니다. 물방울·흐른 자국·젖은 막·광택·굴절·어두워짐·Tess 변위를 포함한 표면 최종 결과를 숨기지만 낙하 물방울 파티클에는 영향이 없습니다. **마스크 고급 설정**에는 **마스크 채널**(R/G/B/A), **마스크 반전**, **타일링**, **오프셋**이 있습니다. 마테리얼 인스펙터에서는 **고급 > 전체 땀 마스크**입니다. 회색조 값을 정확히 쓰려면 텍스처의 **sRGB (Color Texture)를 꺼 주십시오**. 기본 강도는 `0`이라 업데이트만으로 기존 외형이 바뀌지 않습니다.

### v2.0.0에서 빠진 기능

우유 모드, 바디 노멀맵의 젖은 표현, 광학 LUT, 흐름 가이드 맵, Rest 패턴 회전은 2.0.0 땀 모양에 없습니다. Pattern Space의 수동 Rest 축 모드(Rest Front XY／Side ZY／Top XZ)도 없어졌고, 이 모드를 쓰던 마테리얼은 Rest Normal Triplanar로 바뀝니다. `Body Normal Map` 값은 마테리얼에 남아 있지만 효과가 없고, 흐름 방향은 실시간 월드 중력을 따릅니다. 다른 메쉬별 패턴 밀도와 Tuning의 '패턴 밀도'도 숨겼습니다.

Light Limit Changer(LLC)로 아바타의 밝기를 바꾸면 피부 땀도 같은 비율로 따라갑니다. [호환성](../compatibility.mdx#light-limit-changer)을 확인해 주십시오.

## 상대 저부하와 거울

**상대 저부하**는 아바타 메뉴 항목이며 Tuning Inspector 항목이 아닙니다. 상대 화면은 No Tess로, 땀구멍의 작은 물방울 없이 그리고, 저부하와 경량에서는 잔류 방울과 애니의 얇은 막 선도 빼며 면의 방향이 바뀌는 곳의 처리를 줄입니다(상대의 GPU 시간이 저부하에서 약 4~8%, 표준에서 23~29% 줄어듦). 상대 몸 김／Custom Steam은 개수는 그대로 진하기를 0.6배로 낮춥니다(3D 몸 김은 개수 25%). 3D 파티클 품질을 쓰면 상대 낙하 물방울을 50%로 줄이고 강한 움직임 추가 방울을 끕니다. 내 화면 품질은 유지됩니다.

거울 옵션:

- **거울에서도 땀 고품질**은 기본값이 꺼짐입니다. 꺼져 있으면 거울에서는 땀구멍의 작은 물방울을 빼고 그리고, 물방울 입체감도 솟지 않습니다. 켜면 거울에서도 원래 화면과 같게 그립니다.
- **거울 속 몸 김**은 **전체 품질**, **낮음 (2D 불투명도 감소)**, **숨김**입니다. 2D에서 낮음은 파티클 수를 줄이지 않은 채 거울 속 몸 김을 전체 품질의 0.8배 진하기로 그립니다. 3D에서 낮음은 현재 전체 품질과 같은 표현과 부하를 사용합니다. 가장 낮은 거울 비용은 숨김입니다.

:::warning[GPU 부하가 겹치는 조합]
표준 품질, 화면을 크게 차지하는 근접 화면, 거울, 물방울 입체감을 함께 쓰면 GPU 부하가 겹칠 수 있습니다. 큰 옵션은 한 번에 하나씩 바꾸고 업로드된 아바타로 확인해 주십시오.
:::

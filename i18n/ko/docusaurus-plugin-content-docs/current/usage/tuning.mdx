# 튜닝 가이드

먼저 기본 프리셋으로 동작을 확인한 다음, 필요한 항목만 조금씩 조절하는 방법을 권장합니다.

## Tuning을 여는 방법

Setup이 끝나면 Hierarchy의 **아바타 루트 > RealSweat** 오브젝트를 선택합니다. Inspector의 **RealSweatSystem Tuning** 컴포넌트에서 값을 조절할 수 있습니다.

재질 외형처럼 즉시 반영되는 값과 **FX에 적용**을 눌러야 하는 값이 다르므로, 조절 후에는 아래의 [변경 사항이 반영되는 시점](#변경-사항이-반영되는-시점)을 확인하세요.

[![RealSweatSystem Tuning 한국어 Inspector](/img/guide/tuning-korean.png)](/img/guide/tuning-korean.png)

*<small>한국어 Tuning Inspector 예시입니다. 화면의 수치는 테스트 Scene 값이므로 설치 기본값과 다를 수 있습니다.</small>*


## 전체 땀양

| 설정 | 용도 |
|---|---|
| **적음(경량화)** | 표현을 가장 가볍게 사용하려는 경우 |
| **적음(저부하)** | 기본값. 품질과 부하의 균형을 원하는 경우 |
| **보통(중부하)** | 화면에 더 풍부한 땀 표현이 필요한 경우 |

이전 버전 또는 개발 중 자료에 표시된 다른 땀양 항목은 현재 공개 버전의 선택지가 아닙니다.

## 주요 조절 항목

| 항목 | 바뀌는 부분 | 부하 영향 | 시작 권장값 |
|---|---|---|---|
| 감도 프리셋 | Auto Mode의 움직임 반응 | 작음 | **균형** |
| 사용자 지정 누적 속도 곡선 | Sweat % 구간별 누적 속도 | 작음 | 프리셋 확인 후 조절 |
| 전체 땀양 | 화면에 표시되는 물방울 양 | 중간~큼 | **적음(저부하)** |
| 물방울 크기 | 개별 물방울의 크기 | 작음~중간 | 극단적인 값 피하기 |
| 패턴 밀도 | 물방울의 개수와 세밀함 | 중간~큼 | 다인 환경에서는 낮게 |
| 입체기능(테셀레이션) | 실제 표면의 입체 변위 | 큼 | 일반 플레이에서는 OFF |

## 감도와 누적 속도 곡선

감도 프리셋은 몸의 움직임에 얼마나 민감하게 반응할지 정합니다. 사용자 지정 누적 속도 곡선은 현재 Sweat % 구간에 따라 얼마나 빠르게 쌓일지 정합니다. 두 설정은 서로 대체하는 옵션이 아니라, 함께 Auto Mode에 반영됩니다.

그래프는 필요할 때만 펼쳐 사용할 수 있습니다. 기본 사용자는 **균형** 프리셋만으로 먼저 확인해도 충분합니다.

- **움직임 반응** 그래프는 현재 선택한 감도 프리셋, 땀 축적 배속과 수평·상하 민감도가 반영된 반응을 보여 줍니다.
- **누적 그래프**는 현재 누적 프로필 또는 사용자 지정 곡선과 예상 누적 시간을 보여 줍니다.
- 그래프는 편집 중인 값을 즉시 보여 주는 미리보기입니다. 인게임 FX를 갱신하려면 **FX에 적용**을 누르세요.

## 변경 사항이 반영되는 시점

Tuning에서 값이나 그래프가 바뀌는 시점과 생성된 FX에 실제로 반영되는 시점은 다릅니다.

- **즉시 반영:** **전체 땀양**은 Tess와 No Tess 재질의 Material Quality를 즉시 바꾸고, **물방울 크기**와 **패턴 밀도**도 표면 외형에 즉시 반영됩니다.
- **FX에 적용 필요:** 감도와 자동 반응 설정, **사용자 지정 누적 속도 곡선**, 낙하 물방울·바닥 물자국·입김·몸 김 및 성능 제한처럼 생성된 Animator나 파티클 FX를 바꾸는 값은 **FX에 적용**을 눌러야 실제 FX에 반영됩니다. 곡선 그래프는 편집 중 즉시 갱신되지만, 이는 미리보기이며 생성된 FX는 아직 바뀌지 않습니다.
- 전체 땀양을 바꾼 뒤 애니메이션 젖음·낙하 물방울·몸 김을 다시 맞추거나, 물방울 크기 변경을 낙하 물방울과 튀김 파티클 크기에도 반영하려면 **FX에 적용**을 누르세요.

## 고급: 흐름 가이드 맵과 바디 노멀맵

두 맵은 역할이 서로 다릅니다. 물방울의 흐르는 방향을 바꾸려면 Body Normal Map이 아니라 **Flow Guide Map**을 사용해야 합니다.

| 항목 | 역할 | 물방울 흐름 방향 변경 |
|---|---|---|
| **Flow Guide Map (UV0 RG)** | 기본 중력 흐름에 사용자가 만든 방향을 더해 물방울과 트레일을 유도 | **함** |
| **Body Normal Map (Fold / Sheen Only)** | 젖은 하이라이트와 주름 고임 표현 보강 | **하지 않음** |

Flow Guide Map은 색상이 아닌 데이터 텍스처입니다. Texture Import Settings에서 **sRGB (Color Texture)를 끄고**, 안정적인 흐름과 테셀레이션 일치를 위해 **Generate Mip Maps를 켜세요**. 맵을 사용하지 않을 때는 Flow Guide Strength를 0으로 두면 추가 텍스처 샘플을 사용하지 않습니다.

이 항목들은 고급 재질 조정용입니다. 일반 설치에서는 기본값을 바꿀 필요가 없습니다.

## 렌더링 기본값

- 렌더 순서 자동 설정 (권장): **켜짐**
- 땀 렌더 큐: **2455**
- 바디 Shadow Strength 따라가기: **켜짐**
- 입체기능 탑재: **미탑재**
- 입체기능 탑재 시 정밀도: **간소화 — 일반 플레이용**
- 테셀레이션 기본값 켜기: **체크 해제**

<strong>렌더 순서 자동 설정 (권장)</strong>이 켜져 있으면 땀 재질의 Render Queue는 정확히 **2455**로 고정되며, 선택한 Body 재질은 **2454 이하**여야 합니다. Body 재질을 2454 이하로 설정할 수 없다면 <strong>렌더 순서 자동 설정 (권장)</strong>을 끄고, **수동 땀 렌더 큐**를 Body 재질보다 큰 값으로 설정하세요.


**바디 Shadow Strength 따라가기**는 선택한 Body Element 재질의 `_ShadowStrength`를 RealSweatSystem의 드리운 그림자 강도로 복사합니다. lilToon과 Poiyomi를 지원합니다.

이 값은 실시간으로 계속 추적되는 것이 아니라 **Setup — 자동 설치 / 업데이트** 또는 **FX에 적용**을 실행할 때 복사됩니다. 바디 재질의 Shadow Strength를 나중에 바꿨다면 **FX에 적용**을 다시 누르세요.

:::warning[부하가 크게 늘어나는 조합]
전체 땀양과 패턴 밀도를 함께 높이고, 근접 화면·미러·입체기능을 동시에 사용하면 GPU 부하가 크게 증가할 수 있습니다.
:::

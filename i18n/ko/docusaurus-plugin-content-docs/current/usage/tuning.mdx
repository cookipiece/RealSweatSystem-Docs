# Setup · Tuning 옵션 전체 안내

이 페이지는 RealSweatSystem 1.0.1에서 사용자가 정상적으로 조절하는 옵션을 정리합니다. **Base** 표시는 Sweat Base Module, **Effects** 표시는 Sweat Effects Module이 설치된 경우에 나타나는 항목입니다.

## Tuning 컴포넌트 열기

Setup을 완료한 뒤 Hierarchy에서 아바타를 펼치고, 아바타 루트 바로 아래에 생성된 **RealSweat** 오브젝트를 선택합니다. Inspector의 **RealSweatSystem Tuning**에서 값을 조절할 수 있습니다.

오브젝트가 없다면 **CookiTools > RealSweatSystem Setup／Uninstall**을 열고 **Setup — 자동 설치 / 업데이트**를 실행하세요.

[![RealSweatSystem Tuning 한국어 Inspector](/img/guide/tuning-korean.png)](/img/guide/tuning-korean.png)

*<small>스크린샷의 수치는 테스트 Scene의 예시이며 설치 기본값과 다를 수 있습니다.</small>*

## 변경값이 반영되는 시점

| 변경 항목 | 반영 시점 |
|---|---|
| **전체 땀양** | 머티리얼 품질은 즉시 바뀝니다. 젖음 애니메이션·낙하 물방울·몸 김까지 맞추려면 **FX에 적용**을 누릅니다. |
| **물방울 크기 / 패턴 밀도** | Tess와 No Tess 표면 머티리얼에 즉시 반영됩니다. 낙하 물방울과 강한 움직임 비산 크기까지 갱신하려면 **FX에 적용**을 누릅니다. |
| **입체 표현 정밀도** | 설치된 Tess 머티리얼에 즉시 반영됩니다. |
| 자동 반응·누적 곡선·유지시간·이펙트·고급 FX 값 | **FX에 적용**을 누릅니다. |
| 바디 머티리얼의 Shadow Strength | **FX에 적용** 또는 Setup 재실행 시 복사됩니다. |
| 대상 Body·렌더 순서·테셀레이션 지원 등 설치 구조 | **Setup — 자동 설치 / 업데이트**를 다시 실행합니다. |

누적 그래프는 편집 중인 값을 즉시 미리 보여주지만, **FX에 적용**을 누르기 전에는 생성된 FX가 바뀌지 않습니다.

| 항목 | 모듈 | 기본값 | 의미 |
|---|---|---:|---|
| **아바타** | 공통 | 미지정 | VRC Avatar Descriptor가 있는 대상 아바타입니다. |
| **바디 메쉬** | 공통 | 자동 감지 | 땀 셸이 표시될 하나의 SkinnedMeshRenderer입니다. |
| **땀 적용 Element** | Base | Element 0 | 다시 렌더링할 Body 머티리얼 / SubMesh 영역입니다. 일반적으로 Element 0이 메인 피부입니다. |

| **수동 땀 렌더 큐** | Base | `2455` | 자동 렌더 순서를 끄면 나타납니다. Body 머티리얼보다 높은 값으로 설정합니다. |
| **바디 Shadow Strength 따라가기** | Base | 켜짐 | Setup 또는 **FX에 적용** 실행 시 선택한 Body Element의 `_ShadowStrength`를 땀에 복사합니다. lilToon과 Poiyomi를 지원합니다. |
| **전체 땀양** | 공통 | 적음(저부하) | 표면 계산 예산과 젖음 애니메이션·이펙트 양의 기준을 선택합니다. |
| **자동모드 감도** | 공통 | 균형 | 작은 신체 움직임에 Auto Mode가 얼마나 민감하게 반응할지 선택합니다. |
| **입체기능(테셀레이션)(고부하) 설치하기** | Base | 꺼짐 | 끄면 No Tess 하나만, 켜면 Tess와 No Tess를 함께 넣고 인게임 입체기능 전환을 추가합니다. |
| **입체 표현 정밀도** | Base + Tess | 간소화 | 설치되는 Tess 머티리얼의 정밀도입니다. |
| **입체기능(테셀레이션) 기본값 켜기** | Base + Tess | 꺼짐 | 아바타 로드 직후 로컬 입체 표시의 초기 상태입니다. 한 번에 땀 머티리얼 하나만 활성화됩니다. |
| **낙하 물방울** | Effects | 켜짐 | 몸에서 떨어지는 땀 파티클을 설치합니다. |
| **바닥 물자국 사용** | Effects | 켜짐 | 낙하 물방울이 바닥에 남기는 젖은 자국을 설치합니다. |
| **입김** | Effects | 켜짐 | 입김 emitter를 설치합니다. |
| **몸 김** | Effects | 켜짐 | 몸 김 emitter를 설치합니다. |
| **몸 김 위치** | Effects | 가슴골·양어깨·겨드랑이·허벅지 켜짐, 고간·발 꺼짐 | Setup이 생성할 몸 김 위치를 선택합니다. |
| **삭제 시 생성 에셋도 제거** | 공통 | 꺼짐 | Uninstall 때 bake·material·animation·menu 생성물도 지웁니다. 보존하려면 끄세요. |

### 전체 땀양

- **적음(경량화):** 물방울 계산 예산이 가장 작습니다. 일부 신체 부위나 시야각에서 패턴이 이어지는 곳에 옅은 선이 보일 수 있습니다.
- **적음(저부하):** 기본값입니다. 낮은 부하를 유지하면서 경량화 단계의 이음선을 숨기는 쪽입니다.
- **보통(중부하):** 땀 표시량과 표면 계산 예산이 증가합니다.

업로드 전에 근접 화면과 거울을 모두 확인하세요. 땀양·패턴 밀도·화면 점유율·테셀레이션은 GPU 부하가 서로 겹칠 수 있습니다.

### 테셀레이션 선택지

| 입체 표현 정밀도 | Tess 계수 | 용도 | 상대 부하 |
|---|---:|---|---|
| **간소화 — 일반 플레이용** | `2.5` | 일반 플레이 | Tess 중 가장 낮음 |
| **균형 — 근접 감상용** | `4` | 가까운 거리 | 높음 |
| **정밀 — 사진 촬영용** | `7` | 정지 사진 | 가장 높음 |

테셀레이션 지원을 설치해도 두 머티리얼이 동시에 렌더링되지는 않습니다. 메뉴가 Body 슬롯 하나를 Tess 또는 No Tess로 교체합니다. 인게임 입체기능을 끄면 실제 No Tess 셰이더를 사용하므로 Hull / Domain 테셀레이션 연산도 실행되지 않습니다.

## Tuning 옵션

### 자동 누적 반응

| 항목 | 기본값 | 의미 |
|---|---:|---|
| **감도 프리셋** | 균형 | **균형**은 움직임 강도에 비례하고, **민감**은 작은 움직임에서 더 빨리 최대 반응에 도달합니다. 프리셋을 바꾸면 반응 시작점·포화점·상승 / 건조 기준·평활화가 해당 프리셋 값으로 돌아갑니다. |
| **땀 축적 배속** | `1.0` | 프리셋 전체의 자동 누적 속도 배율입니다. 범위 `0.25–4.0`. |
| **수평 민감도 (좌우·앞뒤)** | `1.0` | 좌우 및 앞뒤 움직임 반응입니다. 범위 `0.95–1.10`. |
| **상하 민감도** | `1.2` | 위아래 움직임 반응입니다. 범위 `0.90–1.30`. 작은 상하 운동이나 스쿼트에는 `1.2`를 권장합니다. |
| **미리보기 방향** | 혼합 | 그래프 미리보기만 바꿉니다. 인게임에서는 모든 방향이 계속 활성화됩니다. |
| **움직임 반응** | 접힘 | 현재 시작점·포화점·평활화·방향 민감도를 보여주는 미리보기입니다. |
| **누적 프로파일** | 균일 | 현재 Sweat % 구간에 따라 누적 속도를 바꿉니다. 동기화 파라미터나 런타임 레이어를 추가하지 않습니다. |
| **세부 수치** | 접힘 | 활성 곡선의 `0/25/50/75/100%` 배율을 편집합니다. 범위 `0.1–2.0`. |
| **누적 그래프** | 접힘 | 일정한 움직임을 가정한 곡선과 95% 도달 예상시간을 보여줍니다. 실제 PhysBone 입력은 아바타와 애니메이션에 따라 달라집니다. |

누적 프로파일:

- **균일:** 모든 Sweat %에서 같은 배율을 사용합니다. 신규 설치의 기본값입니다.
- **자연스럽게 (권장):** 초반은 조금 빠르고 Sweat %가 높아질수록 점차 느려집니다.
- **초반 빠르게:** 시작 구간의 누적을 강하게 강조합니다.
- **후반 가속:** 초반은 느리고 후반으로 갈수록 빨라집니다.
- **사용자 지정:** 다섯 지점을 직접 편집합니다.

제공되는 프로파일은 95%까지의 예상시간이 거의 같게 조정되어 있지만, 보이는 진행 방식과 마지막 5%는 다를 수 있습니다. 감도·축적 배속·방향 민감도·누적 프로파일은 모두 Auto Mode에 함께 영향을 줍니다.

## 고급 FX 조정

고급 옵션은 생성된 Animation / Particle 에셋을 수정하므로 **FX에 적용**이 필요합니다. **분류 기본값 복원**은 해당 분류만 초기화합니다.

### 자동 반응

| 항목 | 기본값 | 의미 |
|---|---:|---|
| **반응 시작점** | 균형 `0.04`, 민감 `0.015` | 자동 누적이 시작되는 움직임 크기입니다. |
| **포화점** | 균형 `0.35`, 민감 `0.18` | 상승 속도가 최대 반응에 도달하는 움직임 크기입니다. |
| **평활화** | 균형 `0.12`, 민감 `0.16` | 높을수록 빠르게, 낮을수록 묵직하게 반응합니다. |
| **땀 누적 저항 (%)** | `100%` | 높은 Sweat %의 누적을 점진적으로 억제합니다. 강한 움직임은 최대 효율을 유지하며 `0%`는 이전 방식의 반응입니다. |
| **이동 재개 대기시간** | `1초` | WASD / Jump가 멈춘 뒤 진자 움직임으로 다시 누적되기까지의 시간입니다. |
| **물방울 회복시간** | `3초` | 움직임이 멈춘 뒤 낙하 물방울 활동이 안정되는 시간입니다. |
| **운동 회복시간** | `9초` | 몸 열기에 사용되는 중간 운동 단계의 회복시간입니다. 입김 표시 자체를 뜻하지 않습니다. |
| **몸 열기 회복시간** | `30초` | 몸 김 주기 보정의 회복시간입니다. |
| **진자 본** | Hips | 모션 센서 부착 위치입니다. Chest·Head·좌우 Hand도 선택할 수 있지만 Head / Hand는 민감 프리셋에서 과민할 수 있습니다. |

### Effects Module 고급 분류

| 분류 | 조절 항목 | 분류 기본값 |
|---|---|---|
| **낙하 물방울** | 양·낙하속도·수명·크기·길이 배율, 강한 움직임 비산, 비산 임계값·확률·쿨다운·최소 / 최대 개수 | 배율 `1.0`, 비산 켜짐, 임계값 / 확률 `0.55`, 쿨다운 `3.5초`, `2–5개` |
| **바닥 물자국** | 수명·크기·불투명도, 중앙 건조 대비, 고임 확률 | 배율 `1.0`, 대비 `0.75`, 확률 `0.25` |
| **몸 김** | 시작 Sweat %, 밀도·상승속도·수명·크기·퍼짐·불투명도 | 시작 `30%`, 배율 `1.0` |
| **입김** | 시작 Sweat %, 입 열림 방식·파라미터·임계값, 양·속도·수명·크기·퍼짐·불투명도·주기 속도 | 시작 `25%`, Auto, `v2/JawOpen`, 입 열림 `0.2`, 배율 `1.0` |
| **성능 한도** | 낙하 물방울·바닥 자국·몸 김·입김의 최대 파티클 수 | 낙하 `64`, 자국 `80`, 몸 김 emitter당 `24`, 입김 `48` |

**입김 입 열림 방식**:

- **항상:** 입 움직임으로 제한하지 않습니다.
- **Viseme (립싱크):** VRChat Viseme을 사용합니다.
- **사용자 파라미터 (VRCFT):** 지정한 Float와 입 열림 임계값을 사용합니다.
- **자동 (VRCFT 우선, Viseme 대체):** 변화 중인 VRCFT `JawOpen`을 우선 사용하고, 8초 동안 열림 / 닫힘 변화가 없으면 Viseme으로 대체합니다.

## 땀 머티리얼 맵

아래 항목은 Tuning 컴포넌트가 아니라 생성된 RealSweat 머티리얼 Inspector에서 조절합니다.

| 항목 | 위치 | 용도 | 중요 설정 |
|---|---|---|---|
| **스폰 마스크 (흰색 = 생성)** | **기본 > 스폰 마스크** | 흰색은 물방울 생성, 검은색은 차단, 회색은 부분 적용입니다. 원하지 않는 UV 영역에서 땀이 나오지 않게 할 수 있습니다. | UV0와 R 채널을 사용합니다. |
| **흐름 가이드 맵 (선택)** | **흐름 & 자국 > 흐름 가이드 맵 (선택)** | UV0 탄젠트 방향으로 흐르는 물방울과 자국을 유도합니다. | RG 데이터 텍스처이며 중립은 `(0.5, 0.5)` 회색입니다. **sRGB 끄기**, **Generate Mip Maps 켜기**. 강도 `0`은 월드 중력만 사용하고 가이드 맵을 샘플하지 않으며 시작 권장은 `0.35–0.65`입니다. |
| **바디 노멀맵 (주름 고임 / 광택 전용)** | **고급 > 바디 노멀 — 젖은 표현 전용** | 젖은 하이라이트와 주름의 고임 표현을 바꿉니다. | 물방울이나 자국의 방향을 바꾸지 않습니다. 방향에는 Flow Guide Map을 사용하세요. |

## 상대 저부하와 거울

**상대 저부하(Remote Low Load)**는 아바타 메뉴 옵션이며 Tuning Inspector 항목은 아닙니다. 테셀레이션 지원 여부와 관계없이 설치됩니다.

- Tess 지원 시 상대방은 No Tess 머티리얼과 내장 Lite 경로를 사용합니다.
- Tess 미지원 시 같은 No Tess 머티리얼이 내장 Lite 경로로 전환됩니다.
- 별도 “Performance material”을 사용하지 않으며, 소유자 본인의 로컬 화면을 낮추지도 않습니다.

거울 카메라는 자동으로 저비용 광학 경로를 사용합니다. 일부 근접 광학 표현은 거울에서 의도적으로 단순해집니다. Tuning에는 사용자가 조절하는 거울 품질 스위치가 없습니다.

:::warning[GPU 부하가 겹치는 조합]
많은 땀양, 높은 패턴 밀도, 화면을 크게 차지하는 근접 화면, 거울, 테셀레이션을 함께 사용하면 GPU 부하가 누적됩니다. 큰 옵션은 한 번에 하나씩 바꾸고 업로드된 아바타로 확인하세요.
:::

# 수동 모드와 자동 모드

## 인게임 메뉴

Setup에서 설치한 모듈과 옵션에 따라 다음 메뉴가 구성됩니다.

```text
땀
├─ 땀 켜기
├─ 땀 %
├─ 자동 모드
└─ 부하 줄이기
   ├─ 상대 저부하
   ├─ 나에게만 보이기
   ├─ 파티클
   │  ├─ 전체 파티클
   │  ├─ 낙하 물방울
   │  ├─ 바닥 물자국
   │  ├─ 입김
   │  └─ 몸 김
   └─ 입체효과 (사진전용, 고부하)
```

- **상대 저부하**는 Sweat Base Module 설치 시 표시됩니다.
- **파티클**은 Sweat Effects Module 설치 시 표시됩니다.
- <strong>입체효과 (사진전용, 고부하)</strong>는 입체기능(테셀레이션)을 탑재한 경우에만 표시됩니다.

설치하지 않은 모듈이나 옵션의 항목은 자동으로 생략됩니다.

:::info[처음 시작할 때]
자동 모드의 기본값은 ON입니다. 땀 %를 직접 확인하려면 먼저 자동 모드를 OFF로 바꾸세요.
:::

수동 모드와 자동 모드는 **같은 Sweat %를 공유**합니다. 모드를 바꿔도 현재 땀 %는 초기화되지 않고 그대로 이어집니다.

## 수동 모드 (Manual Mode)

**자동 모드**를 끄고 Radial Menu의 <strong>땀 %</strong>를 0~100%로 직접 조절합니다. 촬영, 기능 비교 또는 일정한 땀양을 유지할 때 적합합니다.

## 자동 모드 (Auto Mode)

Humanoid 아바타에서는 몸의 움직임이 클수록 Sweat %가 빠르게 증가하고, 움직임을 멈추면 천천히 감소합니다.

- 감도 프리셋은 움직임에 대한 반응 정도를 조절합니다.
- 사용자 지정 누적 속도 곡선은 Sweat % 구간별 누적 속도를 조절합니다.
- 두 설정 모두 Auto Mode의 결과에 영향을 줍니다.
- 일반적인 이동 입력인 **WASD와 점프는 누적에서 제외**되고, 아바타의 로컬 몸 움직임에 반응합니다. 이동만 했는데 운동으로 인식되는 현상을 막기 위한 동작입니다.

감도 프리셋의 기본값은 **균형**입니다.

Non-Humanoid 아바타이거나 MA Bone Proxy 기반 Motion Pendulum을 만들 수 없는 구성에서는 Manual Mode와 **낙하 물방울**, **바닥 물자국**을 사용할 수 있습니다. 이 경우 **자동 모드**, **입김**, **몸 김** 메뉴는 생성되지 않습니다.

Motion Pendulum은 만들었지만 필수 Head·Chest Anchor를 찾지 못한 구성에서는 **자동 모드**를 사용할 수 있으며, **입김**과 **몸 김** 메뉴만 생성되지 않습니다.

## 땀 켜기와 0%의 차이

- **땀 켜기 ON + 땀 0%:** 시스템을 대기 상태로 유지하며 Auto Mode가 0%부터 땀을 누적할 수 있습니다.
- **땀 켜기 OFF:** 땀 표현을 비활성화합니다.

운동을 시작하는 순간부터 자연스럽게 땀이 누적되게 하려면, 땀을 켠 상태에서 0%로 시작하세요.

## 권장 동작 확인

1. **땀 켜기**를 활성화합니다.
2. 자동 모드를 끄고 땀 %를 0%, 25%, 50%, 75%, 100%에서 확인합니다.
3. 자동 모드를 켜고 아바타를 움직입니다.
4. 움직임을 멈춘 뒤 값이 천천히 감소하는지 확인합니다.
5. 구간을 지날 때 표현이 갑자기 건너뛰지 않는지 확인합니다.

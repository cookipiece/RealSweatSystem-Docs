# 수동 모드와 자동 모드

## 인게임 메뉴

전체 메뉴는 Setup에서 설치한 모듈과 옵션에 따라 구성됩니다.

```text
땀
├─ 땀 표시
├─ 땀 %
├─ 자동 모드
├─ 이펙트
│  ├─ 전체 이펙트
│  ├─ 낙하 물방울
│  ├─ 바닥 물자국
│  ├─ 입김
│  ├─ 몸 김
│  └─ 몸 김·입김 진하기 (선택형 래디얼)
└─ 부하 줄이기
   ├─ 피부 땀 숨기기
   ├─ 상대 저부하
   ├─ 나에게만 보이기
   └─ 물방울 입체감(테셀레이션 / 고부하)
```

- **상대 저부하**는 Sweat Base Module을 설치하면 나타납니다.
- **이펙트**는 Sweat Effects Module을 설치하면 나타납니다.
- **몸 김·입김 진하기**는 Setup에서 저장·동기화 래디얼을 선택한 경우에만 나타납니다.
- <strong>물방울 입체감(테셀레이션 / 고부하)</strong>은 물방울 입체감을 설치한 경우에만 나타납니다.

설치하지 않은 모듈이나 옵션의 항목은 자동으로 생략됩니다. 인게임 메뉴 이름은 <strong>[설치 / 업데이트]</strong>를 누를 때의 설치 창 언어로 만들어집니다.

:::note[v2.0.0에서 바뀐 메뉴 이름]
'표면 땀 숨기기'를 '**피부 땀 숨기기**'로 바꿨습니다. 파라미터는 그대로라 저장된 값은 유지됩니다. 메뉴 이름은 <strong>[설치 / 업데이트]</strong>나 **FX에 적용**을 누를 때 바뀝니다. 이전의 **VRC 라이트 볼륨** 토글은 없어졌습니다.
:::

## 수동 모드

**자동 모드**를 끄고 <strong>땀 %</strong>를 0~100%로 직접 정합니다. 촬영, 전후 비교, 일정한 땀양이 필요한 장면에 적합합니다.

수동 모드와 자동 모드는 값을 따로 두지 않습니다. 자동 모드를 끄면 현재 <strong>땀 %</strong>가 수동값으로 유지되고, 다시 켜면 게이지를 초기화하지 않고 그 값에서 이어집니다.

메뉴 땀양은 1% 단위로 갱신되며, 원격 Float 동기화 정밀도는 약 1/127(0.8%)입니다.

## 자동 모드

설치 후 **자동 모드는 기본값이 켜짐**입니다. 몸의 실제 움직임을 감지하여, 많이 움직일수록 땀 %가 빨리 쌓이고 움직임을 멈추면 땀 %가 천천히 줄어듭니다.

춤, 스쿼트, 짐볼 운동, 상체 흔들기 같은 트래킹된 움직임이 센서를 움직입니다. 이동 뒤의 짧은 안정화 구간을 포함해 **WASD 이동과 점프는 의도적으로 제외**하므로, 월드를 돌아다니기만 해서는 땀이 나지 않습니다. 움직임 감지·땀 축적·회복은 0.1초 고정 주기로 계산되어 게임 FPS에 따라 속도가 달라지지 않습니다.

- **자동 모드 감도**는 움직임을 얼마나 강하게 해석할지 정합니다.
- **사용자 지정 누적 속도 곡선**은 땀 % 구간별 누적 속도를 바꿉니다.
- 두 설정 모두 자동 모드에 영향을 줍니다.

감도 프리셋의 기본값은 **균형**입니다.

자동 모드에는 Modular Avatar 뼈 구성이 갖춰진 Humanoid 아바타가 필요합니다. Non-Humanoid 아바타나 필요한 뼈 참조가 없는 아바타는 수동 모드를 사용할 수 있습니다.

## 땀 표시와 땀 0%의 차이

- **땀 표시 켜짐 + 땀 0%:** 시스템이 대기 상태로 유지되며, 자동 모드가 0%부터 땀을 쌓을 수 있습니다.
- **땀 표시 꺼짐:** 땀 표현 전체가 꺼집니다.

아바타가 마른 상태에서 시작해 움직이기 시작한 뒤 자연스럽게 젖게 하려면 땀 표시를 켠 채 0%로 시작해 주십시오.

땀 0%와 땀 표시 끄기는 완전히 공짜가 아닙니다. 굴절을 위한 화면 복사(GrabPass, 약 +0.05 ms)가 남습니다. 피부 땀의 부하가 없어지는 것은 **피부 땀 숨기기**뿐입니다. [성능 가이드](../performance.mdx)를 확인해 주십시오.

## 빠른 동작 확인

1. **땀 표시**를 켭니다.
2. 기본값으로 켜져 있는 자동 모드를 잠시 끄고 0%, 25%, 50%, 75%, 100%를 확인합니다.
3. 자동 모드를 켜고 아바타를 움직입니다.
4. 움직임을 멈추고 값이 천천히 줄어드는지 확인합니다.
5. 구간을 지날 때 표현이 갑자기 건너뛰지 않는지 확인합니다.

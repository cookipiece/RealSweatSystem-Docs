# 성능 가이드

Real Sweat System의 부하는 주로 화면에 보이는 땀의 면적, 물방울 양과 패턴 밀도, 입체기능, 미러의 추가 렌더링, 파티클 표시량에 따라 달라집니다.

## 먼저 조절할 항목

1. 입체기능을 탑재했다면 **3D Effect (Photos Only, High Load)**를 끕니다.
2. 전체 땀양을 **적음(저부하)** 또는 **적음(경량화)**으로 설정합니다.
3. 패턴 밀도를 낮춥니다.
4. 사용하지 않는 스팀과 파티클 효과를 끕니다.
5. 상대방에게 보이는 비용을 줄이려면 **Remote Low Load**를 사용합니다.
6. 필요한 촬영 상황에서는 **Only Visible to Me**를 활용합니다.

## Tess와 No Tess

입체기능 지원은 기본적으로 탑재되지 않습니다. 설치 시 입체기능을 선택한 경우에만 아바타 메뉴에 **3D Effect (Photos Only, High Load)**가 나타납니다.

입체기능이 꺼져 있을 때는 No Tess 구성을 사용하므로, 일반 플레이에서는 OFF 상태를 권장합니다. 가까이에서 물방울의 실제 입체감을 촬영할 때만 켜는 방법이 효율적입니다.

## 미러

미러에서는 아바타가 다른 카메라에 한 번 더 렌더링되므로 부하가 증가합니다. 특히 몸이 화면을 크게 차지하고 땀양과 패턴 밀도가 높으면 차이가 커질 수 있습니다.

미러가 있는 월드에서는 다음을 함께 비교하세요.

- 입체기능 ON / OFF
- 전체 땀양 설정
- 파티클 전체 ON / 필요한 효과만 ON
- 미러 가까이 / 일반 거리

## Remote Low Load

**Remote Low Load**는 내 화면의 설정을 유지하면서, 다른 사용자에게 표시되는 Real Sweat의 부담을 줄이기 위한 옵션입니다. Base Module이 설치된 경우에만 메뉴에 나타납니다.

## FPS 수치에 대하여

FPS는 CPU와 GPU, VRChat 동기화 방식, 미러, 월드, 해상도와 주변 아바타에 함께 영향을 받습니다. 특정 GPU 모델이나 특정 Sweat %에서의 FPS는 보장할 수 없습니다.

비교할 때는 같은 월드, 같은 카메라 거리, 같은 미러 상태에서 기능을 하나씩 바꾸어 확인하세요.

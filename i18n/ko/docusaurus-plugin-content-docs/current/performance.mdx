# 성능 가이드

Real Sweat System의 부하는 땀 품질 단계, 땀이 화면을 차지하는 정도, 물방울 입체감, 거울, 파티클 이펙트, 그리고 함께 그려지는 아바타 수에 따라 달라집니다.

v2.0.0은 v1.1.3보다 훨씬 가벼워졌습니다. 다른 사람이 이 아바타를 처음 불러올 때의 셰이더 컴파일 멈춤이 약 3분의 2 짧아졌고, 기본 설치의 땀 100% 부하는 v1.1.3의 약 절반이며, 땀 0%의 부하도 크게 줄었습니다.

## 권장 조정 순서

1. **3D 파티클**은 끄고 기본의 가벼운 2D 파티클을 사용합니다.
2. **표현**을 **기본**으로 두거나, 물방울 입체감을 설치했다면 인게임에서 <strong>물방울 입체감(테셀레이션 / 고부하)</strong>를 끕니다.
3. **표준** 대신 <strong>저부하(권장)</strong>를 사용합니다. **경량**은 조금 더 빼지만 GPU 시간은 저부하와 거의 같습니다.
4. 선택형 이펙트를 끕니다. 몸 김부터 줄이는 것이 좋습니다.
5. 거울 속 몸 김이 필요 없다면 **거울 속 몸 김**을 **Hidden**으로 정합니다.
6. **거울에서도 땀 고품질**은 꺼 둡니다.
7. 다른 사람을 위해 **상대 저부하**를 켭니다.
8. 다른 사람에게 보일 필요가 없다면 **나에게만 보이기**를 사용합니다.
9. 피부 땀이 전혀 필요 없다면 **피부 땀 숨기기**를 사용합니다. 부하가 없습니다.

한 번에 하나만 바꾸고, 같은 카메라 거리와 같은 거울 상태에서 비교해 주십시오.

## 측정한 부하 {/* #measured-load */}

RSS가 없는 같은 아바타에 대한 아바타 GPU 시간의 배수입니다(작을수록 가벼움). PC 한 대(RTX 5090, D3D11, 2880 × 2880, MSAA 없음)에서 밀티나가 화면의 28%(전신) / 69%(상반신)를 채우게 하고, 100프레임 × 7회를 번갈아 잰 중앙값입니다. GPU가 다르면 배수도 달라지므로 행끼리 비교해 주십시오. 따로 적지 않은 것은 애니입니다.

| 전신 / 상반신 | v1.1.3 | v2.0.0 |
|---|---|---|
| 기본 설치(저부하), 땀 100% | 5.04배 / 4.44배 | 2.68배 / 2.36배 (실사 2.61배 / 2.27배) |
| 표준, 땀 100% | 5.25배 / 4.55배 | 3.59배 / 2.98배 (실사 3.90배 / 3.23배) |
| 물방울 입체감, 저부하, 땀 100% | 6.58배 / 5.33배 | 3.57배 / 2.93배 |
| 상대 저부하일 때 다른 사람에게 보이는 기본 설치 | 3.53배 / 3.22배 | 2.45배 / 2.18배 |
| 땀 0% | 2.10배 / 2.09배 | 1.18배 / 1.10배 |
| 피부 땀 숨기기 | 1.00배 / 1.00배 | 1.00배 / 1.00배 |

- 애니 표준은 v1.1.3의 퍼블릭 프리셋(3.21배 / 2.86배)과 비슷하고, 실사 표준은 조금 더 무겁습니다.
- 첫 로딩(다른 사람의 셰이더 컴파일 멈춤, 같은 PC): v1.1.3은 약 0.81초, v2.0.0은 약 0.27초입니다.
- 아바타는 고른 스타일의 셰이더만 쓰므로, 다른 사람의 첫 로딩은 스타일과 상관없이 비슷합니다.
- 땀 0%와 땀 표시 끄기는 완전히 공짜가 아닙니다. 굴절을 위한 화면 복사(GrabPass, 약 +0.05 ms)가 남습니다. 부하가 없어지는 것은 피부 땀 숨기기뿐입니다.

## 물방울 입체감 (Tess와 No Tess)

물방울 입체감은 선택 기능이며 기본으로 설치되지 않습니다. 설치하면 아바타 메뉴에서 **물방울 입체감**을 켜고 끌 수 있습니다.

가까이에서는 GPU 부하가 늘어납니다. 기본 정밀도(간소화)에서는 약 0.7 m보다 멀면 입체감이 없을 때와 똑같이 그립니다(균형은 약 1.5 m, 정밀은 약 2.2 m부터). 물방울 입체감을 끄면 보이지 않는 테셀레이션 처리를 계속하지 않고 No Tess 마테리얼을 사용합니다. 일반 플레이에서는 꺼 두고, 가까이에서의 입체 모양이 필요할 때만 켜 주십시오.

이 표면 옵션은 입김·낙하 물방울·몸 김을 메시 파티클로 바꾸는 **3D 파티클**과는 별개입니다.

## 땀 스타일

실사의 셰이더 명령 수는 애니보다 조금 적습니다(표준 단계 3457 대 3523). GPU 시간은 애니와 비슷하고, 가까이에서 몸통 전체가 화면을 채우면 최대 약 14% 늘어납니다. 물방울 입체감을 켜면 표준에서 애니 입체감의 약 1.07배, 저부하에서 약 0.95배입니다.

## 거울

거울은 다른 카메라로 아바타를 한 번 더 그리므로, 보이는 셰이더와 파티클 작업이 크게 늘 수 있습니다. 같은 아바타로 다음을 비교해 주십시오.

- 거울을 껐을 때
- 거울을 켰을 때
- 일반 대화 거리
- 몸이 화면의 큰 부분을 채우는 근접 화면

부하 차이가 크다면 먼저 물방울 입체감을 끄고, 거울에서도 땀 고품질을 끈 채로 두고, 거울 속 몸 김을 Hidden으로 정한 뒤 땀 품질을 낮춰 주십시오.

**거울에서도 땀 고품질**은 기본값이 꺼짐입니다. 꺼져 있으면 거울에서는 땀구멍의 작은 물방울을 빼고 그리고, 물방울 입체감도 솟지 않습니다. 켜면 거울에서도 원래 화면과 같게 그리므로 거울 GPU 부하가 증가합니다.

거울 속 몸 김은 Full, Low, Hidden입니다. 2D `Low`는 파티클 수를 줄이지 않은 채 거울 속 몸 김을 `Full`의 0.8배 진하기로 그립니다. 3D `Low`는 현재 `Full`과 같은 부하이므로, 거울 비용을 가장 낮추려면 `Hidden`을 사용해 주십시오.

## 상대 저부하

**상대 저부하**는 내가 고른 로컬 표현을 유지하면서 다른 사람에게 보이는 작업량을 줄입니다. 사용자가 별도의 성능용 마테리얼을 올릴 필요는 없습니다.

상대 화면은 No Tess로, 땀구멍의 작은 물방울 없이 그리고, 저부하와 경량에서는 잔류 방울과 애니의 얇은 막 선도 빼며 면의 방향이 바뀌는 곳의 처리를 줄입니다(상대의 GPU 시간이 저부하에서 약 4~8%, 표준에서 23~29% 줄어듦). 상대 몸 김／Custom Steam은 개수는 그대로 진하기를 0.6배로 낮춥니다(3D 몸 김은 개수 25%). 3D 파티클에서는 상대 낙하 물방울을 50%로 줄이고 강한 움직임 추가 방울도 끕니다. 내 화면 품질은 바뀌지 않습니다.

## 렌더 큐와 화면 복사

2.0.0의 땀은 화면 복사(GrabPass)에서 피부를 읽습니다. 2350이 아닌 큐에 그리는 땀(그대로 둔 바디 큐, Cutout 다음의 다른 메쉬, 수동 큐)은 "(Late Queue)" 셰이더를 사용하고, 그릴 때 화면을 따로 복사합니다. 그만큼 화면 복사가 한 번 늘어납니다. [호환성](./compatibility.mdx#render-queue-and-shadows)을 확인해 주십시오.

## 여러 땀 대상

선택한 Body Element와 실험적 추가 Renderer는 각각 자기 땀 마테리얼과 드로우를 사용합니다. 추가 메쉬는 별도의 Rest 데이터, 셸 에셋, 선택형 낙하 물방울도 추가할 수 있습니다. 특히 메쉬가 크거나 BlendShape가 많은 아바타에서는 필요한 대상만 추가해 주십시오.

## 파티클 조작

Effects Module을 설치했다면 다음 메뉴를 엽니다.

**땀 → 이펙트**

필요 없는 효과만 끄거나, **전체 이펙트**를 한 번에 조작하는 마스터 토글로 사용해 주십시오.

- 튀김을 켜면 파티클 시스템 2개와 마테리얼 칸 2개가 늘어나므로, VRChat 성능 순위가 한 단계 내려갈 수 있습니다(예: 마테리얼 칸 15 → 17이면 Medium → Poor).
- 새 몸 김은 파티클을 덜 씁니다(기본 설치 최대 168 → 95). 다만 김이 넓어진 만큼 가까이에서 그리는 양은 늘어납니다.
- 3D 몸 김과 입김은 VRChat 성능 순위의 Mesh Particle Active Polys가 크게 줄었습니다(기본 설치의 김·입김 96,000 → 92).

:::info[FPS에 대하여]
FPS는 CPU, GPU, VR 헤드셋 모드, 월드, 거울, 화면에 보이는 모든 아바타에 따라 달라집니다. 설정 하나를 바꿨을 때 FPS가 얼마나 오를지는 보장할 수 없습니다.
:::

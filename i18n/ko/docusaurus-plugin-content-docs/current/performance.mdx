# 성능 가이드

Real Sweat System의 부하는 주로 화면에 보이는 땀의 면적, 물방울 양과 패턴 밀도, 입체기능, 2D/3D 파티클, 미러의 추가 렌더링, 추가 땀 대상과 파티클 표시량에 따라 달라집니다.

## 먼저 조절할 항목

1. 3D 파티클을 설치했다면 Setup에서 **3D 파티클 품질**을 끄고 전체 Setup을 다시 실행해 가벼운 2D로 전환합니다.
2. 입체기능을 탑재했다면 <strong>물방울 입체감(테셀레이션 / 고부하)</strong>을 끕니다.
3. **거울에서도 바디 땀 전체 품질**을 끄고 몸 김 거울 모드를 `Low` 또는 `Hidden`으로 설정합니다.
4. 전체 땀양을 **적음(저부하)** 또는 <strong>적음(경량화)</strong>으로 설정합니다.
5. 패턴 밀도를 낮추고 불필요한 추가 Element／Renderer를 제거합니다.
6. 사용하지 않는 몸 김 위치·Custom Steam과 이펙트를 끕니다.
7. 내 화면의 설정을 유지하면서 다른 사용자에게 보이는 부담을 줄이려면 **상대 저부하**를 사용합니다.
8. 내 화면의 표시를 유지하면서 다른 사용자에게 Real Sweat를 표시하지 않으려면 **나에게만 보이기**를 사용합니다.

## Tess와 No Tess

입체기능 지원은 기본적으로 탑재되지 않습니다. 설치 시 입체기능을 선택한 경우에만 아바타 메뉴에 <strong>물방울 입체감(테셀레이션 / 고부하)</strong>이 나타납니다.

입체기능이 꺼져 있을 때는 No Tess 구성을 사용하므로, 일반 플레이에서는 OFF 상태를 권장합니다. 가까이에서 물방울의 실제 입체감을 촬영할 때만 켜는 방법이 효율적입니다.

## 미러

미러에서는 아바타가 다른 카메라에 한 번 더 렌더링되므로 부하가 증가합니다. 특히 몸이 화면을 크게 차지하고 땀양과 패턴 밀도가 높으면 차이가 커질 수 있습니다.

미러가 있는 월드에서는 다음을 함께 비교하세요.

- 입체기능 ON / OFF
- 바디 땀 거울 최적화 / 전체 품질
- 몸 김 `Full / Low / Hidden`
- 2D / 3D 파티클
- 전체 땀양 설정
- 전체 이펙트 ON / 필요한 효과만 ON
- 미러 가까이 / 일반 거리

**거울에서도 바디 땀 전체 품질**은 No Tess에서 거울 GPU 중부하, Tess에서 고부하를 추가할 수 있습니다. 2D 몸 김 `Low`는 블러를 생략하고 표시를 약하게 하지만 파티클 수 자체는 줄이지 않습니다. 3D `Low`는 현재 `Full`과 같은 표현 및 부하이므로 가장 낮은 몸 김 거울 비용은 `Hidden`입니다.

## 상대 저부하와 나에게만 보이기

**상대 저부하**는 Base가 설치된 구성에서 내 화면의 설정을 유지하면서 다른 사용자에게는 No Tess + Lite 표면 땀을 표시해 원격 부담을 줄입니다. Full Pack의 3D 파티클 품질에서는 상대 낙하 물방울을 50%로 줄이고 강한 움직임 추가 방울을 끄며, 상대 몸 김／Custom Steam을 25%로 줄입니다.

**나에게만 보이기**는 내 화면의 Real Sweat 표시를 그대로 유지하면서 다른 사용자에게는 표시하지 않아 원격 부담을 더 줄입니다. 촬영 전용 모드가 아니라, 원격 표시가 필요하지 않을 때 사용하는 기능입니다.

## 여러 Element와 추가 Renderer

설정된 각 땀 대상은 한 번에 Tess 또는 No Tess 마테리얼 하나를 렌더링하지만, 여러 Body Element와 추가 Renderer는 각각 별도의 땀 마테리얼과 드로우콜을 만듭니다. 필요한 피부 영역만 등록하고 실제 업로드된 아바타에서 프레임과 거울 부하를 함께 비교하세요.

## FPS 수치에 대하여

FPS는 CPU와 GPU, VRChat 동기화 방식, 미러, 월드, 해상도와 주변 아바타에 함께 영향을 받습니다. 특정 GPU 모델이나 특정 Sweat %에서의 FPS는 보장할 수 없습니다.

비교할 때는 같은 월드, 같은 카메라 거리, 같은 미러 상태에서 기능을 하나씩 바꾸어 확인하세요.

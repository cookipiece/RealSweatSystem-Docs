# 업데이트 및 변경 내역

## 최근 패치 내역

최근 패치의 주요 변경 사항을 짧게 요약합니다. 버전을 누르면 아래의 전체 상세 내역으로 이동합니다.

- **[v2.1.0 — 현재 버전](#v210)**
  - **심박 연동 (실험, 선택, 기본 꺼짐):** 심박 앱이 OSC로 VRChat에 보내는 심박수(BPM)에 맞춰 자동 모드의 땀 양이 정해집니다. 동기화 비트는 늘지 않습니다. Unity 안에서만 시험했고, 게임 안에서는 아직 시험하지 못했습니다. [심박 연동](./usage/heart-rate-link.mdx)을 봐 주십시오.
  - **새 조절 항목:** 레거시 스타일용 **1.x 패턴 밀도**가 생겼습니다.
  - **Linux·macOS 에디터에서의 구매 인증:** v2.1.0부터 할 수 있습니다. Linux는 실제 환경에서 확인했고, macOS는 아직 확인하지 못했습니다.
  - **수정:** Clothing Fix가 직접 바꾼 복제본을 덮어쓰지 않고, 복제 아바타가 아직 쓰는 공유 렌더 큐는 올린 채로 둡니다. 제거가 열려 있는 다른 씬이 쓰는 땀 파일을 지우지 않습니다. 설치 창이 아무것도 바꾸기 전에 Modular Avatar 1.12 이상, 긴 파일 경로, 옮긴 `RealSweat` 오브젝트를 확인합니다. 알 수 없는 판의 d4rkAvatarOptimizer가 있어도 업로드가 멈추지 않습니다.
  - **2.0.x에서 업데이트:** 기존 파일 위에 덮어 임포트하면 됩니다. <strong>[설치 / 업데이트]</strong>를 다시 누르지 않아도 됩니다. 심박 연동을 더할 때는 눌러 주십시오.
- **[v2.0.2](#v202)**
  - **1.x (레거시) 스타일:** 설치 창 첫 화면의 **땀 스타일**에 세 번째 그림 <strong>1.x (레거시)</strong>가 생겼습니다. RSS 1.x의 물방울 모습으로 그리고, 1.1.x보다 가볍습니다. **물방울 입체감**을 켜면 2.0 스타일처럼 물방울이 하나씩 둥글게 솟습니다.
  - **새 조절 항목:** Tuning에 **패턴 밀도**를 다시 넣었고, 바디 마스크를 재질 칸마다 따로 쓸 수 있으며, 땀 마테리얼 인스펙터에 **굴절 세기**가 생겼습니다.
  - **모양 수정:** 솟은 물방울 위로 외곽선이 지나가 보이던 것을 고쳤고, 대화 거리에서 애니의 작은 물방울이 피부의 혹처럼 보이던 것과 실사에서 그늘진 어두운 피부 위의 물방울이 흰 줄이나 흰 점처럼 보이던 것을 줄였습니다.
  - **움직임추와 기본값 복원 버튼:** 자동 모드의 움직임추를 아무도 잡거나 포즈를 걸거나 밀 수 없게 했고, Tuning의 기본값 복원 버튼이 설치할 때 빼 둔 이펙트를 다시 켜지 않습니다.
  - **2.0.0／2.0.1에서 업데이트:** 기존 파일 위에 덮어 임포트하면 됩니다. <strong>[설치 / 업데이트]</strong>를 다시 누르지 않아도 됩니다.
- **[v2.0.1](#v201):** Body의 마테리얼 칸(Element)을 두 개 이상 고른 아바타에서 VRCFury 토글이나 슬라이더가 밝기 속성을 바꾸면 업로드가 멈추던 문제를 고쳤고, 빌드 도구가 땀 칸을 바꿔도 업로드를 멈추지 않습니다.
- **[v2.0.0](#v200)**
  - **새 땀 모양:** 피부 땀을 처음부터 다시 만들었고, 그림으로 고르는 두 스타일 <strong>실사 (기본)</strong>(윤곽 없는 투명한 물방울)와 **애니**(또렷한 윤곽과 하이라이트)가 생겼습니다. **물방울 입체감**도 다시 만들어, 두 스타일 모두에서 가까이 있는 물방울이 피부 위로 실제로 솟습니다.
  - **새 설치 창·몸 김·낙하 물방울·튀김:** 첫 화면에는 꼭 필요한 항목만 두고, 그곳에서 바디 메쉬를 확인하고 이펙트는 체크 상자로, 스타일과 표현은 그림으로, 부하는 버튼으로 고릅니다. 몸 김은 넓은 곳에서 옅게 피어오르고, 낙하 물방울과 튀김을 새로 그렸으며, 바닥 물자국은 바닥을 어둡게만 합니다.
  - **더 가벼워졌습니다:** 다른 사람이 처음 불러올 때의 멈춤이 v1.1.3보다 약 3분의 2 짧아졌고, 기본 설치의 땀 100% 부하는 v1.1.3의 약 절반입니다.
  - **구매 인증:** 새 설치와 모듈 추가에는 PC마다 한 번 구매 인증이 필요하고, 모듈의 인증이 없는 PC에서 업로드하면 그 모듈이 빠집니다. [구매 인증](./license-activation.mdx)을 봐 주십시오.
- **[v1.1.3](#v113):** Steam을 끈 상태에서 설치가 실패하던 문제를 수정했고, 선택 해제한 이펙트의 파티클과 전용 FX가 남지 않게 했습니다.
- **[v1.1.2](#v112):** 표면 땀 숨기기에 빈 마테리얼 슬롯 대신 전용 숨김 마테리얼을 사용합니다.
- **[v1.1.1](#v111):** 중복 참조 검사를 줄이고, 일부 No Tess 제거 처리를 개선하고, 단계별 진단 로그를 추가했습니다.
- **[v1.1.0](#v110):** 선택형 3D 파티클, Custom Steam Point, 표시 마스크, 실험적 추가 메쉬를 추가했습니다.
- **[v1.0.2 — 2026-07-27](#v102--2026-07-27):** Write Defaults 설정을 자동으로 확인하고 최종 빌드에서 다시 보정해, 일부 MMD 재생 중 표정이나 립싱크가 멈추는 문제를 줄였습니다.
- **[v1.0.1 — 2026-07-27](#v101--2026-07-27):** VRCFT·Face Tracking·Write Defaults OFF 아바타에서 얼굴 표정·땀 메뉴·자동 모드가 함께 동작하도록 호환성을 개선했습니다.

## 업데이트 전 안전 절차

1. 아바타와 프로젝트를 프로젝트 밖에 백업합니다.
2. 현재 설치된 Real Sweat System 버전을 확인합니다.
3. 보유한 Base와 Effects 모듈을 모두 같은 새 버전으로 기존 파일 위에 임포트합니다. 가져오는 순서는 상관없습니다.
4. 이전 버전을 먼저 제거하거나 `RealSweat` 오브젝트 또는 `Assets/CookiTools/Generated`를 삭제하지 **마십시오**.
5. `CookiTools → RealSweatSystem → Setup／Uninstall`을 열고 아바타마다 <strong>[설치 / 업데이트]</strong>를 한 번 눌러 주십시오. **FX에 적용만으로는 이 업데이트가 되지 않습니다.**
6. 씬을 저장하고 Console을 확인한 뒤, 업로드 전에 Play Mode와 아바타 빌드로 확인합니다.
7. 업로드하기 전에, 아바타에 설치한 모듈의 구매 인증이 이 PC에 모두 있는지 확인해 주십시오([구매 인증](./license-activation.mdx)). 업데이트는 인증을 묻지 않지만, 인증 없이 업로드하면 그 효과가 빠집니다.

버전이 섞여 있으면 설치 창이 같은 버전으로 다시 임포트하라고 알리고 설치를 막습니다.

2.0.x에서 2.1.0으로 업데이트할 때는 <strong>[설치 / 업데이트]</strong>를 다시 누르지 않아도 됩니다. 기존 파일 위에 덮어 임포트하면 됩니다. 심박 연동과, **땀 표시**를 끌 때 바닥 물자국도 숨기는 것은 <strong>[설치 / 업데이트]</strong>를 누를 때 들어갑니다. [업데이트 빠른 안내](./update-guide.mdx)를 확인해 주십시오.

1.x에서 v2.1.0으로 업데이트할 때는 먼저 [1.x에서 업데이트하는 방법](./quick-start.mdx#updating-from-1x)을 읽어 주십시오. 이전 땀 마테리얼의 모양 값이 새 기본값으로 바뀌고, 첫 <strong>[설치 / 업데이트]</strong>에서 아바타별 데이터를 새로 저장합니다.

제거, 깨끗한 재설치, Base·Effects·Full Pack 사이의 변경은 [제거·재설치·모듈 변경](./troubleshooting.mdx#uninstall-reinstall-or-change-modules)을 따라 주십시오.

## v2.1.0 {/* #v210 */}

v2.1.0(2026-11-16)은 심박 연동(실험, 선택), 1.x 패턴 밀도, Linux·macOS 에디터에서의 구매 인증을 더하고 여러 문제를 고친 업데이트입니다.

업데이트하려면 보유한 Base／Effects 모듈을 모두 v2.1.0으로 기존 파일 위에 덮어 임포트합니다. 2.0.x에서 업데이트할 때는 <strong>[설치 / 업데이트]</strong>를 다시 누르지 않아도 됩니다. 심박 연동과, **땀 표시**를 끌 때 바닥 물자국도 숨기는 것은 <strong>[설치 / 업데이트]</strong>를 누를 때 들어갑니다. 1.x에서 업데이트하려면 [1.x에서 업데이트하는 방법](./quick-start.mdx#updating-from-1x)을 따라 주십시오.

- **심박 연동 (실험, 선택, 기본 꺼짐):** 심박 앱이 OSC로 VRChat에 보내는 심박수(BPM)에 맞춰 자동 모드의 땀 양이 정해집니다. 설치 창 첫 화면의 **자동 모드 감도** 아래에서 **심박 연동**을 켜고 <strong>[설치 / 업데이트]</strong>를 눌러 주십시오. 끄면 아바타에 아무것도 더하지 않고, 켜도 동기화 비트는 늘지 않습니다. Unity 안에서 시험했고, 게임 안에서 심박 앱과 함께 쓰는 시험은 아직 하지 못했습니다. 자세한 내용은 [심박 연동](./usage/heart-rate-link.mdx)에 있습니다.
- **1.x 패턴 밀도:** 땀이 1.x (레거시) 스타일일 때 Tuning의 **표면 물방울 외형**에서 **패턴 밀도** 아래에 **1.x 패턴 밀도**(4~64)가 나옵니다. 1.x (레거시) 스타일만 읽는 값이고, 올리면 물방울이 더 많고 작아집니다. 새 설치는 22에서 시작하고, 1.1.x에서 업데이트한 아바타는 1.x에서 쓰던 값을 그대로 씁니다. 그래서 다른 설정이 같아도 아바타마다 레거시의 물방울 수가 크게 다를 수 있습니다. 이때 이 값으로 맞춰 주십시오.
- **구매 인증 (Linux·macOS):** Linux·macOS의 Unity 에디터에서도 구매 인증을 할 수 있습니다. 지금까지는 인증 정보를 Windows 전용 방식으로만 보관해서 Linux·macOS에서는 인증할 수 없었습니다. Windows에서는 달라지는 것이 없고, 이미 인증한 PC는 다시 인증하지 않습니다. Real Sweat System은 Windows에서 시험합니다. Linux는 실제 환경에서 확인했고, macOS는 아직 확인하지 못했습니다.
- **Clothing Fix:**
  - <strong>마테리얼 복제본으로 적용 (권장)</strong>을 다시 눌러도(예: 의상을 더 넣은 뒤) 직접 바꾼 복제본을 덮어쓰지 않습니다. 바꾼 복제본은 그대로 두고 렌더 큐만 땀에 맞추며, 결과에 그 이름이 나옵니다. 원본에서 다시 만들려면 **추적된 의상 변경 복원**을 누른 뒤 다시 적용해 주십시오. 바꾸지 않은 복제본은 지금처럼 원본의 변경을 따릅니다. Poiyomi의 Lock과 Lock 해제, 셰이더 인스펙터가 스스로 저장하는 값, 셰이더 업데이트로 늘어난 속성은 바꾼 것으로 치지 않습니다.
  - **원본 마테리얼에 직접 적용:** 같은 마테리얼에 이 방식을 적용한 다른 설치 아바타(복제한 아바타 등)가 열려 있는 씬에 있으면, 한쪽에서 **추적된 의상 변경 복원**이나 <strong>[제거]</strong>를 해도 렌더 큐를 올린 채로 두고 결과에 알립니다. 마지막으로 복원하거나 제거하는 아바타가 원래 큐로 되돌립니다. 다른 설치가 이미 올려 둔 마테리얼에 나중에 적용한 아바타도 그 마테리얼을 함께 추적합니다. 그 다른 아바타가 저장하지 않은 씬이나 프리팹 모드에만 있을 때도 큐를 올린 채로 두고, 그 씬을 저장하라고 알립니다. 2.1.0 전에 적용한 아바타는 다시 적용하면 이렇게 됩니다.
  - 2.1.0부터 적용한 마테리얼은 원래 렌더 큐가 셰이더 기본값(From Shader)이면, 복원할 때 숫자로 굳지 않고 셰이더 기본값으로 돌아갑니다. 복원과 제거는 직접 푼 Poiyomi Lock을 다시 걸지 않습니다.
  - '다른 메쉬에도 땀 넣기'로 땀을 넣은 렌더러는 의상으로 넣을 수 없습니다(나중에 그리면 그 땀이 가려지기 때문입니다). 아바타 칸에 프로젝트 창의 프리팹을 넣으면 아무것도 바꾸지 않고 멈춥니다. 씬(Hierarchy)의 아바타를 넣어 주십시오.
- **제거:** 생성 폴더를 지우기 전에 열려 있는 모든 씬과 프리팹 모드에서 그 폴더를 쓰는 오브젝트를 찾습니다. 저장하지 않은 다른 씬의 복제 아바타가 쓰던 땀 파일이 지워지던 문제를 고쳤습니다. 설치 정보 없이 남은 생성 파일을 제거할 때도, 다른 오브젝트가 그 폴더를 쓰고 있으면 쓰는 곳의 이름을 알려 줍니다.
- **설치 창과 [설치 / 업데이트]:**
  - 프로젝트에 스크립트 컴파일 오류가 있어 모듈을 불러오지 못하면, 다시 임포트하라고 하지 않고 Console의 빨간 오류를 먼저 고치라고 알립니다([설치 창이 프로젝트에 스크립트 컴파일 오류가 있다고 함](./troubleshooting.mdx#script-compile-errors)).
  - '파라미터가 모자랄 수 있습니다' 경고가 다른 오브젝트의 Modular Avatar Parameters가 업로드할 때 더하는 파라미터도 셉니다. 그래서 업로드할 때에야 실패하던 아바타도 미리 알 수 있습니다.
  - `RealSweat` 오브젝트를 옮기거나 이름을 바꿨으면, 원인과 다른 오류(파라미터 이름 충돌, 설치 정보 불일치) 대신 지금 위치와 되돌릴 곳(아바타 루트 바로 아래, 이름 `RealSweat`)을 알려 줍니다. EditorOnly 아래에 둔 백업은 이 안내에 나오지 않습니다.
  - Modular Avatar 1.12~1.16에서 늘 나오던 'Modular Avatar가 오래되었습니다' 창이 나오지 않습니다. 1.12보다 오래된 판에서는 아무것도 바꾸기 전에 1.12 이상이 필요하다고 알리고 멈춥니다(전에는 오류로 멈췄습니다).

  - 탄젠트가 없는 바디를 <strong>안전한 사본 만들기 (권장)</strong>로 설치한 아바타는 업데이트할 때마다 같은 질문을 묻지 않습니다.

  - 큰 프로젝트에서 <strong>[설치 / 업데이트]</strong>가 빨라졌습니다(Rest 굽기마다 프로젝트 전체를 새로 고치지 않습니다).
  - 편집 중의 Write Defaults 판정이 EditorOnly 아래의 Merge Animator를 세지 않습니다. 업로드에서 빠지는 것이라 빌드의 판정과 달라질 수 있었습니다.
  - 창 언어가 한국어나 일본어일 때 영어로만 나오던 바디 빌드 오류, 파라미터 이름 충돌 목록, Tuning의 **입 파라미터** 설명도 그 언어로 나옵니다.

- **그늘진 어두운 피부:** 실사에서 그늘진 어두운 피부 위의 물방울과 흐른 자국이 흰 줄이나 흰 점처럼 보이던 것을 줄였습니다. 밝은 피부와 구릿빛 피부는 그대로입니다.

- **설명서:** 패키지에 든 README에 **옷 뒤 땀 숨기기와 젖은 피부 막** 절을 더했습니다.

Base와 Effects는 따로 인증하며, Full Pack은 둘 다 포함합니다. 이미 설치한 아바타의 업데이트, **FX에 적용**, <strong>[제거]</strong>, 빌드는 막지 않습니다. 자세한 내용은 [구매 인증](./license-activation.mdx)에 있습니다.

- **Windows 전용:** 구매 인증이 Windows 데이터 보호 기능을 쓰므로 Mac과 Linux의 에디터에서는 인증할 수 없고, 그곳에서 업로드하면 효과가 빠집니다. (v2.1.0부터는 Linux·macOS 에디터에서도 인증할 수 있습니다. [v2.1.0](#v210)을 봐 주십시오.)

### 주요 변경 사항

- **그림으로 고르는 땀 스타일 두 가지:** 설치 창 첫 화면에서 두 그림 가운데 하나를 누릅니다. **애니**는 윤곽과 밝은 하이라이트가 있는 또렷한 만화풍 물방울이라 멀리서도 잘 보입니다. <strong>실사 (기본)</strong>는 윤곽 없는 투명한 작은 물방울이 많고, 비쳐 보이는 피부가 렌즈처럼 살짝 휘어 보이며, 멀리서는 젖은 광택으로 보입니다. 새 설치와 v1.1.x에서 업데이트한 아바타는 실사로 시작하고, 2.0.0으로 이미 설치한 아바타는 고른 스타일을 그대로 씁니다. 스타일은 아바타마다 하나이고, 나중에 Tuning의 **기본 설정 > 땀 스타일**에서 바꿀 수 있습니다.
- **두 스타일 모두 입체 물방울:** 물방울 입체감(테셀레이션, 고부하)을 다시 만들었습니다. 가까이에서 맺힌 물방울과 흘러내리는 물방울이 피부 위로 실제로 솟아 옆에서 봐도 둥글게 보입니다. 애니와 실사 모두에서 동작합니다. 기본 정밀도에서는 약 0.7 m보다 멀면 입체감이 없을 때와 똑같이 그립니다.
- **새 피부 땀 모양:** 맺힌 물방울과 흘러내리는 물방울, 땀구멍 물방울, 흐른 자국과 막 흐른 자국의 광택, 얇은 젖은 막, 먼 거리의 모습을 처음부터 다시 만들었습니다. 흐른 자국은 v1.1.x처럼 거의 곧게 내려갑니다. 애니에서는 흐르는 물방울의 머리가 둥글고 줄기가 매끄럽게 이어져, 줄기와 물방울이 끊겨 보이지 않습니다. 실사에서는 흐르는 물방울이 지나가며 거둔 작은 물방울이 바로 뒤에서 다시 나타나지 않고, 자국이 마르면서 돌아옵니다.
- **가까이에서 더 또렷한 물방울:** 물방울이 조금 커지고(물방울 크기 1.6) 반짝임이 더 크고 밝아졌습니다. 반짝임은 마테리얼 인스펙터 빠른 설정의 **반짝임 크기**와 **반짝임 세기**(둘 다 1.5)로 바꿀 수 있고, 1로 낮추면 더 차분한 모습입니다.
- **땀 흐름:** 마테리얼 인스펙터 빠른 설정에 가파른 피부에서 흘러내리는 물방울의 수와 거리를 정하는 슬라이더가 생겼습니다. 기본값 1이 스타일마다의 기본 모습이고, 0이면 물방울이 제자리에 머물고, 2면 대부분 흘러내립니다.
- **어두운 피부:** 물방울이 회색 원판 대신 밝게 반짝이고, 막과 흐른 자국이 덜 번들거립니다. 흰 피부, 보통 피부, 태닝 피부의 모습은 그대로입니다.
- **몸에 맞춘 물방울 크기:** 몸통과 다리의 휴머노이드 뼈 길이로 잽니다. 바운딩 박스를 쓰지 않으므로 머리카락, 모자, 액세서리, 자세의 영향을 받지 않습니다. 어느 아바타의 어느 메쉬에서도(cm든 m든) 물방울이 몸에 비해 같은 크기이고, 아바타 배율에 따라 함께 바뀝니다. 휴머노이드가 아닌 아바타는 시점 위치를 씁니다.
- **새 설치 창:** 첫 화면에는 상태, **땀을 넣을 곳**(바디 메쉬 칸. 찾은 메쉬가 틀리면 맞는 메쉬를 끌어다 놓습니다. 그 아래에 마테리얼이 보이고, <strong>[바꾸기]</strong>를 누르면 고급 설정의 마테리얼 칸 고르기가 열립니다), **설치할 이펙트**(낙하 물방울·바닥 물자국·입김·몸 김)와 **피부 땀**(**젖을수록 피부 광택**)의 체크 상자, 스타일 그림, **표현** 그림(**기본** / **입체 (고부하)**), **부하** 버튼(**저부하(권장)** / **표준**), 자동 모드 감도, <strong>[설치 / 업데이트]</strong>가 있고, 나머지 옵션은 **고급 설정**에 있습니다. 고급 설정의 **이펙트**에는 몸 김이 나오는 곳과 진하기 메뉴가 있습니다. <strong>입체 (고부하)</strong>는 물방울 입체감, 3D 파티클, 물방울 튀김을 함께 켜고, 그 아래에 **처음부터 켜기**가 나옵니다. 새로 설치하면 **기본**으로 시작하고 튀김은 꺼져 있습니다. 입체 그림 아래에는 물방울이 가까이나 옆에서 볼 때 솟아 보인다는 설명과, 처음부터 켜기를 체크하지 않으면 물방울 입체감은 처음에 꺼져 있고 인게임 메뉴에서 켠다는 설명이 있습니다. 꺼 두면 그 메뉴 위치를 안내 상자로 알려 줍니다. 그림은 창 크기와 상관없이 같은 크기로 보이고, 창이 짧으면 스크롤됩니다. **경량**은 **고급 설정 > 품질·부하**에서 고릅니다. 탭은 설치 / 문제 해결 / 제거이고, 결과는 누른 버튼 바로 아래에 나오며, 오래 걸리는 단계에서는 진행 막대가 나옵니다.
- **새 몸 김:** 한 점에서 큰 덩어리 하나가 솟는 대신, 뭉개진 옅은 김이 그 주변 넓은 곳(가슴 위쪽, 어깨선, 허벅지와 발목 앞쪽)에서 천천히 피어오릅니다. 걸을 때 몸을 따라오고, 깊이 텍스처가 없는 월드에서도 보이며, 어두운 월드에서 빛나지 않고, 파티클도 줄었습니다(기본 설치 최대 168 → 95).
- **새 낙하 물방울·튀김:** 떨어지며 늘어나는 더 작은 물방울과 둥근 작은 방울이 짧게 튀는 튀김입니다. 두 스타일과 2D·3D 파티클 모두에 적용됩니다. 2D에도 튀김이 생겼고, 3D의 왕관 모양 고리는 없어졌습니다. 바닥 물자국은 1.1.3과 같은 번진 모양으로 바닥을 어둡게만 합니다.
- **3D 몸 김·입김의 성능 순위:** 모습은 그대로이고, VRChat 성능 순위의 Mesh Particle Active Polys가 크게 줄었습니다(기본 설치의 김·입김 96,000 → 92).
- **훨씬 가벼워졌습니다:** 다른 사람이 이 아바타를 처음 불러올 때의 셰이더 컴파일 멈춤이 v1.1.3보다 약 3분의 2 짧아졌습니다. 기본 설치의 땀 100% 부하는 v1.1.3의 약 절반이고, 땀 0%의 부하도 크게 줄었습니다. [측정값](./performance.mdx#measured-load)을 확인해 주십시오.
- **렌더 큐 2350:** 피부 땀의 렌더 큐가 2350이 되었습니다(v1.1.x는 2455). 그래서 바디 위에 겹쳐 그리는 그림자·데칼 마테리얼과 같은 큐에 놓이지 않고, Cutout 의상과 머리카락이 땀을 가립니다. 바디 렌더러에 2350 이상인 불투명·Cutout 마테리얼이 있으면 설치 창이 2349로 낮출지 한 번 묻고(권장), 제거할 때 원래 큐로 되돌립니다.
- **화면 복사 분리:** 2.0.0의 땀은 새 이름의 화면 복사에서 피부를 읽으므로, 같은 화면의 v1.1.x 땀과 섞이지 않습니다. 2350이 아닌 큐에 그리는 땀은 "(Late Queue)" 셰이더를 사용합니다.
- **Light Limit Changer 따라가기:** Light Limit Changer(LLC)로 아바타의 밝기(최소·최대 밝기)를 바꾸면 피부 땀도 같은 비율로 따라갑니다. 바디 피부가 lilToon이나 Poiyomi일 때 동작하며, 따로 정할 것이 없고 파라미터도 늘지 않습니다.

### 그 밖에 바뀐 것

- **땀 품질**(이전의 '전체 땀양')에서 세 단계 가운데 하나를 고릅니다: 표준, 저부하(권장, 기본값), 경량. 피부 땀의 양은 세 단계 모두 같아졌습니다(30%에서 0.30, 100%에서 1.00). 그래서 저부하나 경량을 쓰던 아바타는 v1.1.x보다 땀이 많아 보입니다.
- 아바타마다 무늬 번호를 받으므로, 같은 아바타 두 명이 같은 자리에 땀을 흘리지 않습니다.
- 새 모양에는 Rest 데이터가 필요합니다(설치 창이 굽습니다). Rest 데이터가 없는 마테리얼은 마테리얼 인스펙터와 Tuning이 알려 줍니다.
- **거울에서도 땀 고품질**이 꺼져 있으면(기본값) 거울에서는 땀구멍의 작은 물방울을 빼고, 물방울 입체감도 솟지 않습니다.
- **상대 저부하**가 이제 모든 단계에서 다른 사람에게 보이는 피부 땀을 가볍게 합니다. 몸 김은 개수를 줄이지 않고 진하기 0.6배로 보입니다.
- 마테리얼 인스펙터는 새 모양이 읽는 값만 보여 줍니다. 프리셋은 **기본 모습으로 되돌리기** 버튼 하나로 바뀌었습니다.
- 뺀 기능: 우유 모드, 바디 노멀맵의 젖은 표현, 광학 LUT, 흐름 가이드 맵, Rest 패턴 회전, 수동 Rest 축 모드, VRC Light Volumes 지원. 업데이트하면 'VRC 라이트 볼륨' 메뉴 토글과 1bit 파라미터가 빠집니다. 옛 값은 마테리얼에 숨겨진 채 남고, 쓰지 않는 텍스처는 아바타 빌드에서 업로드되지 않습니다.
- 인게임 메뉴 이름: '표면 땀 숨기기'를 '피부 땀 숨기기'로 바꿨습니다. 파라미터와 저장된 값은 그대로입니다.
- 제거한 뒤 마테리얼 목록이 프리팹과 다시 같아진 프리팹 인스턴스에는 마테리얼 재정의가 남지 않습니다.
- **3D 파티클 몸 김:** 단계별 양은 1.1.3과 같습니다(저부하와 경량에서 표준의 0.65배). 일부 테스터에게만 배포한 2.0.0 시험판에서 김 덩어리가 엉뚱한 자리에 그려지던 문제(길게 늘어진 줄과 색 얼룩, 1.1.x에는 없던 문제)도 고쳤습니다. 3D 파티클을 쓰는 아바타는 <strong>[설치 / 업데이트]</strong>나 **FX에 적용**을 한 번 누른 뒤 다시 업로드해 주십시오.
- **깊이 텍스처가 없을 때의 3D 파티클 몸 김·입김:** 카메라에 깊이 텍스처가 없는 월드(실시간 그림자를 드리우는 디렉셔널 라이트가 없는 월드 등)에서 더 이상 사라지지 않습니다.
- **투명한 실사 물방울:** 실사 물방울이 윤곽 없는 투명한 물방울로 바뀌었고, 빛을 굴절시킵니다. 둘레에 어두운 테두리, 고리, 접촉 그림자가 없어서 더 이상 피부 위의 혹처럼 보이지 않습니다. 물방울을 통해 보이는 피부는 렌즈처럼 살짝 휘어 보입니다. 큰 물방울에는 작은 흰 하이라이트가 생겼고, 흐른 자국은 회색 줄 없이 맑고 윤기 있는 줄이 되었으며, 아주 작은 물방울은 조금 줄었습니다. 정면에서 본 물방울은 그대로 또렷합니다. 애니는 그대로입니다(또렷한 윤곽과 하이라이트).
- **실사의 몸 윤곽:** 얇은 막이 비추는 하늘 반사가 윤곽 쪽으로 갈수록 밝아지지 않습니다. 그래서 몸의 윤곽을 따라 생기던 밝은 선이 절반 아래로 옅어졌습니다. 애니는 그대로입니다.
- **낙하 물방울·바닥 물자국·튀김:** 기존 설치는 <strong>[설치 / 업데이트]</strong>를 한 번 누르면 새 모양으로 바뀝니다. **낙하 방울 최대 개수 (시스템별)** 기본값은 64에서 12로 바뀌고, 강한 움직임 방울은 그 2/3인 8개까지 씁니다. 64 그대로인 설치만 바뀝니다. v1.1.x의 2D 파티클 설치는 업데이트해도 튀김 없이 그대로입니다. 튀김을 쓰려면 <strong>[설치 / 업데이트]</strong>를 누르기 전에 **물방울 튀김**을 켜거나 <strong>입체 (고부하)</strong>를 골라 주십시오.
- **편집기 코드 DLL:** 편집기 코드가 컴파일된 DLL로 들어갑니다. `Core/Editor/CookiTools.RealSweatSystem.Editor.dll`과, Effects Module에서는 `Modules/SweatEffectModule/Editor/CookiTools.RealSweatSystem.Effects.Editor.dll`입니다. 일부 `.cs` 파일에는 이제 두 줄짜리 주석만 들어 있습니다. 이 파일들은 이전 버전 위에 업데이트할 때 같은 이름의 이전 스크립트를 덮어쓰므로 지우지 마십시오.
- **버전이 섞인 모듈:** Base와 Effects의 버전이 다르면 설치 창은 여전히 설치하지 않지만, 아바타 빌드는 더 이상 멈추지 않습니다. 대신 업로드에서 Real Sweat System을 빼고 Console에 경고를 남깁니다.
- **젖은 피부 막 토글:** 인게임 땀 메뉴에 **젖은 피부 막** 토글(기본 켜짐)이 생겼습니다. 이 토글은 물방울 사이의 얇은 젖은 막과 그 광택(멀리서 보이는 반짝임 포함)을 켜고 끄며, 동기화 파라미터를 1bit 씁니다. 설치 창의 **젖을수록 피부 광택**이 켜져 있을 때만 설치됩니다.
- **정면에서도 또렷한 물방울:** 정면에서 본 물방울도 또렷하게 반짝입니다.
- **컴포넌트 아이콘:** RealSweat 컴포넌트(Tuning, Installer, Custom Steam Point)는 Hierarchy와 Inspector에서 기본 스크립트 아이콘 대신 RealSweat 아이콘을 보여 줍니다. Scene 뷰의 아이콘은 프로젝트마다 한 번만 끕니다. Scene 뷰의 Gizmos 메뉴에서 다시 켤 수 있습니다.
- **Ctrl+Z:** <strong>[설치 / 업데이트]</strong>, Tuning의 **FX에 적용**, <strong>[제거]</strong>, Rest Vertex Data Baker의 **2. 베이크 및 할당**은 Ctrl+Z로 되돌릴 수 없습니다. 이 동작들은 생성 파일을 지우거나 다시 만들기 때문에, 되돌리면 없는 파일을 가리키게 됩니다. 누르기 전에 한 변경은 그대로 Ctrl+Z로 되돌릴 수 있습니다. 설치를 없애려면 <strong>[제거]</strong>를 써 주십시오.
- **제거:** <strong>[제거]</strong>를 누른 뒤 NDMF가 Console에 오류를 내지 않습니다.

### 알려진 제한

- Rest 데이터가 맞지 않으면 땀을 그리지 않습니다. 설치 전의 마테리얼이나 굽기 뒤에 바뀐 메쉬가 그렇습니다(다음 빌드에서 다시 구울 때까지).
- 물방울 입체감은 가까이에서 GPU 부하가 늘어나는 고부하 옵션입니다.
- 땀 0%와 땀 표시 끄기는 완전히 공짜가 아닙니다. 굴절을 위한 화면 복사(GrabPass, 약 +0.05 ms)가 남습니다. 부하가 없어지는 것은 피부 땀 숨기기뿐입니다.
- 상대 저부하: 면의 방향이 바뀌는 곳(몸통 옆, 팔 등)에서 다른 사람 화면의 물방울 아래쪽 끝이 곧게 잘려 보일 수 있습니다. 드물고 작은 차이입니다.
- 실사: 접힌 곳(배꼽 위 등)에서는 작은 물방울이 두 쪽으로 갈라져 보일 수 있고, 물방울끼리 실제로 합쳐지지는 않습니다. 실사의 경량은 실사의 저부하·표준과 물방울 배치가 조금 다릅니다.
- 옷에 맺히는 RealRain 자체의 실사 빗방울은 RealRain 업데이트로 제공됩니다. RealRain이 피부에 묻히는 빗물은 이미 땀 스타일을 따릅니다.

### 되돌리는 방법

v2.0.0에는 이전 모양이 들어 있지 않습니다. 이전 모양이 필요하면 v1.1.3을 계속 사용해 주십시오. 업데이트한 뒤 되돌리려면 업데이트 전에 만든 백업을 사용해 주십시오.

## v1.1.0 {/* #v110 */}

### v1.0.0～v1.0.2에서 업데이트

중간 버전을 거칠 필요는 없습니다. 현재 v1.0.0～v1.0.2 설치는 [같은 절차](./quick-start.mdx#updating-from-1x)로 v2.1.0에 바로 업데이트합니다. 다음 v1.1.0 이전 안내는 이 설치들에도 그대로 적용됩니다.

- 이전 RealSweat 생성 데이터가 발견되면 닫을 수 있는 Scene 뷰 알림이 표시됩니다. 준비가 되었을 때 설치 창에서 <strong>[설치 / 업데이트]</strong>를 눌러 주십시오.
- 기존 감도·땀 품질·자동 반응·주요 토글·몸 김 위치는 대부분 유지됩니다. 생성된 컨트롤러·메뉴·클립·파티클을 직접 수정했다면 설치 중 다시 생성될 수 있으므로 별도로 백업해 주십시오.
- 바닥 물자국의 `Pooling Chance`가 정확히 기존 기본값 `0.25`라면 새 기본값 `0`으로 이전됩니다. 다른 사용자 지정 값은 유지됩니다.
- 기존 몸 김 거울 설정은 외형 보존을 위해 `Full`로 유지됩니다. 새 설치 기본값은 `Low`입니다.
- 3D 파티클과 바디 땀 거울 전체 품질은 자동으로 켜지지 않습니다. 젖은 피부 광택도 업데이트 시 기존 설치 마테리얼 상태를 따릅니다.
- Base와 Effects의 구버전·신버전 혼용은 Setup과 빌드에서 차단됩니다. 제거는 필요하지 않습니다.

### 새 기능과 개선

- 기본의 가벼운 2D 파티클을 유지하면서 선택형 고부하 3D 입김·몸 김·낙하 물방울을 추가했습니다.
- 3D 낙하 물방울의 선택형 충돌 튀김을 추가했습니다.
- 3D 낙하 물방울과 몸을 흔들 때 튀는 물방울의 기본 크기를 최초 크기보다 8% 작게 조정했습니다.
- 전용 파티클 셰이더와 몸 김 `Full / Low / Hidden` 거울 모드를 추가했습니다.
- 선택형 바디 땀 거울 전체 품질을 추가했습니다.
- 젖은 피부 광택 Setup 옵션, VRC Light Volumes 인게임 토글, **표면 땀 숨기기**를 추가했습니다. VRC Light Volumes 인게임 토글은 v2.0.0에서 제거되었습니다.
- 채널·반전·강도·타일링·오프셋을 지원하는 최종 바디 표면 표시 마스크를 추가했습니다.
- Tess／No Tess 원본 셰이더와 **비주얼 초기화**의 얇은 젖은 자국 기본값을 `0`으로 통일했습니다. 비주얼 초기화 시 물방울 크기와 패턴 밀도도 관리 대상 및 연동 파티클 설정에 함께 전파됩니다. v2.0.0에서는 프리셋이 **기본 모습으로 되돌리기** 버튼 하나로 바뀌었습니다.
- 한 Body Renderer의 여러 Material Element와 별도 `SkinnedMeshRenderer`를 설치하는 실험적 추가 대상 기능을 추가했습니다.
- Tuning 상태 표시, **추가 대상 관리...**, 안내에 따른 복구·제거, 손상된 생성 슬롯의 빌드 차단을 추가했습니다.
- 위치마다 설정하고 좌우 미러 페어를 지원하는 Custom Steam Point를 추가했습니다.
- 기본 미설치인 선택형 저장·동기화 **몸 김·입김 진하기** 래디얼을 추가했습니다. 0%는 불투명도 0.1배, 50%는 기존 표현을 유지하는 1.0배, 100%는 1.5배입니다. 불투명도만 바꾸며, 0%도 효과를 끄지 않고, 파티클 수와 성능 부하는 줄지 않습니다.
- 선택형 **내 시점에서도 입김 보기**를 추가했습니다.
- 바닥 자국의 3×3 변형, 충돌 직후의 짧은 퍼짐, 완만한 겹침 농도, 바뀐 건조 방식을 적용했습니다.
- 바디 자동 감지, 파라미터 이름 충돌 검사, 최종 Rest／Tangent 검증, d4rkAvatarOptimizer 보호, 모듈 버전 혼용 차단, 설치 실패 시 롤백을 보강했습니다.
- 빌드 후반 Submesh의 `baseVertex` 변경에 대응하는 호환 처리를 추가해, 확인된 Modular Avatar Shape Changer Delete 구성에서 표면 땀이 파편화되는 문제를 방지했습니다. 모든 메쉬 변경 도구·조합과의 완전 호환을 보장하는 것은 아닙니다.
- 일부 Body 메쉬의 내장 버텍스 컬러 때문에 파티클이 보이지 않는 경우를 위한 선택형 낙하 물방울 호환 설정을 설치 창의 **문제 해결** 탭에 추가했습니다. 기본 동작은 바뀌지 않으며 낙하 물방울과 몸을 흔들 때 튀는 물방울에만 적용됩니다.
- 선택형 3D 물방울 파티클 셰이더에서 사용하지 않는 조명·Soft Particle 변형 축을 제거했습니다. 외형과 GPU 인스턴싱은 바뀌지 않습니다.
- 메뉴 이름을 `땀 켜기`에서 **땀 표시**로 바꾸고, 이펙트를 별도 하위 메뉴로 나눴습니다.

### v1.1의 중요한 제한

- 실험적 추가 대상은 `SkinnedMeshRenderer`만 지원하며, 설정한 대상마다 땀 마테리얼과 드로우 부하가 하나씩 추가됩니다.
- 각 대상에는 Read/Write 가능한 메쉬 데이터, 유효한 Submesh／마테리얼／Tangent, 고유한 애니메이션 경로, 공유하지 않는 생성 땀 마테리얼 연결이 필요합니다.
- RealSweat이 생성한 마테리얼이나 Renderer 슬롯을 삭제·비우기·이동·교체·병합하지 마십시오. 대상의 복구나 제거는 <strong>추가 대상 관리...</strong>와 <strong>[설치 / 업데이트]</strong>로 해 주십시오.
- Face Tracking, 표정, 메쉬 병합·교체·최적화의 모든 조합은 보장되지 않습니다. 눈·입술 주변 Tess는 피해 주십시오.
- 바닥 물자국은 낙하 물방울의 충돌 하위 이펙트이므로 낙하 물방울이 켜져 있어야 합니다.
- 활성 Custom Steam 슬롯은 최대 4개이며 미러 페어는 2개를 사용합니다. 내장／Custom을 합쳐 12개가 상한이며, 발생량 가중치가 `4.0`을 넘으면 같은 비율로 줄입니다.
- 3D 파티클과 거울 전체 품질 옵션은 GPU 부하를 늘립니다. 3D에서 몸 김 `Low`는 현재 `Full`과 같은 부하이므로, 거울 비용을 가장 낮추려면 `Hidden`을 사용해 주십시오.

현재 동기화 파라미터 비용은 [기술 사양](./technical-specifications.mdx#synced-parameters)을 확인해 주십시오.

## v1.0.2 — 2026-07-27 {/* #v102--2026-07-27 */}

### 호환성 개선

- v1.0.1에서 전체 FX가 WD ON인 아바타에 RealSweat Output 레이어만 WD OFF로 추가되어 ON/OFF 혼합 구성이 되면서, 일부 MMD 댄스 중 표정·립싱크가 작동하지 않던 문제를 수정했습니다.

- WD OFF, ON/OFF 혼합 또는 판정 불가 환경에서는 v1.0.1의 Driver ON / Output OFF 호환 구조를 유지합니다.
- 빌드 시 NDMF로 최종 병합된 FX를 다시 검사하고, 감지 결과에 맞춰 RealSweat의 WD 구성을 조정합니다.

:::

:::caution[MMD 월드]
WD OFF 또는 ON/OFF 혼합 FX 구성에서는 월드의 FX 레이어 제어 방식에 따라 일부 MMD 재생 중 표정 또는 Real Sweat System이 정상적으로 작동하지 않을 수 있습니다. 자세한 내용은 [호환성](./compatibility.mdx#mmd-world-compatibility)을 확인해 주십시오.

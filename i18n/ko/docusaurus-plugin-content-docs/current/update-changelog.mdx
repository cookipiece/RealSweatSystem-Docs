# 업데이트 및 변경 내역

## 업데이트 전 안전 절차

1. 아바타 Prefab 또는 Unity Project를 백업합니다.
2. 현재 설치된 Real Sweat System 버전을 확인합니다.
3. Base와 Effects를 함께 사용한다면 같은 버전의 패키지를 준비합니다.
4. 새 UnityPackage를 가져옵니다.
5. 아바타를 선택하고 **Setup — 자동 설치 / 업데이트**를 한 번 실행합니다.
6. Console과 Play Mode에서 얼굴, 메뉴, Auto Mode 및 설치한 Effects를 확인합니다.

## v1.0.2 — 2026-07-27

### 호환성 개선

- v1.0.1에서 전체 FX가 WD ON인 아바타에 RealSweat Output 레이어만 WD OFF로 추가되어 ON/OFF 혼합 구성이 되면서, 일부 MMD 댄스 중 표정·립싱크가 작동하지 않던 문제를 수정했습니다.
- 아바타 FX의 Write Defaults 구성을 판정하는 **자동 감지 (권장)** 모드를 추가했습니다.
- RealSweat 외부 FX State가 모두 WD ON이면 생성되는 RealSweat 레이어도 모두 WD ON으로 구성합니다.
- WD OFF, ON/OFF 혼합 또는 판정 불가 환경에서는 v1.0.1의 Driver ON / Output OFF 호환 구조를 유지합니다.
- 빌드 시 NDMF로 최종 병합된 FX를 다시 검사하고, 감지 결과에 맞춰 RealSweat의 WD 구성을 조정합니다.

:::note[v1.0.1 사용자]
v1.0.2를 가져온 뒤 **Setup — 자동 설치 / 업데이트**를 한 번 실행하세요. 땀의 외형과 사용자 설정에는 의도된 변경이 없습니다.
:::

:::caution[MMD 월드]
WD OFF 또는 ON/OFF 혼합 FX 구성에서는 월드의 FX 레이어 제어 방식에 따라 일부 MMD 재생 중 표정 또는 Real Sweat System이 정상적으로 작동하지 않을 수 있습니다. 자세한 내용은 [호환성](./compatibility.mdx#mmd-월드-호환성)을 확인하세요.
:::

## v1.0.1 — 2026-07-27

### 호환성 개선

- Write Defaults ON/OFF 아바타 및 Face Tracking Animator와의 호환성을 개선했습니다.
- 얼굴 표정, 땀 토글과 Auto Mode가 함께 정상 동작하도록 Animator 설치 처리를 보강했습니다.
- 생성된 Animator 설정이 잘못 변경되는 경우를 줄이기 위한 안전 처리를 추가했습니다.

### 문서 및 UI

- **Rest Vertex Data Baker** 안내를 한국어, 영어, 일본어로 제공합니다.
- 이 도구가 일반적인 설치 과정에서 직접 사용할 필요가 없는 고급 유지보수 기능임을 명시했습니다.

:::note[v1.0.0 사용자]
v1.0.0에서 정상 동작하던 일반 아바타의 땀 표현과 기본 사용 방법은 바뀌지 않았습니다. v1.0.1을 가져온 뒤 **Setup — 자동 설치 / 업데이트**만 한 번 실행하세요.
:::

## 문서 버전 정책

작은 수정마다 문서를 복제하지 않고 최신 v1.x 문서와 이 변경 내역을 갱신합니다. 설치 방식이 크게 달라지는 버전만 별도 이전 문서로 보존합니다.

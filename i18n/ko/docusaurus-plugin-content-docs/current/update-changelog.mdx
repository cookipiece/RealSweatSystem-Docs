# 업데이트 및 변경 내역

## 업데이트 전 안전 절차

1. 아바타 Prefab 또는 Unity Project를 백업합니다.
2. 현재 설치된 Real Sweat System 버전을 확인합니다.
3. Base와 Effects를 함께 사용한다면 **두 모듈 모두 같은 버전**의 패키지를 준비합니다.
4. 새 UnityPackage를 기존 파일 위에 가져옵니다. 일반 업데이트 전에 Uninstall하거나 기존 `RealSweat` 오브젝트 또는 `Assets/CookiTools/Generated`를 삭제하지 않습니다.
5. 아바타를 선택하고 **FX에 적용**이 아니라 **Setup — 자동 설치 / 업데이트**를 한 번 실행합니다.
6. Console과 Play Mode에서 얼굴, 메뉴, Auto Mode 및 설치한 Effects를 확인합니다.

## v1.1.0

### 주요 변경 사항

- 기존의 가벼운 2D 입김·몸 김·낙하 물방울을 유지하면서 선택형 고부하 3D 파티클과 낙하 물방울 충돌 튀김을 추가했습니다.
- 3D 낙하 물방울과 몸을 흔들 때 튀는 물방울의 기본 크기를 최초 크기보다 8% 작게 조정했습니다.
- 전용 파티클 셰이더와 몸 김 `Full / Low / Hidden`, 선택형 바디 땀 거울 전체 품질을 추가했습니다.
- 젖은 피부 광택 Setup 옵션, 최종 표시 마스크와 VRC Light Volumes 인게임 토글을 추가했습니다.
- Tess／No Tess 원본 셰이더와 **비주얼 초기화**의 얇은 젖은 자국 기본값을 `0`으로 통일했습니다. 비주얼 초기화 시 물방울 크기와 패턴 밀도도 관리 대상 및 연동 파티클 설정에 함께 전파됩니다.
- 한 Body Renderer의 여러 Material Element와 별도 `SkinnedMeshRenderer`를 설치하는 실험적 추가 대상 기능을 추가했습니다.
- Custom Steam Point와 1인칭 입김 표시 옵션을 추가했습니다.
- 기본 미설치인 선택형 몸 김·입김 진하기 래디얼을 추가했습니다. 0%는 불투명도 0.1배, 50%는 기존 표현을 유지하는 1.0배, 100%는 1.5배입니다. 0%도 완전한 끄기가 아니며, 불투명도만 바꾸므로 파티클 수와 성능 부하는 줄지 않습니다.
- 바닥 자국을 2×2에서 3×3으로 확장하고 충돌 직후 퍼짐·겹침 농도·가장자리 건조를 조정했습니다.
- 메뉴에서 `땀 켜기`를 `땀 표시`로 바꾸고, 표면 땀 설정과 별도 **이펙트** 하위 메뉴로 재구성했습니다.
- 바디 자동 감지, 파라미터 이름·256bit 충돌 검사, Write Defaults/VRCFT, 최종 Rest/Tangent, d4rkAvatarOptimizer 보호, Setup 실패 롤백과 모듈 버전 혼용 차단을 보강했습니다.
- 빌드 후반 Submesh의 `baseVertex` 변경에 대응하는 호환 처리를 추가해, 확인된 Modular Avatar Shape Changer Delete 구성에서 표면 땀이 파편화되는 문제를 방지했습니다. 모든 메쉬 변경 도구·조합과의 완전 호환을 보장하는 것은 아닙니다.
- 일부 Body 메쉬의 내장 버텍스 컬러 때문에 파티클이 보이지 않는 경우를 위한 선택형 낙하 물방울 호환 설정을 **Setup > 문제 해결**에 추가했습니다. 기본 동작은 바뀌지 않으며 낙하 물방울과 몸을 흔들 때 튀는 물방울에만 적용됩니다.
- 선택형 3D 물방울 파티클 셰이더에서 사용하지 않는 조명·Soft Particle 변형 축을 제거했습니다. 외형과 GPU 인스턴싱은 바뀌지 않습니다.

### v1.0.2에서 v1.1.0으로 업데이트

v1.0.0／v1.0.1에서도 중간 버전을 거치지 않고 같은 절차로 v1.1.0에 바로 업데이트할 수 있습니다.

1. 아바타와 Unity Project를 백업합니다.
2. 보유한 Base／Effects 모듈을 **모두 같은 v1.1.0**으로 기존 파일 위에 임포트합니다.
3. 기존 버전을 먼저 Uninstall하거나 `RealSweat` 오브젝트 또는 `Assets/CookiTools/Generated`를 삭제하지 마세요.
4. `CookiTools → RealSweatSystem → Setup／Uninstall`을 열어 Body Element·추가 대상·설치 옵션을 확인합니다.
5. **Setup — 자동 설치 / 업데이트**를 한 번 실행하고 Scene을 저장한 뒤 Play Mode와 아바타 빌드로 확인합니다.

:::warning[FX에 적용만으로는 업데이트되지 않습니다]
**FX에 적용**은 이미 설치된 구조의 세부 값을 갱신합니다. v1.1의 Controller·Menu·Particle·추가 Mesh 데이터와 빌드 안전장치를 설치하려면 전체 Setup이 필요합니다.
:::

v1.1 패키지를 임포트하면 같은 GUID를 유지하는 공유 셰이더 코드는 즉시 교체되어 셰이더 수정이 먼저 반영될 수 있습니다. 반면 새 Controller·Menu·Particle·추가 대상 데이터와 설치 마이그레이션은 전체 Setup 후 적용됩니다. 따라서 정상적인 v1.0.2 설치가 Setup 전에도 대체로 계속 작동하고 빌드될 수 있다는 사실을 **업데이트 완료**로 판단하지 마세요. 이전 생성 데이터가 발견되면 Scene 뷰에 닫을 수 있는 업데이트 알림이 표시됩니다.

| 항목 | 업데이트 동작 |
|---|---|
| 감도·전체 땀양·자동 반응·주요 토글·몸 김 위치 | 대부분 유지 |
| 직접 수정한 생성 Controller·Menu·Clip·Particle | Setup에서 다시 생성될 수 있으므로 별도 백업 |
| 바닥 자국 `Pooling Chance`가 정확히 `0.25` | 새 기본값 `0`으로 이전. 다른 사용자 지정 값은 유지 |
| 기존 몸 김 거울 설정 | 외형 보존을 위해 `Full` 유지. 새 설치 기본값은 `Low` |
| 3D 파티클·바디 땀 거울 전체 품질 | 자동으로 켜지지 않음 |
| 젖은 피부 광택 | 기존 설치 마테리얼 상태 유지 |
| Uninstall 후 생성 에셋 | Undo와 Scene／Prefab 안전성을 위해 보존 |

:::caution[Base와 Effects 버전 혼용]
v1.0.x와 v1.1.x 모듈을 섞으면 Setup과 빌드가 의도적으로 중단됩니다. Uninstall하지 말고 보유한 모듈을 모두 같은 v1.1.0으로 다시 임포트하세요.
:::

## v1.0.2 — 2026-07-27

### 호환성 개선

- v1.0.1에서 전체 FX가 WD ON인 아바타에 RealSweat Output 레이어만 WD OFF로 추가되어 ON/OFF 혼합 구성이 되면서, 일부 MMD 댄스 중 표정·립싱크가 작동하지 않던 문제를 수정했습니다.
- 아바타 FX의 Write Defaults 구성을 판정하는 **자동 감지 (권장)** 모드를 추가했습니다.
- RealSweat 외부 FX State가 모두 WD ON이면 생성되는 RealSweat 레이어도 모두 WD ON으로 구성합니다.
- WD OFF, ON/OFF 혼합 또는 판정 불가 환경에서는 v1.0.1의 Driver ON / Output OFF 호환 구조를 유지합니다.
- 빌드 시 NDMF로 최종 병합된 FX를 다시 검사하고, 감지 결과에 맞춰 RealSweat의 WD 구성을 조정합니다.

:::note[과거 업데이트 안내]
v1.0.1 출시 당시에는 v1.0.2를 가져온 뒤 Setup을 한 번 실행했습니다. 현재 v1.0.0／v1.0.1 설치는 중간 버전을 거치지 않고 위의 절차로 v1.1.0에 바로 업데이트할 수 있습니다.
:::

:::caution[MMD 월드]
WD OFF 또는 ON/OFF 혼합 FX 구성에서는 월드의 FX 레이어 제어 방식에 따라 일부 MMD 재생 중 표정 또는 Real Sweat System이 정상적으로 작동하지 않을 수 있습니다. 자세한 내용은 [호환성](./compatibility.mdx#mmd-월드-호환성)을 확인하세요.
:::

## v1.0.1 — 2026-07-27

### 호환성 개선

- Write Defaults ON/OFF 아바타 및 Face Tracking Animator와의 호환성을 개선했습니다.
- 얼굴 표정, 땀 토글과 Auto Mode가 함께 정상 동작하도록 Animator 설치 처리를 보강했습니다.
- 생성된 Animator 설정이 잘못 변경되는 경우를 줄이기 위한 안전 처리를 추가했습니다.

### 문서 및 UI

- **Rest Vertex Data Baker** 안내를 한국어, 영어, 일본어로 제공합니다.
- 이 도구가 일반적인 설치 과정에서 직접 사용할 필요가 없는 고급 유지보수 기능임을 명시했습니다.

:::note[과거 업데이트 안내]
이 릴리스는 정상 동작하던 v1.0.0 설치의 땀 표현과 기본 사용 방법을 의도적으로 바꾸지 않았습니다. 현재 v1.0.0 설치는 중간 버전을 거치지 않고 위의 절차로 v1.1.0에 바로 업데이트할 수 있습니다.
:::

## 문서 버전 정책

작은 수정마다 문서를 복제하지 않고 최신 v1.x 문서와 이 변경 내역을 갱신합니다. 설치 방식이 크게 달라지는 버전만 별도 이전 문서로 보존합니다.

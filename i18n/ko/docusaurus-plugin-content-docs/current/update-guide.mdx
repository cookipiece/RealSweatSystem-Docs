# 업데이트 빠른 안내

이미 설치한 Real Sweat System을 2.0.0 이상으로 올릴 때 보는 요약입니다. 단계별 전체 절차는 [1.x에서 업데이트하는 방법](./quick-start.mdx#updating-from-1x)에 있습니다.

## 짧은 답 {/* #short-answer */}

1. 보유한 Base／Effects 모듈을 **모두 같은 버전으로** 기존 파일 위에 덮어 임포트합니다. 이전 버전을 지우거나 제거할 필요는 없습니다.
2. 설치 창에 '이전 버전으로 설치되었습니다'라는 노란 상자가 보이면 아바타마다 <strong>[설치 / 업데이트]</strong>를 한 번 누릅니다.
3. 2.0.0부터 구매 인증이 있습니다. 업로드하기 전에 PC마다 한 번 인증해 주십시오.

임포트하기 전에 아바타와 프로젝트를 **프로젝트 밖에** 백업해 주십시오. 설치 창은 `CookiTools → RealSweatSystem → Setup／Uninstall`, 인증 창은 `CookiTools → RealSweatSystem → Purchase Activation`에서 엽니다.

## 어느 버전에서 올리는가 {/* #by-version */}

| 지금 설치된 버전 | 해야 할 일 |
|---|---|
| **1.0.x, 1.1.x** | 덮어 임포트한 뒤 아바타마다 <strong>[설치 / 업데이트]</strong>를 한 번 누르고, 업로드하기 전에 구매 인증을 합니다. 중간 버전을 거칠 필요는 없습니다. |
| **2.0.x에서 2.1.0으로** | 덮어 임포트만 하면 됩니다. <strong>[설치 / 업데이트]</strong>를 다시 누르지 않아도 됩니다. [심박 연동](./usage/heart-rate-link.mdx)을 더할 때와, **땀 표시**를 끌 때 이미 바닥에 생긴 물자국도 숨기려 할 때만 누르면 됩니다. |

v1.0.0～v1.0.2에서 올릴 때는 [업데이트 및 변경 내역](./update-changelog.mdx#v110)의 v1.1.0 이전 안내도 함께 적용됩니다.

## 이렇게 해도 됩니다 {/* #fine */}

| 방법 | 결과 |
|---|---|
| 이전 버전을 지우지 않고 그 위에 덮어 임포트 | 올바른 방법입니다. 먼저 제거할 필요가 없습니다. |
| 중간 버전을 건너뛰고 바로 새 버전으로 | 됩니다. v1.0.0～v1.0.2 설치도 바로 올릴 수 있습니다. |
| Base와 Effects를 아무 순서로 임포트 | 순서는 상관없습니다. 버전만 같으면 됩니다. |
| 구매 인증을 하기 전에 임포트하고 <strong>[설치 / 업데이트]</strong>를 누름 | 됩니다. 이미 설치한 아바타의 업데이트는 인증을 묻지 않습니다. 아바타에 없던 모듈을 새로 더할 때만 인증을 묻습니다. 인증은 업로드하기 전에 해 주십시오. |

## 하지 않아도 되거나, 하면 안 되는 것 {/* #avoid */}

| 이렇게 하면 | 어떻게 되는가 | 이렇게 해 주십시오 |
|---|---|---|
| 임포트만 하고 <strong>[설치 / 업데이트]</strong>를 누르지 않음 (1.x에서 올릴 때) | 땀 마테리얼의 모양 값은 임포트 직후 새 기본값으로 바뀌지만, 아바타별 업데이트는 되지 않은 채로 남습니다. 무늬 번호, Rest의 위 방향, 몸 크기에 맞춘 물방울 크기, 새 몸 김, 메뉴 이름이 반영되지 않습니다. 설치 창에는 노란 상자가 계속 나오고, Scene 뷰에도 'RealSweatSystem 업데이트 권장' 알림이 나옵니다. | 아바타마다 <strong>[설치 / 업데이트]</strong>를 한 번 눌러 주십시오. |
| **FX에 적용**만 누름 | 이 업데이트는 되지 않습니다. 노란 상자도 그대로 남습니다. | <strong>[설치 / 업데이트]</strong>를 눌러 주십시오. |
| Base와 Effects 가운데 하나만 새 버전으로 임포트 | 설치 창이 같은 버전으로 다시 임포트하라고 알리고 설치를 막습니다. 그대로 업로드하면 빌드는 멈추지 않지만 아바타에서 Real Sweat System이 빠지고, Console에 `[RealSweatSystem]`으로 시작하는 경고가 남습니다. | 보유한 모듈을 모두 같은 버전으로 임포트한 뒤 설치 창을 다시 열어 주십시오. |
| 구매 인증을 하지 않은 PC에서 업로드 | 빌드는 실패하지 않고 창도 뜨지 않지만, 인증이 없는 모듈의 효과가 업로드한 아바타에서 빠집니다. 씬과 Play Mode에서는 그대로 보입니다. | 인증한 뒤 다시 업로드해 주십시오. <strong>[설치 / 업데이트]</strong>를 다시 누를 필요는 없습니다. |
| 먼저 <strong>[제거]</strong>하고 새 버전으로 다시 설치 | 필요 없는 일입니다. 제거하면 설치 오브젝트와 그 설치 전용 생성 폴더가 함께 정리되므로, 아바타에 맞춰 둔 설정을 처음부터 다시 맞춰야 합니다. 그 뒤의 설치는 새 설치라서 구매 인증을 묻습니다. | 제거하지 말고 덮어 임포트해 주십시오. |
| `RealSweat` 오브젝트를 직접 삭제 | 메쉬를 되돌리는 정보가 이 오브젝트에 들어 있습니다. 삭제하면 Body에 생성 메쉬와 땀 마테리얼 슬롯이 남을 수 있습니다. | 삭제하지 마십시오. 이미 삭제했다면 [`RealSweat` 오브젝트만 직접 삭제한 경우](./troubleshooting.mdx#manual-delete-recovery)를 따라 주십시오. |
| `Assets/CookiTools/Generated` 또는 `CookiTools` 폴더 전체를 삭제 | Body가 쓰던 생성 메쉬가 없어져 Body가 보이지 않을 수 있습니다. | 삭제하지 마십시오. 이미 삭제했다면 [Generated 폴더를 삭제한 뒤 Body가 사라져 보이는 경우](./troubleshooting.mdx#if-the-generated-folder-was-deleted-and-the-body-disappeared)를 따라 주십시오. |
| `Assets/CookiTools/RealSweatSystem` 제품 폴더를 지우고 다시 임포트 | 필요 없는 일입니다. 생성 파일은 보통 별도 폴더(`Assets/CookiTools/Generated`)에 남아 있습니다. | 지웠다면 보유한 모듈을 모두 같은 버전으로 다시 임포트해 주십시오. |
| <strong>[설치 / 업데이트]</strong>를 누르기 전에 모양을 다듬음 (1.x에서 올릴 때) | 그 버튼을 누를 때 모양 값이 다시 새 기본값이 됩니다. | 모양은 업데이트를 마친 뒤에 다듬어 주십시오. 그 뒤에 다듬은 값은 그대로 남습니다. |

## 1.x에서 올리면 바뀌는 것 {/* #from-1x */}

- **모양:** 2.0.0에서 피부 땀 모양을 새로 만들었습니다. 이전 버전 땀 마테리얼의 모양 값은 마테리얼마다 한 번 새 기본값으로 바뀌고, 업데이트한 아바타는 **실사** 스타일로 시작합니다.
- **물방울 자리:** 새 무늬 번호 때문에 물방울 자리가 한 번 바뀝니다.
- **렌더 큐:** 자동 렌더 순서의 땀 렌더 큐가 2455에서 2350으로 바뀝니다. 2350 이상인 바디 마테리얼이 있으면 <strong>[설치 / 업데이트]</strong>가 2349로 낮출지 묻습니다. 직접 정한 수동 렌더 큐는 그대로입니다.
- **그대로 남는 것:** 땀 품질, 자동 모드 감도, 이펙트와 메뉴, Rest 데이터, 스폰 마스크와 표시 마스크, 의상 스텐실 등은 그대로입니다.

바뀌는 값과 남는 값의 전체 목록은 [1.x에서 업데이트하는 방법](./quick-start.mdx#updating-from-1x)에 있습니다.

:::note[첫 업로드는 오래 걸릴 수 있습니다]
이 PC에서 처음 업로드할 때는 땀 셰이더를 컴파일하느라 몇 분 걸릴 수 있습니다. 진행 창이 보이지 않아도 Unity를 끄지 말고 기다려 주십시오.
:::

## 잘못 올렸을 때 {/* #recovery */}

- **임포트만 하고 버튼을 누르지 않았습니다.** 지금 아바타마다 <strong>[설치 / 업데이트]</strong>를 한 번 누르면 됩니다. 누르기 전에 다듬은 모양 값은 그때 새 기본값이 됩니다.
- **모듈 하나만 올렸습니다.** 나머지 모듈도 같은 버전으로 임포트한 뒤 설치 창을 다시 열어 주십시오. 제거할 필요는 없습니다.
- **인증하기 전에 업로드했습니다.** 인증한 뒤 다시 업로드해 주십시오. 씬의 아바타는 바뀌지 않았습니다. 확인 방법은 [업로드하면 땀이나 이펙트가 빠짐](./troubleshooting.mdx#missing-after-upload)에 있습니다.
- **먼저 제거했습니다.** 새 버전을 임포트하고 <strong>[설치 / 업데이트]</strong>를 눌러 새로 설치해 주십시오. 새 설치이므로 구매 인증이 필요합니다.
- **`RealSweat` 오브젝트나 `Generated` 폴더를 지웠습니다.** [제거·재설치·모듈 변경](./troubleshooting.mdx#uninstall-reinstall-or-change-modules)의 복구 절차를 따라 주십시오. 생성 Body 메쉬가 연결된 상태에서 <strong>[설치 / 업데이트]</strong>를 바로 누르지 마십시오.
- **이전 버전으로 돌아가고 싶습니다.** 업데이트 전에 만든 백업으로 되돌리는 것이 가장 안전합니다. 백업이 없으면 패키지에 들어 있는 README의 「v1.1.3으로 되돌리기」를 따라 주십시오. <strong>[설치 / 업데이트]</strong>, **FX에 적용**, <strong>[제거]</strong>는 Ctrl+Z로 되돌릴 수 없습니다.

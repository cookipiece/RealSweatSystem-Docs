# 보조 도구

Real Sweat System의 일반 설치와 업데이트는 Setup에서 처리됩니다. 아래 도구는 특정 의상 문제를 보정하거나, 고급 사용자가 Mesh를 수동으로 변경했을 때 사용하는 보조 기능입니다.

## RealSweatSystem Clothing Fix

입체기능(테셀레이션)을 켰을 때 물방울이 의상을 관통해 보이는 경우에만 사용합니다. **No Tess 사용자는 일반적으로 필요하지 않습니다.**

### 사용 방법

1. Real Sweat System Setup을 먼저 완료합니다.
2. Clothing Fix에서 대상 아바타를 선택합니다.
3. 문제가 보이는 의상 Renderer를 드래그하거나 목록에 추가합니다.
4. **Queue Preview**에서 변경될 재질과 순서를 확인합니다.
5. **Apply with Material Copies (Recommended)**를 실행합니다.
6. Play Mode에서 의상 표시, 땀, 아웃라인과 투명 표현을 함께 확인합니다.

**Apply with Material Copies (Recommended)**는 의상용 재질 복사본을 만들어 적용하므로, 다른 아바타나 Prefab에서 같은 원본 재질을 사용하고 있어도 영향을 분리하기 쉽습니다.

:::warning Direct mode
Direct mode는 원본 재질 자체를 변경합니다. 해당 원본 재질을 공유하는 모든 의상, 아바타, Prefab과 Scene에 같은 변경이 적용될 수 있으므로 결과를 정확히 이해하는 경우에만 사용하세요.
:::

변경을 되돌리려면 **Restore Tracked Clothing Changes**를 사용합니다.

### 확인할 사항

- Clothing Fix는 땀 Render Queue 이하에 있는 대상 재질만 변경합니다.
- 투명, Cutout, Decal, Outline 또는 여러 Layer를 사용하는 재질은 렌더링 순서가 달라질 수 있습니다.
- 적용 후 Scene과 Play Mode에서 의상의 앞뒤 관계와 기존 표현을 반드시 확인하세요.
- 문제가 없는 의상에는 미리 적용할 필요가 없습니다.

## Rest Vertex Data Baker (Advanced)

Setup은 필요한 **Rest Position / Normal / Tangent** 데이터를 자동으로 생성합니다. 따라서 일반적인 설치와 업데이트 과정에서는 이 도구를 직접 사용할 필요가 없습니다.

다음과 같은 고급 작업에만 사용하세요.

- Setup 이후 최종 Body Mesh를 수동으로 교체한 경우
- 호환되는 커스텀 재질에 Rest 데이터를 직접 연결하는 경우
- 기존 Rest 데이터의 복구 또는 문제 진단이 필요한 경우

### 기본 절차

1. 대상 Renderer와 호환되는 Material을 선택합니다.
2. **Analyze Mesh**로 현재 Mesh 상태를 확인합니다.
3. 문제가 없다면 **Bake And Assign**을 실행합니다.
4. Play Mode에서 땀의 위치와 방향을 확인합니다.

Body Mesh를 다시 교체하거나 업데이트했다면 새 Mesh를 기준으로 다시 Bake해야 합니다.

:::info 변경되지 않는 항목
Rest Vertex Data Baker는 원본 FBX, Renderer의 `sharedMesh`, UV, BlendShape 또는 다른 재질을 수정하지 않습니다. 선택한 호환 재질에 필요한 Rest 데이터만 생성하고 연결합니다.
:::

도구가 호환되지 않는 Renderer 또는 Material을 표시한다면 강제로 진행하지 말고, 기본 Setup에서 올바른 Body Mesh와 Sweat Target Element를 먼저 확인하세요.

# 5-Minute Quick Start

This guide installs Real Sweat System without changing more of your avatar than necessary.

## 1. Check the project

- Open the Unity project that contains your VRChat avatar.
- Back up the avatar Prefab or project.
- Confirm that the Console has no existing compile errors.
- Confirm that **Modular Avatar** is installed.
- If you are updating from v1.0.0, import v1.0.1 and run **Setup — Install / Update** once.

## 2. Import the package

Import the UnityPackage for the product you purchased:

- **Base Module** for skin sweat
- **Effects Module** for falling drops, floor stains, breath, and steam
- Both packages for **Full Pack (Base + Effects)**, the complete configuration

When using both modules, keep Base and Effects on the same version.

## 3. Select the avatar and Body Mesh

Open the Real Sweat System Setup tool, select the avatar root, and assign the target **Body Mesh**.

- Select a child `SkinnedMeshRenderer` with a valid mesh.
- The current installer supports **one Body Renderer per installation**.
- Do not assign the Face Renderer to the Body field.
- If the Body has multiple submeshes, choose the exact **Sweat Target Element**.
- Effects-only installation still needs the Body Mesh as the particle emission surface, but it does not modify the Body mesh or material.

If Body auto-detection does not select the correct Renderer, assign it manually.

## 4. Review the initial settings

The standard defaults are:

| Setting | Default |
|---|---|
| Overall Sweat Amount | **Low amount (Low Load)** |
| Auto Mode Sensitivity | **Balanced** |
| Automatic Render Order | **On** |
| Sweat Render Queue | **2455** |
| Follow Body Shadow Strength | **On** |
| 3D Feature (Tessellation) | **Not installed** |
| 3D Detail Precision | **Simplified — General Play** |
| Tessellation Default On | **Off**, when tessellation support is installed |

The default Effects are Falling Drops, Floor Stains, Breath Puffs, and Steam. See [Effects Guide](./usage/effects.mdx) for the default steam locations.

## 5. Install or update

Review the selected avatar and Body Mesh, then run **Setup — Install / Update**. Wait for Unity to finish before interacting with the project. When setup completes, check the Console for new errors.

If the tool reports missing tangents, choose **Safe Copy (Recommended)**.

## 6. Test in Play Mode

Use Gesture Manager or another preview method:

1. Open the avatar menu and turn **Sweat On** on.
2. Leave **Auto Mode** off and move **Sweat %** through several values.
3. Enable **Auto Mode** and compare movement with standing still.
4. Open **Reduce Load** and check the options installed by your package.
5. Confirm that facial expressions and existing avatar controls still work.

:::info[Expected behavior]
Sweat should increase continuously as Sweat % rises. At 0%, leaving Sweat On enabled keeps the system ready for Manual or Auto Mode; this is different from turning Sweat On off.
:::

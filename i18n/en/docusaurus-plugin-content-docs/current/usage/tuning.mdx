# Tuning Guide

Start with the presets, test in the intended scene, and adjust only the settings that need a different result.

## Open the Tuning component

After Setup, expand the avatar in the Hierarchy and select the generated **RealSweat** object directly under the avatar root. Its Inspector contains the **RealSweatSystem Tuning** component.

If the object is missing, open **CookiTools > RealSweatSystem Setup／Uninstall** and run **Setup — Install / Update** before tuning.

## Applying changes

- Material quality and surface appearance changes are applied immediately to the Tess and No Tess materials.
- Press **Apply to FX** after changing the automatic-response curve or other FX values.
- Press **Apply to FX** to retune generated animated wetness, falling drops, fling-particle scale, Breath Puffs, and Steam.

If Setup reports that the installed routing is outdated, run **Setup — Install / Update** once, then press **Apply to FX** again.

## Main controls

| Control | What it changes | Performance impact | Starting point |
|---|---|---|---|
| Auto Mode Sensitivity | Response to body movement | Low | **Balanced** |
| Custom Accumulation Speed Curve | Build rate across the Sweat % range | Low | Leave at the supplied curve first |
| Overall Sweat Amount | Visible amount and density | Medium to high | **Low amount (Low Load)** |
| Droplet Size | Apparent size of droplets | Low to medium | Avoid extreme values |
| Pattern Density | Number and fineness of droplets | Medium to high | Keep moderate for crowded worlds |
| 3D Feature (Tessellation) | Physical surface displacement | High | Install only when needed |

## Overall Sweat Amount

The available choices are:

- **Low amount (Lightweight)**
- **Low amount (Low Load)** — default
- **Standard amount (Medium Load)**

The names describe both appearance and expected load. Test the selected amount in a mirror and at close range before upload.

## Sensitivity and accumulation curve

The sensitivity preset determines how strongly motion feeds Auto Mode. The accumulation curve then shapes how quickly sweat builds at different points in the current Sweat % range.

The curve editor can be collapsed when you do not need it. Its graph reflects the current sensitivity so that the displayed tendency matches the active setup more closely.

## Body Normal Map and Flow Guide Map

These two textures do different jobs:

| Texture | Purpose | Does it steer droplets? |
|---|---|---|
| **Body Normal Map** | Changes wet highlights and how moisture settles around body folds | **No** |
| **Flow Guide Map (Optional)** | Adds an artist-authored UV0 tangent direction to flowing droplets and trails | **Yes** |

Do not use the Body Normal Map to fix an unwanted flow direction. For custom flow, expand **Flow & Trails > Flow Guide Map (Optional)** in the sweat material.

The Flow Guide stores direction in the RG channels. Neutral direction is `(0.5, 0.5)` gray. Import it with **sRGB (Color Texture) Off** and **Generate Mip Maps On**; padding UV-island borders with neutral gray helps prevent seams. A strength around `0.35–0.65` is a reasonable starting range. At strength `0`, the map is not sampled.

## Render order and shadows

- **Automatic Render Order** is on by default.
- Automatic Render Order fixes the **Sweat Render Queue** at **2455** and requires the selected Body material to use **2454 or lower**.
- If that Body queue is not possible, disable Automatic Render Order and set the Sweat Render Queue above the Body material.
- **Follow Body Shadow Strength** is on by default. It copies `_ShadowStrength` from the material in the selected **Sweat Target Element** into RealSweatSystem's **Cast Shadow Strength**.
- The shadow value is refreshed when **Setup — Install / Update** or **Apply to FX** runs. It is not a live runtime link, so press **Apply to FX** after changing the Body material's shadow strength.
- If the source shader does not expose `_ShadowStrength`, the current RealSweatSystem value is kept.

Change render order only when another material on the avatar requires a deliberate ordering adjustment.

## Tessellation

Tessellation support is not installed by default. When you choose to include it:

- **Tessellation Default On** remains off by default.
- **3D Detail Precision** starts at **Simplified — General Play**.
- The in-game menu adds **3D Effect (Photos Only, High Load)**.
- Turning the 3D Effect off uses the No Tess display.

:::warning[Combined load]
High sweat amount, high pattern density, close-up framing, mirrors, and tessellation can compound GPU load. Change one major setting at a time while testing.
:::

# Real Sweat System

**Real Sweat System** adds real-time sweat effects to PC VRChat avatars. Set **Sweat %** directly from the radial menu, or use **Auto Mode** to build sweat from body movement and let it dry gradually after movement stops.

:::info[Current documentation]
This documentation covers **Real Sweat System v1.0.1**.
:::

## What it can display

- Sweat and droplets on the skin
- Sweat that naturally flows with gravity
- Falling sweat drops
- Wet marks left on the floor
- Steam rising from the body
- Breath puffs driven by Visemes or VRCFT

Skin sweat is included in **Sweat Base Module**. Falling Drops, Floor Stains, Steam, and Breath Puffs are included in **Sweat Effects Module**. **Full Pack (Base + Effects)** includes both modules as the complete configuration.

## Before you begin

Real Sweat System requires:

- Unity 2022.3
- VRChat Avatars SDK3
- Modular Avatar
- A PC avatar using Direct3D 11

Quest standalone is not supported. Auto Mode is available on Humanoid avatars; other avatar types can still use Manual Mode.

# Package Guide

| Package | Main features | Best for |
|---|---|---|
| **Sweat Base Module** | Skin sweat, flowing droplets, masks, Rest data, Tess/No Tess support, mirror controls, render-order controls, Remote Low Load | Users who need skin sweat |
| **Sweat Effects Module** | 2D or optional 3D Falling Drops, Floor Stains, Breath Puffs, Body/Custom Steam | Users who need surrounding particle effects |
| **Full Pack (Base + Effects)** | Base Module + Effects Module | The complete linked sweat presentation |

Each module includes the common **Core** files it needs. Core is not a separate user-facing product.

Auto Mode requires a compatible Humanoid motion setup. Breath Puffs and Steam additionally require the relevant Head/Chest anchors. See [Compatibility](./compatibility.mdx#avatar-type) for the exact fallback behavior.

## Sweat Base Module

The Base Module adds sweat to selected material Elements of the primary Body Renderer. v1.1 can also install sweat on additional `SkinnedMeshRenderer` targets such as a separate face mesh as an **experimental** feature. Rest data is generated per mesh, not per Element; Elements on the same Renderer share that mesh mapping, while a separate Renderer gets its own Rest data. Each configured sweat Element still adds its own material and draw. Manual Mode and Auto Mode share the same Sweat % value. If tessellation support is installed, the in-game menu switches all Tess-enabled sweat slots together.

## Sweat Effects Module

The Effects Module uses the selected Body Mesh as its emission surface. It does **not** modify the Body material, Body mesh, Rest data, or tessellation setup. The existing lightweight 2D particles remain the default; optional high-load 3D rendering is selected during the full Setup.

The Effects menu appears only when this module is installed.

## Full Pack (Base + Effects)

Full Pack is the complete configuration. Install both modules at the same version so skin sweat and Effects respond to the same Sweat % value.

The avatar menu is built from the installed modules:

- **Only Visible to Me** appears in every package configuration.
- **Remote Low Load** appears when Base is installed.
- **Effects** appears when Effects is installed.
- **Droplet Depth (Tessellation / High Load)** appears only when tessellation support is installed.

## Installing, updating, or changing packages

- For a new installation, follow [5-Minute Quick Start](./quick-start.mdx).
- Keep Base and Effects on the same version when both are present.
- Do not mix v1.0.x and v1.1.x modules. Setup and avatar build intentionally stop when installed module versions do not match.
- To expand Base or Effects into Full Pack, import the missing module at the same version, then run **Setup — Install / Update** once.
- To update from v1.0.x, import every module you own at the same v1.1.0 version **over the existing files**. Do not Uninstall first or delete the `RealSweat` object. Review the targets and options, then run the full **Setup — Install / Update** once. **Apply to FX alone is not an update.**
- To remove the system or change back to a single-module installation, follow [Uninstall, reinstall, or change modules](./troubleshooting.mdx#uninstall-reinstall-or-change-modules).

# Real Sweat System

**Real Sweat System** adds real-time sweat effects to PC VRChat avatars. Set **Sweat %** directly from the radial menu, or use **Auto Mode** to build sweat from body movement and let it dry gradually after movement stops.

:::info[Current documentation]
This documentation covers **Real Sweat System v2.0.0**. It is a major update with a new skin sweat look, a new Setup window, and new body steam. To update a 1.x installation, follow [Updating from 1.x](./quick-start.mdx#updating-from-1x).
:::

## What it can display

- Sweat and droplets on the skin, in two styles: **Anime** and **Realistic (default)**
- Running droplets and trails that follow real-world gravity and run almost straight down
- Optional **Droplet Depth**: droplets close to the camera really rise from the skin
- Falling sweat drops and a short splash
- Floor stains that darken the floor
- Soft body steam that rises slowly from the area around each spot
- Breath driven by Visemes or VRCFT
- Optional 3D particles for falling drops, body steam, and breath
- Sweat on multiple Body material Elements or additional skinned meshes (experimental)

Skin sweat is included in **Sweat Base Module**. Falling Drops, Floor Stains, Breath, and Body Steam are included in **Sweat Effects Module**. **Full Pack (Base + Effects)** includes both modules as the complete configuration.

## Before you begin

Real Sweat System requires:

- Windows for the Unity editor (purchase activation works only on Windows)
- Unity 2022.3
- VRChat Avatars SDK 3.10.3 or later (checked up to 3.10.6)
- Modular Avatar
- A PC avatar using Direct3D 11
- A one-time [purchase activation](./license-activation.mdx) on each PC

Quest standalone is not supported. Auto Mode is available on Humanoid avatars; other avatar types can still use Manual Mode.

To remove Real Sweat System, do not manually delete the `RealSweat` object or `Assets/CookiTools/Generated`. Open `CookiTools → RealSweatSystem → Setup／Uninstall`, use the **Uninstall** tab, and follow the [removal procedure](./troubleshooting.mdx#uninstall-reinstall-or-change-modules).
:::

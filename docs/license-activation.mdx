# Purchase Verification

Each PC is activated once with your BOOTH order number, or your Gumroad license key if you bought on Gumroad. The activation window is at `CookiTools → RealSweatSystem → Purchase Activation`.

One order (or Gumroad purchase) covers up to 3 PCs at the same time. The Game & App license, sold only on BOOTH, allows 10.

Internet is needed to activate, and at least once every 3 weeks for the automatic renewal. Building and uploading avatars never needs it.

How to activate, how to release a PC, gifts, and error codes are explained on the page linked below.

- **Details:** [Purchase activation guide](https://cookistudio.com/license/)

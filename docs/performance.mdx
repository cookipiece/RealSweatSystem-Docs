# Performance Guide

Real Sweat System load changes with the amount of sweat visible on screen, droplet density, tessellation, mirrors, particle effects, and how many avatars are being rendered.

## Recommended adjustment order

1. Turn **3D Effect (Photos Only, High Load)** off, if it was installed.
2. Use **Low amount (Lightweight)** or **Low amount (Low Load)**.
3. Lower Pattern Density if the avatar is still expensive at close range.
4. Disable optional particle effects, starting with Steam.
5. Enable **Remote Low Load** for other viewers.
6. Use **Only Visible to Me** when remote visibility is not needed.

Make one change at a time and compare the same camera distance and mirror state.

## Tess and No Tess

Tessellation support is optional and is not installed by default. If you include it, the avatar menu can switch the 3D Effect on or off.

When the 3D Effect is off, the system uses the No Tess material instead of continuing to process tessellation invisibly. Leave the 3D Effect off for general play and enable it only when its close-up shape is useful.

## Mirrors

A mirror draws the avatar through another camera, so visible shader and particle work can increase sharply. Check performance with the same avatar:

- With the mirror off
- With the mirror on
- At normal conversation distance
- In a close-up where the Body fills much of the view

If the drop is significant, first disable the 3D Effect, then reduce Overall Sweat Amount or Pattern Density.

## Remote Low Load

**Remote Low Load** keeps your chosen local presentation while reducing the work shown to other users. It does not require a separate performance material to be uploaded by the user.

This option is available when the Base Module is installed.

## Particle controls

When the Effects Module is installed, open:

**Sweat → Reduce Load → Particles**

Disable only the effects you do not need, or use **All Particles** as a single master control.

:::info[About FPS]
FPS depends on the CPU, GPU, VR headset mode, world, mirrors, and every visible avatar. A specific FPS increase cannot be guaranteed from one setting change.
:::

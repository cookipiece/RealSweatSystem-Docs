# Update & Changelog

## Safe update procedure

1. Back up the avatar Prefab or Unity project.
2. Check the currently installed Real Sweat System version.
3. If using both Base and Effects, update both to the same version.
4. Import the new UnityPackage.
5. Open **CookiTools > RealSweatSystem Setup／Uninstall**, select the **Install** tab, and run **Setup — Install / Update** once.
6. Check the Console and test the avatar in Play Mode before upload.

For removal, clean reinstallation, or changing between Base, Effects, and Full Pack, follow [Uninstall, reinstall, or change modules](./troubleshooting.mdx#uninstall-reinstall-or-change-modules).

## v1.0.2 — 2026-07-27

### Compatibility

- Fixed an issue where v1.0.1 could add only the RealSweat Output layers as WD OFF to an otherwise all-WD-ON FX setup, creating a mixed controller that prevented expressions or lip sync from working during some MMD dances
- Added **Auto Detect (Recommended)** for the avatar FX Write Defaults structure
- When every non-RealSweat FX state uses WD ON, all generated RealSweat layers also use WD ON
- WD OFF, mixed, or unknown setups retain the v1.0.1 Driver ON / Output OFF compatible split
- Rechecks the final NDMF-merged FX controller during build and adjusts the RealSweat WD structure to the detected result

:::note[Updating from v1.0.1]
Import v1.0.2 and run **Setup — Install / Update** once. There are no intended changes to the sweat appearance or user settings.
:::

:::caution[MMD worlds]
With a WD OFF or mixed FX setup, expressions or Real Sweat System may not work correctly during MMD playback in some worlds, depending on how the world controls FX layers. See [Compatibility](./compatibility.mdx#mmd-world-compatibility).
:::

## v1.0.1 — 2026-07-27

### Fixed

- Improved compatibility with Write Defaults OFF avatars
- Improved compatibility with VRCFT and other Face Tracking animator setups
- Added safeguards so facial animation, sweat controls, and Auto Mode can operate together

### Documentation and UI

- Added Japanese, English, and Korean labels for **Rest Vertex Data Baker**
- Clarified that Rest Vertex Data Baker is not normally used in everyday setup

:::note[Existing v1.0.0 users]
This update does not intentionally change the appearance or normal controls of avatars that were already working correctly. Import v1.0.1 and run Setup once to update the generated installation.
:::

## Documentation policy

The current v1.x documentation is updated in place. Separate archived instructions are kept only when a future release requires substantially different installation steps.

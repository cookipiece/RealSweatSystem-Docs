# Manual Mode & Auto Mode

## In-game menu

The full menu is assembled from the modules and options installed during Setup.

```text
Sweat
├─ Sweat Display
├─ Sweat %
├─ Auto Mode
├─ Wet Skin Film
├─ Effects
│  ├─ All Effects
│  ├─ Falling Drops
│  ├─ Floor Stains
│  ├─ Breath
│  ├─ Body Steam
│  └─ Body Steam & Breath Intensity (optional radial)
└─ Reduce Load
   ├─ Hide Skin Sweat
   ├─ Remote Low Load
   ├─ Only Visible to Me
   └─ Droplet Depth (Tessellation / High Load)
```

- **Remote Low Load** appears when Sweat Base Module is installed.
- **Wet Skin Film** appears when Sweat Base Module is installed with **Wet Skin Gloss** on in Setup. It turns the thin wet film between the droplets and its gloss on and off, on by default, and costs 1 synchronized bit.
- **Effects** appears when Sweat Effects Module is installed.
- **Body Steam & Breath Intensity** appears only when its saved synchronized radial was selected during Setup.
- **Droplet Depth (Tessellation / High Load)** appears only when Droplet Depth was installed.

Items for modules or options that are not installed are omitted automatically. In-game menu names are made in the Setup window's language when you press **[Install / Update]**.

:::note[Menu names changed in v2.0.0]
Breath Puffs → **Breath**, Steam → **Body Steam**, Hide Surface Sweat → **Hide Skin Sweat**, Steam & Breath Intensity → **Body Steam & Breath Intensity**. Parameters are unchanged, so saved values stay. The names change when you press **[Install / Update]** or **Apply to FX**. The old **VRC Light Volumes** toggle was removed.
:::

## Manual Mode

Turn **Auto Mode** off and set **Sweat %** directly from 0–100%. Manual Mode is useful for photos, before-and-after comparisons, and scenes that need a fixed sweat level.

Manual and Auto Mode do not keep separate values. Turning Auto Mode off preserves the current **Sweat %** as the manual value. Turning it on again continues from that value instead of resetting the gauge.

The menu gauge updates in 1% steps; remote Float synchronization has approximately 1/127 (0.8%) precision.

## Auto Mode

**Auto Mode is on by default** after installation. It detects physical body movement: more movement builds Sweat % faster, and Sweat % gradually falls after movement stops.

Tracked motion such as dancing, squats, exercise-ball movement, and torso sway can drive the sensor. **WASD locomotion and jumping are intentionally excluded**, including a short settling delay after locomotion, so simply moving through a world does not make the avatar sweat. Motion response, build-up, and recovery use fixed 0.1-second updates, so their timing does not change with game FPS.

- **Auto Mode Sensitivity** controls how strongly movement is interpreted.
- The **Custom Accumulation Speed Curve** changes the build rate across the Sweat % range.
- Both settings contribute to Auto Mode.

The default sensitivity preset is **Balanced**.

Auto Mode requires a Humanoid avatar with the expected Modular Avatar bone setup. Non-humanoid avatars and avatars without the required bone reference can use Manual Mode.

## Sweat Display versus Sweat 0%

- **Sweat Display on + Sweat 0%:** the system remains ready, and Auto Mode can begin building sweat from zero.
- **Sweat Display off:** the complete sweat presentation is disabled.

Use Sweat Display at 0% when you want the avatar to begin dry and get wetter naturally after movement starts.

Sweat 0% and Sweat Display off are not completely free: the screen copy for refraction (GrabPass, about +0.05 ms) remains. Only **Hide Skin Sweat** removes the skin sweat's cost. See [Performance Guide](../performance.mdx).

## Quick behavior check

1. Enable **Sweat Display**.
2. Turn the default Auto Mode off temporarily and inspect 0%, 25%, 50%, 75%, and 100%.
3. Enable Auto Mode and move the avatar.
4. Stop moving and confirm that the value falls gradually.
5. Confirm there are no abrupt visual jumps while crossing the range.

# エフェクトガイド

Effects Moduleの機能は、アバターメニューの **Reduce Load / 負荷を軽減 > Particles / パーティクル** からまとめて、または個別にON/OFFできます。

## 初期状態

落下する滴、床の濡れ跡、息、湯気は初期状態でONです。湯気の放出位置は胸元・両肩・脇・太ももがON、股間・足がOFFです。

## Falling Drops

身体の各部から汗の粒が自然に落下します。表面の汗と同じSweat %に連動します。

## Floor Stains

落下した汗の粒が床へ到達すると濡れ跡を残します。ワールドの床構造やColliderの状態によって見え方が異なる場合があります。

## Steam

身体から立ち上る湯気を表現します。不要な放出位置はSetupでOFFにできます。

## Breath Puffs

口元から吐息を表示します。

- Visemeによる口の開閉に対応します。
- VRCFTを使用するFace Tracking構成にも対応します。
- Face Tracking環境ではv1.0.1以降を使用してください。

:::tip[パフォーマンス]
使用しないEffectsはメニューでOFFにできます。全てをまとめて切り替える場合は **全パーティクル** を使用します。
:::
